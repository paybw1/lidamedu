# 하급심 판결문 투입 폴더 (특허법)

feat-2-035 판례 도식화의 **사실관계** 소스. 대법원 판결문은 법률심이라 사실관계가
"원심이 인정한 사실은 …" 으로 압축돼 있어, 2차 각색 출제의 원형이 되는 구체적 사실이 남지 않는다.

## 화면에서 먼저 시도한다

운영 화면 **`/admin/cases/lower-court`** 에서 건별로 바로 수집·적재할 수 있다(원장 요청 2026-08-20).
`자동 수집` → 실패하면 `원심번호 지정` → 그래도 없으면 `파일 업로드`(PDF·txt·md, 합계 4MB 이하)
또는 `전문 붙여넣기`. 파일명 규약은 아래와 같고, 앞 토큰(대법원 사건번호)을 떼어 출처 표기로 쓴다.
이 폴더에 직접 파일을 넣는 건 4MB 를 넘는 대용량이거나 배치로 한꺼번에 처리할 때다.

## 배치 자동 수집

```bash
npx tsx scripts/case-diagram/fetch-lower-court.mjs --year 2025    # 연도 단위
npx tsx scripts/case-diagram/fetch-lower-court.mjs --from 2005    # 전체
```

대법원 원문의 `【원심판결】` 표기를 파싱해 국가법령정보센터에서 하급심 전문을 받아온다.
**여기에 파일을 넣어야 하는 건 자동 수집이 실패한 건뿐이다** — 실행 끝에 그 목록이 출력된다.

## 파일명 규약

```
<대법원 사건번호> <법원> <하급심 사건번호>.pdf
```

```
2022후10814 특허법원 2021허4232.pdf
2022다265123 특허법원 2022나1234.pdf
2022다265123 서울중앙지법 2021가합5678.pdf     ← 심급 여러 개면 파일 여러 개(같은 접두어)
```

- **첫 공백 앞 토큰 = 대법원 사건번호 = 매칭 키.** DB 의 유일한 안정 키라 이걸 쓴다.
- 뒤 문구(법원·하급심 사건번호)가 그대로 학생 화면의 **출처 캡션**이 된다.
- 같은 접두어 파일이 여러 개면 전부 읽어 합친다(1심+2심). 순서는 파일명 정렬.
- **하위 폴더도 훑는다** — 묶어서 정리해 둬도 된다("업로드 불가 모음" 등). 파일명 규약만 지키면 된다.
- 허용 확장자: `.pdf`(텍스트 레이어 있는 것) · `.txt` · `.md`
- **스캔 이미지 PDF 는 텍스트가 안 나온다** — 추출 0자면 경고 후 건너뛴다(OCR 은 범위 밖).
- 추출은 글자 좌표로 줄을 다시 세운다(`app/features/cases/lib/pdf-extract.server.ts`). 판결문 PDF 는
  본문·괄호·숫자를 따로 그려 두는 경우가 많아 그냥 뽑으면 문장이 조각나고 숫자가 줄 끝으로 밀린다.
- 수기 파일이 있으면 자동 수집보다 **우선**한다(일부러 넣은 것이므로).

## 산출물

- `../.cache/<대법원사건번호>.json` — 전문 캐시. 재실행 시 재요청하지 않는다(`--refresh` 로 무시).
- `../.cache/_report-<범위>.json` — 확보/미확보 분류 리포트.

캐시는 `load-lower-court.mjs --apply` 로 `case_lower_courts`(staff 전용 RLS)에 적재된다 —
운영 화면에서 원문을 확인하고, 도식 생성기는 캐시가 없으면 DB 를 2차 소스로 읽는다.
학생 화면에는 어떤 경로로도 노출되지 않는다(저작물 전문).

## 리포트 분류 4종

| 표시 | 뜻 | 조치 |
|---|---|---|
| `자동` | 국가법령정보센터에서 하급심 전문 확보 | 없음 |
| `자체` | 판례 자체가 하급심(특허법원 판결 등) — 자기 원문이 곧 사실관계 | 없음 |
| `수기` | 이 폴더의 파일에서 확보 | 없음 |
| `△ 요지만` | 수록은 됐지만 판시사항·요지만 있어 사실관계가 없음 | **파일 투입** |
| `✗ 미수록` | 원심 사건번호는 알아냈으나 API 에 없음 | **파일 투입**(사건번호를 알고 있으니 판결문만 구하면 된다) |
| `✗ 원심 표기 없음` | 우리 DB 의 대법원 원문이 요약본이라 원심을 못 찾음 | **원심 확인 후 파일 투입** |

`✗ 미수록` 과 `✗ 원심 표기 없음` 은 필요한 작업이 다르다 — 앞은 판결문만 구하면 되고,
뒤는 원심이 무엇인지부터 찾아야 한다.
