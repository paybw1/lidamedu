주문관리 상태변경 및
결제금액 수정 기능 추가 요청
관리자페이지 주문관리에서 주문 상태와 결제금액을 관리자가 직접 수정할 수 있도록 개선 요청드립니다.
1. 주문상태 셀렉트 기능

관리자페이지 > 주문관리 > 상태 항목을 현재 단순 표시 방식이 아니라 셀렉트(드롭다운) 방식으로 변경해 주세요.

선택 가능한 주문상태
주문접수 결제완료 취소 삭제 환불완료
  • 관리자가 셀렉트에서 상태를 선택하면 해당 주문상태로 변경할 수 있게 해 주세요.
  • 상태 변경 후 저장 또는 확인 절차를 거쳐 반영되도록 해 주세요.
  • 변경일시와 처리관리자를 이력으로 남겨 주세요.
환불완료 선택 시 주의
주문상태를 「환불완료」로 변경하는 것만으로 토스 PG 취소가 자동 실행되면 안 됩니다. 실제 환불처리가 완료된 주문의 관리자 상태값을 정리하는 용도로만 사용해 주세요.
2. 결제금액 관리자 수정 기능

주문관리의 결제금액도 관리자 권한으로 직접 수정할 수 있게 해 주세요.

  • 주문 상세 또는 주문관리 화면에서 [결제금액 수정] 기능 제공
  • 현재 결제금액을 확인한 뒤 수정금액을 직접 입력할 수 있도록 구성
  • 수정 전 금액과 수정 후 금액을 모두 이력으로 보존
  • 수정사유 입력을 필수로 하고 처리관리자·수정일시를 저장
  • 결제금액 수정 후 주문목록과 주문상세에 변경된 금액이 정상 반영되도록 처리
중요
관리자페이지에서 결제금액을 수정하더라도 토스에서 실제 승인된 결제금액이 자동으로 변경되거나 추가결제·부분취소가 실행되면 안 됩니다. 관리자 시스템 내부의 주문금액 정정 기능으로 처리해 주세요.
가능하면 최초 결제금액(원본)은 별도로 보존하고, 관리자 수정금액과 구분하여 확인할 수 있게 해 주세요.
