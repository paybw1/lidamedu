1. 에디터 기능 재수정 요청
에디터 내 JavaScript 및 style 태그 정상 적용
미반영 재요청 ★★★

기존 요청에도 불구하고 현재 강의 상세보기와 페이지관리 에디터에서 HTML 소스코드를 입력할 경우 JavaScript 및 style 태그가 실제 페이지에서 정상적으로 동작하지 않습니다.

이벤트 풀페이지, T-PASS, 패키지 상세페이지 등은 HTML·CSS·JavaScript를 함께 사용하는 경우가 많기 때문에 관리자 HTML 소스모드에서 작성한 코드가 저장 후에도 유지되고 실제 사용자 페이지에서 정상 실행되어야 합니다.

  • HTML 소스모드에서 style 태그 입력 및 저장 가능
  • style 내부 CSS가 저장 후 삭제·변형되지 않도록 처리
  • @media, @keyframes, animation, transition 등 CSS 기능 정상 작동
  • HTML 소스모드에서 필요한 JavaScript 코드 입력 및 실행 가능
  • 저장 과정에서 script 코드가 제거되거나 텍스트로 변환되지 않도록 처리
  • 수정 화면 재진입 시 기존 HTML·CSS·JavaScript 구조 그대로 유지
  • PC·모바일 반응형 CSS 정상 적용
  • 관리자 미리보기와 실제 사용자 페이지 결과 동일
적용 대상은 최소한 강의 상세페이지 에디터와 운영관리 > 시스템 > 페이지관리 에디터입니다.
일반 회원 게시판에는 JavaScript 실행 권한을 줄 필요는 없습니다. 관리자 권한으로 작성하는 강의 상세페이지와 페이지관리에서만 HTML·CSS·JavaScript 소스 편집 및 실행을 허용해 주세요.
2. 홈페이지 메인화면 모듈형 관리
메인화면 모듈형 CMS 적용 미반영 재요청 ★★★

홈페이지 메인화면을 고정형으로 구성하지 않고, 관리자가 필요한 모듈을 직접 추가·수정·삭제하고 노출 순서를 자유롭게 변경할 수 있는 블록 조립형 CMS 구조로 개발해 주세요.

관리자 페이지에 [메인화면 관리] 메뉴를 추가하고 동일 종류의 모듈도 여러 개 등록할 수 있도록 해 주세요.

향후 메인화면 변경 시 별도 개발 요청 없이 관리자가 직접 구성할 수 있는 것이 핵심입니다.
