강의 카테고리 메뉴 추가

★★★ 필수

관리자가 강의 카테고리를 직접 등록하고 관리할 수 있는 별도의 강의 카테고리 메뉴를 추가해 주세요.

등록한 카테고리는 강의 개설·수정 시 선택할 수 있어야 하며, 관리자 검색과 사용자 홈페이지 강의 출력에도 동일하게 연동되어야 합니다.

카테고리 관리

등록, 수정, 사용 여부, 노출 순서 및 삭제 조건을 관리합니다.

강의 등록 연동

강의 개설 및 수정 화면에서 등록된 카테고리를 선택합니다.

홈페이지 출력

선택된 카테고리를 기준으로 강의 목록과 필터를 출력합니다.

관리 항목 요청 기능
카테고리 등록 관리자가 카테고리명을 직접 입력하여 추가
카테고리 수정 카테고리명과 상위·하위 구조 수정
사용 여부 사용 / 미사용 설정 및 미사용 카테고리 선택 제한
노출 순서 UID 또는 별도 순서값으로 관리자와 홈페이지 노출 순서 설정
등록 강의 수 각 카테고리에 연결된 강의 개수 표시
삭제 조건 연결된 강의가 있는 카테고리는 즉시 삭제하지 않고 이동 또는 연결 해제 안내
카테고리 구성은 특정 과목에 고정하지 않고 관리자가 자유롭게 추가·수정할 수 있는 구조로 개발해 주세요.

재생 횟수 차감 기준 수정

★★★ 필수

현재 안내된 “재생 횟수는 하루 1회 기준으로 차감됩니다(같은 날 여러 번 봐도 1회)” 문구와 차감 방식은 실제 운영 기준과 다르므로 삭제해 주세요.

재생 제한은 일별 차감 방식이 아니라 관리자가 해당 강의에 설정한 최대 재생 횟수를 기준으로 적용되어야 합니다.

구분 수정 요청사항
기존 기준 하루 1회 기준으로 차감하고 같은 날 여러 번 재생하면 1회만 차감하는 방식 삭제
변경 기준 관리자가 강의별로 설정한 최대 재생 횟수를 해당 강의 전체에 적용
차감 처리 시스템은 관리자 설정값을 기준으로 재생 횟수를 계산하고 제한
수강생 안내 최대 횟수와 남은 횟수는 내강의실 및 회차 목록에 별도로 표시하지 않음
관리자 확인 관리자 페이지에서는 강의별 설정값과 수강생별 사용 현황을 확인할 수 있도록 유지
최대 재생 횟수의 정확한 차감 시점과 중복 재생 처리 방식은 현재 관리자 설정 및 플레이어 정책과 일치하도록 적용하되, ‘하루 1회 차감’이라는 별도 규칙은 적용하지 않습니다.
