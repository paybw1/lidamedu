추가 수정 요청사항

실제 운영 테스트 중 확인된 오류 및 개선사항입니다. 저장 오류, 강의수정 이동 방식, 강의 상세페이지 폭, 수강연장 정책, 배수 설정 구조, 기기 설정 제거 및 에디터 HTML·CSS·JavaScript 적용 문제를 아래와 같이 수정 부탁드립니다.

추가 수정 요청사항

운영관리 · 강의개설 · 사용자 강의 상세페이지

배수 선택 시 저장 오류 수정

★★★ 필수

운영관리 > 상품 관리 > 상품·요금 관리의 강의 수강 정책(DRM)에서 현재 수강기간 방식 > 배수(강의시간 × N)를 선택한 후 저장하면 오류가 발생하며 저장되지 않습니다.

new row for relation "plan_policies" violates check constraint "plan_policies_check"
  • 배수 설정값 저장 시 DB check constraint 오류가 발생하지 않도록 수정
  • 기존 상품·요금 데이터에 영향 없이 저장 가능하도록 처리
  • 잘못된 값 입력 시 DB 오류문구가 아닌 관리자용 안내 메시지 출력
아래 요청과 같이 배수 설정 자체를 수강기간 방식에서 분리하면, 현재 저장 오류가 발생하는 정책 구조도 함께 재정리해 주세요.

배수 설정을 수강기간 방식에서 분리

★★★ 필수

현재 배수(강의시간 × N)가 수강기간 방식 안에 포함되어 있으나, 수강기간과 배수는 서로 다른 정책이므로 별도의 독립 설정으로 분리해 주세요.

구분 설정 항목 설명
수강기간 수강일수 / 지정 종료일 등 회원이 강의를 이용할 수 있는 기간을 설정
배수 1배수 / 1.5배수 / 2배수 / 3배수 / 무제한 등 강의시간 대비 실제 학습 가능 누적량을 별도로 설정
수강기간을 어떤 방식으로 설정하더라도 배수 값은 별도로 지정할 수 있어야 합니다.

강의수정 버튼 이동 방식 개선

★★★ 필수

운영관리 > 강의·도서몰 > 강의개설에서 등록된 강의의 강의수정 버튼을 클릭하면 현재 전체 강의 목록이 다시 표시되어, 그 목록에서 다시 해당 강의를 찾아야 하는 불편함이 있습니다.

강의개설 목록해당 강의의 강의수정 클릭해당 강의 수정폼 직접 이동
강의수정 버튼은 목록 페이지를 다시 거치지 않고, 클릭한 강의 UID에 해당하는 수정폼으로 바로 이동하도록 변경해 주세요.

강의 상세페이지 최대폭 수정

★★★ 필수

현재 사용자 강의 상세페이지의 가로 최대폭이 너무 좁아 상세 설명과 이미지 콘텐츠가 답답하게 표시됩니다.

  • PC 기준 강의 상세페이지 최대폭: 1230px
  • 가운데 정렬 유지
  • 모바일에서는 100% 반응형 적용
  • 에디터로 작성한 HTML 콘텐츠도 동일한 폭 안에서 정상 출력

수강 연장 허용 상세 설정

★★★ 필수

현재 수강 연장 허용 여부만 설정할 수 있으므로, 연장을 허용한 경우 실제 연장 조건을 추가로 입력할 수 있도록 해 주세요.

  • 수강 연장 허용 / 미허용
  • 허용 선택 시 1일당 연장 금액 입력
  • 최대 연장 가능 일수 입력
  • 회원이 연장일수를 선택하면 금액 자동 계산
예: 1일당 2,000원 / 최대 30일로 설정한 경우, 회원이 10일 연장을 선택하면 20,000원으로 자동 계산되도록 합니다.

최대 기기 수 설정 제거

★★★ 필수

현재 사이트 관리자에 있는 최대 기기 수 설정은 제거해 주세요. 기기 등록 및 기기 제한 정책은 콜러스에서 별도로 설정하고 있으므로 사이트에서 동일 기능을 중복 개발·관리할 필요가 없습니다.

  • 상품·요금 관리의 최대 기기 수 입력 항목 제거
  • 강의 등록·수정 화면의 기기 제한 관련 중복 설정 제거
  • 실제 기기 제한은 콜러스 정책을 기준으로 적용
사이트에서 별도 기기 제한 값을 적용하여 콜러스 설정과 충돌하지 않도록 해 주세요.

에디터 내 JavaScript 및 style 태그 정상 적용

★★★ 필수

현재 강의 상세보기와 페이지관리에서 사용하는 에디터에 HTML 소스코드를 입력할 경우 JavaScript와 <style> 태그가 정상적으로 동작하지 않는 문제가 있습니다.

이벤트 풀페이지, T-PASS, 패키지 상세페이지 등은 HTML·CSS·JavaScript를 함께 사용하여 제작하는 경우가 많으므로, 관리자 에디터에서 입력한 허용된 소스코드가 실제 사용자 페이지에서도 정상적으로 적용되고 실행되도록 수정해 주세요.

  • HTML 소스모드에서 <style> 태그 입력 및 저장 가능
  • <style> 태그 내부의 CSS가 저장 후에도 삭제되거나 변형되지 않도록 처리
  • 미디어쿼리(@media), @keyframes, animation, transition 등 CSS 기능 정상 적용
  • HTML 소스모드에서 필요한 JavaScript 코드 입력 및 실행 가능
  • 페이지 저장 후 JavaScript 코드가 임의로 삭제되거나 문자열로 변환되지 않도록 처리
  • 페이지 수정 후에도 기존 HTML·CSS·JavaScript 구조 유지
  • PC·모바일용 반응형 CSS 및 미디어쿼리 정상 작동
  • 관리자 미리보기 화면과 실제 사용자 페이지의 디자인 및 동작이 동일하게 적용
적용 대상은 최소한 강의 상세페이지 에디터와 운영관리 > 시스템 > 페이지관리 에디터입니다.
보안상 모든 사용자에게 JavaScript 실행 권한을 허용하는 방식은 지양하고, 관리자만 HTML·CSS·JavaScript 소스 편집 기능을 사용할 수 있도록 권한을 제한해 주세요. 일반 회원이 작성하는 게시판에는 JavaScript 실행 권한이 적용되지 않아야 합니다.
