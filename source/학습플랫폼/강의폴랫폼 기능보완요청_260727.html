관리자 기능

강의·콘텐츠·도서몰·매출·공지·커뮤니티 운영 기능

시리즈 및 에디션 제목 수정

★★★ 필수

시리즈명과 각 에디션명을 관리자 페이지에서 직접 변경할 수 있도록 수정 버튼이 필요합니다.

  • 시리즈명 수정
  • 에디션명 수정
  • 수정 후 기존 강의·목차·콘텐츠 연결 관계 유지

회차 및 제목 수정·삭제

★★★ 필수

등록된 강의 목차의 회차 번호와 제목을 수정하거나 삭제할 수 있어야 합니다.

  • 회차 번호 수정
  • 회차 제목 수정
  • 회차 삭제 및 삭제 확인 메시지
  • 기존 콘텐츠 연결 및 순서 정보 유지

수강신청 페이지 노출 순서 설정

★★★ 필수

홈페이지 > 수강신청에 노출되는 강의의 순서를 UID 숫자로 직접 설정할 수 있어야 합니다.

UID 숫자가 작은 강의부터 사용자 화면에 우선 노출되도록 처리해 주세요.

콜러스 콘텐츠 동기화 키 수정

★★★ 필수

콘텐츠라이브러리에서 콜러스 동기화 시 업로드 파일키가 아닌 미디어 콘텐츠키를 불러와 저장해야 합니다.

  • 동기화 기준값: Media Content Key
  • 콘텐츠 목록과 강의 목차 연결 시 동일 키 사용
  • 기존 업로드 파일키 저장 데이터 점검
실제 영상 재생에 직접 영향을 주는 항목이므로 우선 수정이 필요합니다.

시리즈·에디션 삭제 조건

★★★ 필수
  • 수강생이 존재하는 시리즈 또는 에디션은 삭제 불가
  • 수강생이 없는 경우에만 삭제 가능
  • 삭제 전 경고 및 재확인 메시지 표시
  • 삭제 권한은 최고관리자만 보유

강의관리 권한 확대

★★★ 필수

현재 관리자 계정에서 제한된 기능이 많으므로 강의 운영에 필요한 권한을 전체적으로 부여해 주세요.

  • 강의 등록·수정·복사·노출 관리
  • 목차 및 회차 관리
  • 시리즈·에디션 관리
  • 콘텐츠 연결 및 콜러스 동기화
  • 판매정보·수강정책·교재·샘플영상 관리

매출·정산관리 통계 분리

★★★ 필수

관리자 페이지의 매출·정산관리에서는 전체 매출을 한 화면에만 통합하여 표시하지 않고, 상품 유형에 따라 다음 3개의 통계 메뉴로 구분하여 관리할 수 있어야 합니다.

정기구독 통계

정기결제 상품의 신규 구독, 유지 구독, 해지, 결제 성공 및 결제 실패 내역을 기준으로 매출을 확인합니다.

강의매출 통계

온라인 단과, 현장강의, 패키지강의 등 강의 상품의 결제 및 환불 내역을 기준으로 매출을 확인합니다.

도서매출 통계

도서몰에 등록된 교재와 도서 상품의 결제, 취소, 환불 내역을 기준으로 매출을 확인합니다.

정기구독, 강의, 도서의 매출 데이터는 각각 분리하여 조회할 수 있어야 하며, 필요할 경우 전체 매출 합계도 별도로 확인할 수 있도록 해 주세요.

매출통계 기간 검색 기능

★★★ 필수

정기구독 통계, 강의매출 통계, 도서매출 통계에서 공통으로 기간별 검색 기능을 제공해야 합니다.

검색 기준 요청 기능
일별 선택한 날짜의 매출, 환불, 실매출 확인
주별 선택한 주간의 일자별 매출 및 주간 합계 확인
월별 선택한 월의 일자별 매출 및 월간 합계 확인
연도별 선택한 연도의 월별 매출 및 연간 합계 확인
직접 기간 설정 시작일과 종료일을 직접 선택하여 검색
  • 결제금액
  • 할인금액
  • 쿠폰 및 포인트 사용금액
  • 환불금액
  • 실매출금액
  • 결제건수
  • 취소·환불건수

강의매출 통계 검색 조건

★★★ 필수

강의매출 통계에서는 기간 검색과 함께 강의 유형 및 카테고리를 기준으로 매출을 구분하여 확인할 수 있어야 합니다.

검색 항목 요청 기능 중요도
전체강의 모든 강의 상품의 매출을 통합하여 조회 필수
단과강의 온라인 단과강의 매출만 별도 조회 필수
현장강의 학원 현장강의 매출만 별도 조회 필수
패키지강의 패키지 및 기간제 강의 상품 매출만 별도 조회 필수
카테고리 민법, 특허법, 상표법, 디자인보호법, 자연과학 등 카테고리별 조회 필수
개별 강의 검색 강의명, 강사명 또는 강의 UID로 특정 강의 매출 조회 선택
전체강의, 단과강의, 현장강의, 패키지강의 구분 검색은 반드시 제공해 주세요. 개별 강의 검색 기능은 개발 여건에 따라 제외해도 무관합니다.

도서매출 통계 검색 조건

★★★ 필수

도서매출 통계에서는 기간 검색과 함께 도서 카테고리를 기준으로 매출을 구분하여 확인할 수 있어야 합니다.

검색 항목 요청 기능 중요도
전체도서 도서몰에 등록된 전체 도서 매출 조회 필수
카테고리 과목, 시험 구분, 출판 분야 등 등록된 도서 카테고리별 조회 필수
개별 도서 검색 도서명, ISBN 또는 도서 UID로 특정 도서 매출 조회 선택
도서 카테고리별 매출 검색 기능은 반드시 제공해 주세요. 개별 도서 검색 기능은 개발 여건에 따라 제외해도 무관합니다.

매출통계 결과 표시 및 다운로드

★★ 운영필수

검색 결과에서는 매출과 환불 내역을 한눈에 확인할 수 있도록 요약 정보와 상세 내역을 함께 표시해 주세요.

  • 총 주문금액
  • 총 할인금액
  • 총 결제금액
  • 총 환불금액
  • 최종 실매출금액
  • 결제건수 및 환불건수
  • 상품별 판매수량
  • 결제수단별 매출
  • 검색 결과 엑셀 다운로드
엑셀 다운로드 시 현재 화면에서 적용한 기간, 상품 유형, 카테고리, 개별 상품 등의 검색 조건이 동일하게 반영되어야 합니다.

이미지 권장 사이즈 안내

★★★ 필수

관리자 페이지에서 이미지를 등록하는 모든 영역에 해당 이미지의 권장 가로 × 세로 픽셀(px) 사이즈를 명확하게 표시해 주세요.

예시)

  • 강의 썸네일: 800 × 450px
  • 교재 표지: 600 × 850px
  • 강사 프로필: 600 × 800px
  • PC 배너: 1920 × 500px
  • 모바일 배너: 750 × 900px

이미지 등록 영역에는 다음 정보를 함께 안내해야 합니다.

  • 권장 이미지 크기
  • 권장 이미지 비율
  • 허용 파일 형식
  • 최대 파일 용량
권장 사이즈와 다른 이미지를 업로드하더라도 화면이 깨지거나 비율이 과도하게 변형되지 않도록 자동 리사이징 또는 중앙 기준 잘라내기 기능을 적용해 주세요.
PC용 이미지와 모바일용 이미지의 권장 크기가 다른 경우에는 각각 별도로 등록할 수 있도록 하고, 각 등록 위치에 맞는 권장 사이즈를 개별적으로 표시해 주세요.

공지·커뮤니티 게시판 에디터 기능

★★★ 필수

관리자 페이지의 공지·커뮤니티 게시판에도 통합 에디터 기능을 적용하여 일반 편집모드와 HTML 소스 편집모드를 모두 사용할 수 있어야 합니다.

  • 일반 글쓰기 편집모드 지원
  • HTML 소스 직접 편집모드 지원
  • 일반 편집모드와 HTML 편집모드 간 전환
  • 글자 크기, 굵기, 색상, 정렬 등 기본 서식 기능
  • 이미지 업로드 및 본문 삽입
  • 표 삽입 및 편집
  • 외부 링크 및 내부 페이지 링크 삽입
  • 유튜브 영상 및 iframe 소스 삽입
  • 파일 첨부 및 첨부파일 다운로드
  • 작성 중 미리보기 및 전체화면 편집
HTML 편집모드에서 입력한 스타일, 표, 이미지, 링크 및 iframe 코드가 저장 과정에서 임의로 삭제되거나 변경되지 않도록 처리해 주세요.
첨부파일 등록 영역에는 허용 확장자와 최대 파일 용량을 표시하고, 실행파일 등 보안상 위험한 파일 형식은 업로드할 수 없도록 제한해 주세요.

강의별 주교재·부교재 연결

★★★ 필수

도서몰에 등록된 교재를 강의와 연결하여 사용자 화면과 결제 화면에 표시할 수 있어야 합니다.

구분 요청 기능 비고
교재 검색 도서몰에 등록된 교재명 또는 도서 UID로 검색 판매 중인 교재 중심
교재 구분 주교재와 부교재를 구분하여 지정 부교재 복수 선택 가능
구매 설정 필수 구매 또는 선택 구매 설정 강의별 설정
노출 관리 교재 노출 순서, 노출 여부, 연결 해제 기존 도서정보 자동 반영

수강생 강의실·플레이어·결제 기능

마이페이지 강의실 입장 방식

★★★ 필수

수강현황에서 버튼을 클릭했을 때 영상이 즉시 재생되지 않고 강의 목차 화면으로 먼저 이동해야 합니다.

마이페이지수강현황강의실 입장강의 목차회차 선택영상 재생
현재 ‘강의보기’ 버튼 명칭은 ‘강의실 입장’으로 변경해 주세요.

강의와 교재 동시 결제

★★★ 필수

강의 신청 과정에서 연결된 주교재·부교재를 선택하여 하나의 주문으로 동시에 결제할 수 있어야 합니다.

  • 강의 결제 완료 후 수강권 자동 지급
  • 교재 주문 생성 및 재고 자동 차감
  • 배송지 입력 및 배송비 자동 계산
  • 품절 교재 선택·결제 차단
  • 강의와 교재의 취소·환불 상태 분리 관리

결제 화면 내 교재 정보 간소화

★★★ 필수

강의 결제 화면에서는 교재 상세설명을 모두 노출하지 않고 구매 결정에 필요한 정보만 간략하게 표시해 주세요.

노출 항목 처리 방식
교재 이미지 작은 썸네일 형태로 표시
교재 구분 주교재 / 부교재 구분 표시
교재명·판매가격 한눈에 확인 가능하도록 간단히 표시
재고 상태 판매중 / 품절 상태 표시
선택 기능 체크박스 및 수량 선택 제공
상세보기 도서몰 교재 상세페이지로 이동
결제금액은 강의 금액, 교재 금액, 배송비, 할인금액, 최종 결제금액으로 구분하여 표시해 주세요.
