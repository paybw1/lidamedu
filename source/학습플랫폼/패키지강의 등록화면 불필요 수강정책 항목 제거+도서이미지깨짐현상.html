패키지강의 등록화면
불필요 수강정책 항목 제거 요청
패키지에 포함되는 개별 단과강의에서 이미 설정하는 항목은 패키지 등록화면에서 중복 노출하지 않도록 정리해 주세요.
요청사항

정규 패키지 / 상시 패키지 상품 등록 시 아래 수강정책은 패키지 자체에서 다시 설정하지 않아도 됩니다. 패키지에 포함된 각 개별 단과강의의 설정값을 그대로 적용해 주세요.

패키지 등록화면에서 제거할 항목
  • 수강배수 — 무제한 / 1배수 / 1.5배수 / 2배수 / 3배수 / 직접입력
  • PC 수강 허용
  • 모바일 수강 허용
  • 다운로드 허용
  • 수강기간 일시정지 허용
  • 일시정지 최대 횟수 / 1회 최소일 / 1회 최대일 / 누적 최대일
  • 유료 수강기간 연장
  • 연장비용 / 최대횟수 / 연장일수
적용 원칙
패키지는 여러 단과강의를 묶어 판매하는 상품이므로, 영상 재생·기기·다운로드·일시정지·연장 등 강의별 수강정책은 각 단과강의에서 설정한 값을 사용하도록 해 주세요.
패키지에서 유지할 설정

패키지 등록화면에는 패키지 자체에 필요한 정보만 남겨 주세요.

  • 패키지에 포함할 강의 선택
  • 패키지 전체 수강기간 또는 과정기간
  • 패키지 정상가·판매가
  • 판매기간·노출기간
  • 구성강의별 정상가격 등 환불 계산에 필요한 정보
함께 쓰는 교재 이미지 깨짐 현상 수정

수강생 강의 상세페이지의 「함께 쓰는 교재」 영역에서 교재 표지 이미지가 정상적으로 표시되지 않고 깨진 이미지 아이콘으로 보이는 현상이 확인됩니다.

현재 현상
  • 교재명·가격·상세보기·담기 버튼은 정상 표시됨
  • 교재 표지 이미지 영역만 깨진 이미지로 표시됨
  • 관리자 교재 등록/수정 화면에 저장된 이미지가 실제 공개 화면에서 정상 호출되는지 확인
  • 상대경로·절대경로·도메인 변경 등으로 이미지 URL이 잘못 생성되는지 점검
  • 이미지가 없는 교재는 깨진 아이콘 대신 기본 이미지 또는 이미지 없음 상태를 표시
  • PC·모바일 모두에서 교재 이미지 비율이 깨지지 않고 정상 표시되도록 처리
