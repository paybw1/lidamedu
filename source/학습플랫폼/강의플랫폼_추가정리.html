관리자페이지 추가기능

  • 무료 강의 수동 지급 ★★★★ 필수
    회원에게 강의를 무료로 수동 지급합니다.
    회원관리에서 강의 아이디로 지급 또는 강의관리에서 회원 아이디로 등록할 수 있습니다.
  • 도서 무료배송 기준 설정  ★★★★ 필수
    관리자 페이지에서 도서 상품의 무료배송 기준 금액을 설정할 수 있어야 합니다.
    무료배송 조건은 도서 상품의 결제금액만 기준으로 계산하며, 강의 상품 금액은 합산하지 않습니다.

  • 수강평·교재평 관리  ★★★ 필수
    강의와 교재에는 각각 수강평(강의 후기), ​교재평(도서 후기) 게시판을 운영할 수 있어야 합니다
    회원은 구매한 강의 또는 교재에 대해서만 후기를 작성할 수 있으며, 관리자는 관리자 페이지에서
    후기의 등록, 수정, 삭제, 비공개 처리 및 베스트 후기를 관리할 수 있어야 합니다.

    수강평 및 교재평에는 다음 기능이 포함되어야 합니다.

    • 강의별 수강평 게시판
    • 교재별 교재평 게시판
    • 별점(평점) 기능
    • 후기 작성, 수정, 삭제
    • 관리자 답변 등록
    • 베스트 후기 지정
    • 공개 / 비공개 처리
    • 신고 및 블라인드 처리
    • 작성일, 작성자, 조회수 표시
    • 강의 및 교재 상세페이지에 후기 목록과 평균 평점 자동 표시
    • 구매한 회원만 후기 작성 가능하도록 권한 제한


강의관리 메인 화면

  • 강의 목록 ★★★ 필수
    등록된 단과 강의와 패키지 강의를 조회하고 강의명, 카테고리, 강사, 판매상태, 수강생 수를 확인합니다.
  • 강의 검색 및 필터 ★★★ 필수
    강의명, 강사, 카테고리, 판매상태, 공개상태 기준으로 강의를 검색합니다.
  • 강의등록 ★★★ 필수
    하나의 단과 강의에 기본정보, 판매가격, 수강정책, 상세소개, 강의목차를 등록합니다.
  • 패키지강의등록 ★★★ 필수
    여러 단과 강의를 하나의 상품으로 묶어 판매합니다.
  • 강의복사 ★★ 운영필수
    기존 강의의 기본정보, 판매정보, 수강정책, 상세소개, 목차를 복사하여 신규 연도 강의를 빠르게 생성합니다.
  • 강의 노출 순서 변경 ★★ 운영필수
    메인 또는 카테고리 페이지에 표시되는 강의 순서를 직접 조정합니다.

강의등록 화면 구조

판매정보 설정

  • 정가 ★★★ 필수
    할인 전 기준 가격을 입력합니다.
  • 수강료 ★★★ 필수
    회원이 실제 결제하는 판매금액을 입력합니다.
  • 무료수강 ★★★ 필수
    무료강의 체크 시 결제 없이 수강 신청 또는 즉시 수강권이 지급되도록 합니다.
  • 판매기간 ★★★ 필수
    상품을 구매할 수 있는 판매 시작일과 판매 종료일을 설정합니다.
  • 쿠폰 사용 여부 ★★ 운영필수
    해당 강의에 할인쿠폰을 적용할 수 있는지 설정합니다.
  • 포인트 사용 및 적립 ★★ 운영필수
    결제 시 포인트 사용 여부와 결제 완료 후 적립률을 설정합니다.
  • 과세·면세 설정 ★★★ 필수
    온라인 강의와 교재 결합상품의 과세·면세 구분을 주문과 정산에 반영합니다.
  • 강사 정산 기준 연결 ★★★ 필수
    강사별 매출 배분율 또는 정산기준을 강의에 연결합니다.
  • 교재 연결 ★★★ 필수
    강의 상세페이지에서 구매할 필수교재 또는 선택교재를 연결합니다.

수강정책 설정

  • 수강일수 ★★★ 필수
    결제일 또는 수강 시작일 기준으로 강의를 볼 수 있는 기본 수강기간을 설정합니다.
  • 수강 시작 기준 ★★★ 필수
    결제 즉시 시작, 회원 직접 시작, 지정일 시작 중 하나를 선택합니다.
  • 고정 종료일 ★ 선택
    프리패스나 시험일까지 제공되는 상품처럼 모든 회원의 종료일을 동일하게 설정할 때 사용합니다.
  • 수강 배수 ★★★ 필수
    1.5배수, 2배수, 3배수 또는 무제한으로 설정합니다.
  • PC·모바일 수강 ★★★ 필수
    PC와 모바일에서 모두 재생할 수 있는지 설정합니다. 대부분의 상품은 PC+모바일 허용을 기본값으로 사용합니다.
  • 다운로드 허용 ★★ 운영필수
    콜러스 앱을 통한 DRM 다운로드 및 오프라인 수강 허용 여부를 설정합니다.
  • 유료연장 사용 여부 ★★★ 필수
    수강 종료 전후에 회원이 유료로 수강기간을 연장할 수 있는지 설정합니다.
  • 연장 단위 및 가격 ★★★ 필수
    예: 1일 연장 6,000원처럼 연장일수와 금액을 설정합니다.
  • 일시중지 사용 여부 ★★★ 필수
    수강생이 강의를 일정 기간 중지하고 사용한 기간만큼 종료일을 연장할 수 있도록 합니다.
  • 일시중지 총 사용일수 ★★★ 필수
    전체 수강기간 동안 사용할 수 있는 최대 정지일수를 설정합니다. 예: 총 30일.
  • 일시중지 최대 횟수 ★★★ 필수
    전체 정지일수를 나누어 사용할 수 있는 최대 횟수를 설정합니다. 예: 최대 30일 중 3회까지 사용.
  • 일시중지 중 재생 차단 ★★★ 필수
    일시중지 기간에는 해당 수강권의 영상 재생을 차단합니다.

강의소개 및 상세페이지

  • 강의 미리보기(샘플영상) 재생 버튼 ★★★ 필수
    강의 상세페이지에 ‘샘플영상 보기’ 또는 ‘강의 미리보기’ 버튼을 표시합니다. 버튼을 클릭하면 관리자가 맛보기로 지정한 콜러스 영상이 DRM 플레이어로 재생되어야 하며, 비회원 또는 미구매 회원도 재생할 수 있도록 별도 권한으로 처리합니다.
  • 강의 요약소개 ★★ 운영필수
    강의 목록과 상세페이지 상단에 표시될 짧은 소개문구를 입력합니다.
  • HTML 에디터 기능 ★★★★ 핵심필수

    일반 편집모드와 HTML 소스 편집모드를 모두 사용할 수 있어야 하며, 두 모드 간 전환 후에도 입력한 HTML과 CSS가 손상되거나 삭제되지 않아야 합니다.

    ✓ 표 삽입
    ✓ 유튜브·동영상 iframe 삽입
    ✓ 링크 삽입
    ✓ 글자 크기 및 색상 변경
    ✓ 전체화면 편집
    ✓ 미리보기
    ✓ 기존 HTML 코드 불러오기 및 재편집
    ✓ 모바일용 HTML 및 CSS 코드 보존
  • PC·모바일 미리보기 ★★ 운영필수
    저장 전 상세페이지가 PC와 모바일에서 어떻게 표시되는지 확인합니다.
  • 임시저장 ★★ 운영필수
    작성 중인 상세페이지를 공개하지 않고 저장합니다.

강의 목차 및 콜러스 콘텐츠 연결

강의 기본정보가 최초 저장되면 강의목차 탭 또는 목차관리 버튼이 활성화되어야 합니다.

  • 강의 저장 후 목차관리 활성화 ★★★ 필수
    강의 기본정보를 최초 저장하면 시스템은 고유 강의번호를 생성합니다.
    생성된 강의번호를 기준으로 목차를 관리하므로, 최초 저장 전에는 '목차관리' 탭을 비활성화하고 저장 완료 후 활성화해야 합니다.
  • 강의그룹 콘텐츠 불러오기 ★★★ 필수
    콘텐츠관리에서 생성한 강의그룹을 선택하고 해당 그룹의 콜러스 영상을 불러옵니다.
  • 여러 콘텐츠 일괄 추가 ★★★ 필수
    여러 회차의 영상을 한 번에 선택해 강의목차에 추가합니다.
  • 회차명 자동입력 ★★★ 필수
    콘텐츠에 등록된 강의명을 목차명으로 자동 적용하고 필요하면 수정합니다.
  • 목차 순서 변경 ★★★ 필수
    드래그 앤 드롭으로 회차의 노출 순서를 변경합니다.
  • 공개·비공개 설정 ★★★ 필수
    오류 또는 검수 중인 회차를 수강생 화면에서 숨깁니다.
  • 예약 공개 ★★★ 필수
    특정 날짜와 시간부터 회차가 자동 공개되도록 설정합니다.
  • 맛보기 설정 ★★ 운영필수
    특정 회차를 구매 전 무료로 재생할 수 있도록 설정합니다.
  • 배수 차감 여부 ★★★ 필수
    일반 회차는 배수를 차감하고 OT·무료·맛보기 영상은 차감하지 않도록 설정합니다.
  • 진도율 반영 여부 ★★ 운영필수
    OT, 공지영상, 보충영상 등을 전체 진도율 계산에서 제외합니다.
  • 회차별 강의자료 ★★ 운영필수
    PDF, 강의노트, 문제지, 정오표를 회차별로 연결합니다.
  • 영상 교체 ★★★ 필수
    회차명과 수강기록은 유지하면서 연결된 콜러스 콘텐츠만 수정 영상으로 교체합니다.
  • 동일 콘텐츠 재사용 ★★★★ 필수
    동일한 콜러스 콘텐츠를 여러 강의에서 중복 업로드 없이 사용할 수 있어야 합니다.

  • 포함 단과강의 선택 ★★★ 필수

  • 패키지 내 강의 순서 ★★ 운영필수

  • 패키지 수강기간 ★★★ 필수

  • 포함 강의 기간 적용방식 ★★★ 필수

강의 목차 연결

콘텐츠관리에서 정리한 영상을 실제 판매 강의의 목차에 불러와 연결합니다.

  • 강의그룹 기준 불러오기 ★★★ 필수
    목차관리에서 강의그룹을 선택하면 해당 그룹에 포함된 콘텐츠만 표시합니다.
  • 여러 콘텐츠 일괄 선택 ★★★ 필수
    그룹 내 여러 영상을 한 번에 선택하여 강의 목차에 추가합니다.
  • 목차명 자동 적용 ★★★ 필수
    콘텐츠에 등록된 강의명을 목차명으로 자동 적용하고 과정별로 수정할 수 있습니다.
  • 목차 순서 변경 ★★★ 필수
    드래그 앤 드롭으로 1강, 2강, 3강의 노출 순서를 조정합니다.
  • 회차별 공개 및 예약 공개 ★★★ 필수
    회차를 즉시 공개하거나 특정 날짜와 시간부터 공개되도록 설정합니다.
  • 맛보기 설정 ★★★ 필수
    특정 회차를 결제 전 무료로 재생할 수 있는 맛보기 영상으로 지정합니다.
  • 배수 차감 여부 ★★★ 필수
    일반 강의는 배수를 차감하고 OT, 무료, 맛보기 영상은 배수 차감에서 제외합니다.
  • 진도율 반영 여부 ★★ 운영필수
    OT, 공지, 보충영상 등은 전체 강의 진도율 계산에서 제외할 수 있습니다.
  • 회차별 교안 연결 ★★ 운영필수
    PDF, 강의노트, 문제지 등 수강생에게 제공할 파일을 회차별로 연결합니다.
  • 영상 교체 ★★★ 필수
    회차명, 진도율, 수강기록은 유지하면서 연결된 콜러스 콘텐츠만 수정 영상으로 교체합니다.
  • 콘텐츠 재사용 ★★★ 필수
    동일한 콜러스 콘텐츠를 여러 단과 강의나 패키지 과정에서 중복 업로드 없이 사용할 수 있어야 합니다.

개발사 전달용 핵심 요구사항

관리자가 콜러스에 동영상을 업로드한 후 사이트 관리자에서 ‘콜러스 콘텐츠 불러오기’를 실행하면

콘텐츠명, 콘텐츠 키, 원본 파일명, 실제 재생시간, 인코딩 상태가 등록되어야 합니다.

동일 콘텐츠 키는 중복 등록되지 않아야 하며, 불러온 콘텐츠는 강의그룹별로 분류할 수 있어야 합니다.

콘텐츠에는 회차명, 완강 인정 기준, 교안, 관리자 메모, 활성 여부, 사용 상태를 설정할 수 있어야 합니다.

강의관리의 목차 탭에서는 강의그룹을 선택하여 여러 콘텐츠를 목차에 연결하고, 회차 순서, 공개일,

맛보기 여부, 배수 차감 여부, 진도율 반영 여부를 설정할 수 있어야 합니다.

동일한 콜러스 콘텐츠는 여러 곳(강의플랫폼, 학습플랫폼)에서 재사용할 수 있어야 하며, 영상 교체 시 기존 수강기록과 진도율은 유지해야 합니다.

콘텐츠 연결, 교체, 사용중지 및 상태 변경 내역은 관리자와 처리일시를 포함하여 이력으로 저장해야 합니다.
