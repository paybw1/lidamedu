# 해설 컴포넌트 명세

근거는 2026-09 노출 해설 1,622건 실측입니다. 수치를 바꾸려면 재측정하세요.

---

## 1. 실측이 확정한 제약

| 제약 | 수치 | 컴포넌트 결과 |
|---|---|---|
| 문단 수 p95 | 3 | `reasoning` 기본 3문단 가정 |
| 조문 인용 p95 | 6개 | 각주에 전량 표시. 상한 없음 |
| 판례 인용 p95 | 5개 | 동일 |
| 과목 간 길이 편차 | 3배 (민법 467 / 상표 1,371) | 접기 임계를 과목별로 |
| 인용 보유 극단 | 민법 95.4% / 자연과학 0% | 레일 유무 양쪽에서 성립해야 |
| 100자 미만 | 75건 (4.6%) | 부실 표시 필요 |
| 최장 | 3,650자 | 접기 필수 |
| 구조 마커 보유 | 0.1% | v1 폴백 렌더링 필수 |

핵심은 마지막 두 줄입니다. **v1(통짜)과 v2(스키마)가 전환 기간 동안 공존**하고, 둘이 시각적으로 크게 달라 보이면 폴백이 항상 못생겨집니다.

## 2. 구조

```
┌─ ExplanationCard ──────────────────────────────────────┐
│                                                        │
│  ┌─ ConclusionBlock ─────────────────────────────┐     │
│  │ 정답 ③                                        │     │
│  │ 전세권이 소멸한 경우 전세금 반환의무는 …      │     │
│  └───────────────────────────────────────────────┘     │
│                                                        │
│  ─ ReasoningBlock ─                                    │
│  전세권은 용익물권이면서 담보물권의 성격을 겸유한다.   │
│  제303조가 우선변제권을 규정하고, 양도에는             │
│  ‾‾‾‾‾‾‾                                               │
│  제450조 제2항의 대항요건이 적용된다.                  │
│                                                        │
│  판례는 2001다4981에서 이를 다루었고 …                 │
│           ┄┄┄┄┄┄┄┄┄┄                                   │
│                                                        │
│  │ 함정                                                │
│  │ 선지 ②는 목적물 양수인에게 반환의무가 …             │
│                                                        │
│  ─ CitationFootnote ─────────────────────────────       │
│  참조조문  제303조 제317조 제450조② 제186조 제187조    │
│  참조판례  2001다4981● 66다1456○ 70다877◌ 99다15122●   │
└────────────────────────────────────────────────────────┘
```

인용을 본문 아래 각주로 내립니다. 우측 레일안을 목업으로 비교한 결과 본문 폭이 눌려 명조 조판이 죽었고, 조문 6개·판례 5개가 레일에 안 들어가 `+n` 접기가 필요했습니다. 각주는 가로로 흘러 p95 전량이 한눈에 들어옵니다.

`참조조문`·`참조판례`는 판결문 관습 그대로입니다. 수험생이 이미 아는 라벨이라 설명이 필요 없습니다.

**모바일**도 같은 구조입니다. 각주만 기본 접힘입니다.

```
┌─────────────────────┐
│ 정답 ③              │
│ 전세권이 소멸한 …   │
├─────────────────────┤
│ 전세권은 용익물권…  │
│                     │
│ 판례는 2001다4981…  │
├─────────────────────┤
│ 참조 ▾              │  ← 기본 접힘
│ 조문 6 · 판례 5     │
└─────────────────────┘
```

## 3. 컴포넌트

### `ExplanationCard`

variant 두 축입니다.

| 축 | 값 | 근거 |
|---|---|---|
| `schema` | `v2` \| `v1` | 구조 마커 0.1%. 전환 기간 공존 |
| `density` | `cited` \| `uncited` | 민법 95.4% vs 자연과학 0% |

`uncited`는 각주 블록 자체를 렌더링하지 않습니다. 빈 `참조조문` 줄을 남기지 마세요. 자연과학 679건이 이쪽이고, 인용이 하나도 없는 상태가 정상입니다. 목업에서 이 카드가 가장 잘 읽혔습니다.

길이 상태는 variant가 아니라 파생값입니다.

- `len >= --fold-short` (800) → 민법·자연과학 접힘
- `len >= --fold-long` (1200) → 특허·상표·디자인 접힘
- `len < 100` → 본문 아래 부실 표시. 75건
- `len < 20` → 빈 상태. 40건. **본문을 그대로 노출하지 마세요**

임계를 800 단일 값으로 두면 상표가 두 문단에서 끊깁니다. 인용은 각주에 다 보이는데 논리는 안 보이는 상태가 되어, 근거만 있고 설명이 없는 카드가 됩니다.

### `ConclusionBlock`

`--t-md` / 좌측 감색 괘선 2px. `unsplittable`이면 렌더링하지 않고 `reasoning`만 표시합니다. 파일럿에서 이 비율이 낮게 나왔지만 전량에서 올라가면 이 블록을 접어야 합니다.

### `ReasoningBlock`

`.explanation-body`. 문단 간격 `--sp-5`. 4문단 이상이면 접기 대상 후보로만 보고 문단 수 자체로는 접지 않습니다. p95가 3이라 예외입니다.

### `InlineCitation`

본문 안의 조문·판례 참조입니다. **조문은 실선 밑줄, 판례는 점선 밑줄**입니다.

색이 아니라 형태가 구분자입니다. 흑백 인쇄와 색각 이상 양쪽에서 성립해야 하고, 점선 밑줄 단일안은 흑백에서 완전히 뭉개집니다.

검증 상태는 본문에 표시하지 않습니다. 점선을 이미 조문·판례 구분에 썼고, 읽는 중에 확정 여부를 알 필요가 없습니다. 각주에서 확인하면 충분합니다.

폐기한 두 안을 기록해 둡니다. **어깨번호**는 명조 본문에 고딕 숫자가 올라가 행간이 흔들리고 `제450조 제2항³`이 `제2항3`으로 읽힙니다. **바탕색**은 조문 6개면 문장이 칩으로 덮이고, 각주 칩과 형태가 같아 본문과 각주의 위계가 사라집니다.

### `CitationFootnote`

`참조조문` / `참조판례` 두 줄. 라벨 폭 고정, 칩은 가로로 흐릅니다. 상한 없이 전량 표시합니다.

본문 `InlineCitation`과 양방향으로 연동합니다. 한쪽에 머물면 다른 쪽이 강조됩니다. 각주형은 인용이 본문에서 멀어지므로 이 연동이 필수입니다 — 조문 6개가 두 문단에 흩어져 있으면 각주의 `제186조`가 본문 어디서 나온 것인지 안 보입니다.

키보드로도 도달 가능해야 합니다. `aria-describedby`가 이미 양쪽을 잇고 있으니 추가 비용은 적습니다.

### `StatuteChip`

감색. `제450조 제2항` 형태를 그대로 보존합니다. 재구조화 검증이 표기 보존을 전제로 하므로 UI에서 정규화하면 안 됩니다.

### `PrecedentChip`

주색. 검증 상태 3단입니다.

| 상태 | 표시 | 의미 |
|---|---|---|
| `confirmed` | 채운 점 ● | DB 수록 또는 외부 소스 확인 |
| `pending` | 빈 점 ○ | 조회 불가. 심리불속행·미공간·옛 판결 |
| `unchecked` | 점선 점 ◌ | 아직 검증 안 함 |

`pending`을 오류로 보이게 하지 마세요. 감사에서 `98다54434`·`2007다5069`가 두 공개 DB에 없지만 대법원 판결문이 이름을 들어 인용한 실재 판례였습니다. 「출처 없음」이 아니라 「확인 중」입니다.

심리불속행 기각도 같습니다. 공간되지 않으므로 조회에 안 잡히는 게 정상이고, `pending`으로 표시될 뿐 오류가 아닙니다.

### `PitfallNote`

좌측 괘선만. 별색 없음. 12.5%만 보유하고 그중 다수가 오답 선지 분석의 재진술이라, 별색을 주면 없는 카드가 비어 보입니다.

### `FallbackBody` (v1)

통짜 본문을 `.explanation-body`로 렌더링하고, 인용은 정규식 추출로 레일에 띄웁니다. `conclusion`이 없으니 첫 문단을 강조하지 마세요. 추측입니다.

## 4. 접근성

- 감색 `#1F3A5F` on `--paper` = 9.8:1 / 주색 `#8E2B26` = 7.4:1. 둘 다 AA 통과
- 조문·판례 구분은 **색이 아니라 밑줄 형태**입니다. 실선 대 점선
- 검증 상태도 **색으로만** 전달하지 않습니다. 점 모양이 구분자고 색은 보조입니다
- 각주 칩은 키보드 도달 가능. 본문 참조와 `aria-describedby`로 양방향 연결
- 다크 모드에서 감색·주색을 밝은 쪽으로 반전. 토큰 파일에 포함

## 5. 목업으로 확정된 것

| 결정 | 근거 |

| 우측 레일 폐기, 각주형 채택 | 레일이 본문 폭을 눌러 명조 조판이 죽음 |

## 6. 남은 결정

**특허 208건은 이 명세 대상이 아닐 수 있습니다.** 조문 26.4%·판례 5.8%는 민법 95.4%·90.7%와 성격이 다릅니다. 재구조화가 아니라 재생성 대상이면 필드 구조부터 다시 봐야 합니다.

**`--measure: 34em`과 접기 임계는 아직 읽기 실험을 거치지 않았습니다.** 목업에서 눈으로 확인한 값이고, 분포에서 나온 값입니다. 실제 수험생이 읽어 본 결과는 아닙니다.
