구축 기본 방향

영상 파일은 자체 서버에 저장하지 않고, 콜러스플레이어·스타플레이어 등 외부 DRM 서비스에 업로드된 영상 ID를 사이트 강의 회차와 연결하는 구조로 개발합니다.

1
ADMIN CORE
영상 관리
외부 DRM 서비스에 업로드된 영상을 사이트의 강의 회차와 연결하고, 수강생에게 노출되는 영상 정보를 관리하는 기능입니다.
기능명 중요도 개발 요청 내용
강의별 영상 등록 ★★★★★ 하나의 강의 상품 안에 1강, 2강, 3강 등 회차별 영상을 등록하는 기능입니다.
외부 플레이어 영상 ID 등록 ★★★★★ 콜러스 콘텐츠 ID, 스타플레이어 영상 키 등 외부 DRM 영상 식별값을 입력하여 사이트 회차와 연결합니다.
영상 제목, 회차, 강사, 과목, 재생시간 입력 ★★★★★ 수강생 강의 목록에 표시될 기본 정보를 입력합니다.
영상 순서 변경 ★★★★★ 등록된 회차의 노출 순서를 드래그 또는 번호 입력 방식으로 변경할 수 있습니다.
미리보기 영상 설정 ★★★★ 결제 전에도 볼 수 있는 무료 맛보기 강의를 지정합니다.
영상 공개 / 비공개 설정 ★★★★★ 검수 전 영상, 오류 영상, 개강 전 영상 등을 수강생 화면에서 숨길 수 있습니다.
영상 교체 기능 ★★★★ 기존 회차는 유지하면서 실제 재생되는 외부 영상 ID만 수정본으로 교체합니다.
영상별 메모 관리 ★★ 자막 확인, 음량 문제, 수정본 교체 여부 등 내부 운영 메모를 저장합니다.
