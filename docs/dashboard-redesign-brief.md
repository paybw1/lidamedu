# 리담변리사학원 학생 대시보드 리디자인 브리프

> **Claude Design 핸드오프용.** 이 문서를 claude.ai/design 의 `리담 디자인 시스템`(lidam-design-system) 프로젝트에 전달해 `/dashboard` 화면의 UI kit 를 만들기 위한 명세다. 콘텐츠·정보 구조·데이터·제약은 이 문서가 확정하고, 시각 디자인(레이아웃 디테일·간격·모션)은 디자인 시스템 토큰을 따른다.
>
> **앞선 작업과의 관계** — 같은 프로젝트의 랜딩 페이지(`ui_kits/lidam-web/`)는 이미 Wantedly 기반 **딥 로열블루 `#2D5BA8`** 디자인 시스템으로 완성됐다. 대시보드도 **같은 디자인 시스템**으로 통일한다. 콘텐츠 브리프는 `uploads/landing-redesign-brief.md` 와 이 문서 두 개가 된다.

## 0. 산출물 한 줄

> 변리사 수험생이 로그인 직후 보는 학습 허브. **"오늘 무엇을 학습할지", "합격까지 얼마나 왔는지", "내 약점은 어디인지"** 세 가지를 한 화면에서 답한다. 새 UI kit: `ui_kits/lidam-dashboard/`.

## 2. 핵심 목적 — 대시보드가 답해야 하는 3가지 질문

리디자인의 모든 레이아웃 결정은 아래 3가지 우선순위를 따른다.

1. **"오늘 뭘 해야 하지?"** — 이번 주 커리큘럼 트랙, 마감 임박 과제, 자동 추천 액션. *진입 즉시 가장 먼저 눈에 들어와야 한다.*
2. **"합격까지 얼마나 왔지?"** — 합격 진단 점수, 합격자 데이터 대비 비교(USP). *리담변리사학원의 유일한 차별점 — 시각적으로 강조.*
3. **"내 약점은 어디지?"** — 약점 우선 복습, 약점 단원, 과목별 진도.

그 외(학습 패턴 히트맵, 재학습 진입점, 최근 피드)는 보조 정보로 하단 배치.

## 3. 디자인 방향

### 3.1 톤

> "잘 정돈된 분석 도구" — 학구적·신뢰감·차분함. 데이터가 많지만 위계가 또렷해 한눈에 스캔된다. 화려함보다 정돈됨.

### 3.2 색 · 타이포 · 형태 (디자인 시스템 SSOT 그대로)

- **색**: `colors_and_type.css` 의 Wantedly 토큰. 전경은 black-with-alpha(`rgba(0,0,0,α)`), 브랜드는 딥 블루 `#2D5BA8` 계열. cozy sage 팔레트는 **쓰지 않는다**.
- **타이포**: Pretendard 단일. 숫자(시간·정답률·점수·D-day)는 `tabular-nums` 필수.
- **형태**: 8pt 그리드. 카드 radius `R4`(작은 카드)~`R16`(히어로/큰 패널). pill 버튼·chip(`R100`). 2-layer 중성 그림자(`--elev-4` 카드 기본, `--elev-8` hover).
- **모션**: 진입 reveal `cubic-bezier(0.22,1,0.36,1)` 600ms, 인터랙션 120~240ms. 숫자는 count-up. `prefers-reduced-motion` 존중.

### 3.3 데이터 시각화 톤

- 도넛/막대/히트맵/게이지는 모두 **블루 단색 계열의 명도 단계**로. 다색 차트 지양.
- 합격자 비교 등 "좋음/나쁨" 신호만 의미색 사용: 앞섬=`#10A37F`(에메랄드), 뒤처짐=`#F65948`(코랄), 경고=`#F7B500`(앰버).
- 히트맵: 블루 5단계 명도(현재 cozy 톤 → 블루로 교체).

## 4. 레이아웃

### 4.1 셸 구조

현재 구조(좌측 사이드바 + 메인)를 **유지·재디자인**한다. 위젯이 23개로 많아 사이드바 내비게이션이 적합.

```
┌─────────┬──────────────────────────────────────┐
│         │  Topbar — 검색 · 알림벨 · 프로필       │
│ Sidebar ├──────────────────────────────────────┤
│ 240px   │  Main (스크롤)                        │
│ 고정    │   인사말 + D-day                      │
│         │   [위젯 그리드 — §5 정보 구조]         │
└─────────┴──────────────────────────────────────┘
```

- **사이드바**: 로고 + 7개 메뉴(대시보드/학습관리/학습과목/학습보조/학습정보/커뮤니티/운영자 — 라벨은 `landing-redesign-brief.md` §4 와 동일). 디자인 시스템 블루 톤. 활성 메뉴 강조.
- **탑바**: 전역 검색(⌘K), 알림 벨(미읽음 뱃지), 프로필 메뉴.
- **메인**: 반응형 그리드. 데스크톱 3열 → 태블릿 2열 → 모바일 1열.

> 디자이너 재량: 사이드바를 접을 수 있게(collapsible) 하거나, 모바일에서 시트(Sheet)로 전환하는 것은 권장하되 필수는 아님.

### 4.2 그리드 원칙

- 컨테이너 최대폭 `1280px`, 좌우 거터 24px.
- 카드 간 간격 16px(8pt grid의 2배).
- 큰 카드(합격 진단·이번 주 트랙)는 2~3칸 span, 작은 위젯은 1칸.

## 5. 정보 구조 — 위젯 23종을 9그룹으로 재정리

현재 대시보드는 위젯 23개가 위→아래로 길게 나열돼 있다. 리디자인에서는 **§2 우선순위에 따라 9그룹으로 묶고**, 중요 그룹을 상단에 둔다. 그룹 순서는 아래를 따른다.

### A. 헤더 (항상 최상단)
- **인사말** — "어서오세요, {이름}님" + 오늘 날짜(한글) + 기수("27기 · 1차 준비")
- **D-day 배지** — "D-{N}" + "1차 시험까지". 큰 숫자, 브랜드 블루.

### B. 오늘 할 일 (우선순위 1 — 상단 강조 배치)
- **이번 주 트랙** (`WeekTrackCard`) — "W{N}/{전체}" 주차 + 커리큘럼 항목 리스트. 항목별 완수 체크 + 학습 화면 진입 링크. cohort 멤버만 노출.
- **마감 임박 과제** (`PendingAssignmentsBanner`) — 진행 중 과제 top 3. 제목·마감일·진행도 막대.
- **자동 추천 액션** (`RecommendedActionsCard`) — AI 생성 action 카드 최대 5개. priority 4단계(high/medium/low/celebrate) 색상 + 아이콘 + CTA + metric chip.

### C. 합격 진단 (우선순위 2 — USP, 시각적으로 가장 강조)
- **합격 진단 점수** (`PassPredictionCard`) — 0~100점 게이지 + rating 4단계(안정 80+/가능 60+/주의 40+/취약) + 구성 요소 막대 + 한 줄 hint. **대시보드에서 가장 큰 단일 카드.**
- **합격자 벤치마크** (`PasserBenchmarkCard`) — 합격자 평균 vs 본인: 5지표(학습 시간·총 풀이·정답률·활동 일수·최장 연속). 지표별 본인값/합격자평균/차이(±, %)/분위. 앞섬=에메랄드, 뒤처짐=코랄 chip. "12주 곡선 →" 링크.
- **합격자 후기** (`PasserSummariesPreview`) — 익명 합격자 후기 3건. 연도·점수 버킷·인증 chip·후기 발췌.

### D. KPI 요약 (우선순위 1~2 — 상단 가로 띠)
3개 stat 칩을 한 줄로:
- **누적 풀이 시간** — 총 시간 + 지난주 대비
- **푼 문제 수** — 총 문항 수 + 지난주 대비
- **평균 정답률** — % + 기준 문항 수

### E. 진도 (우선순위 3)
- **전체 학습 진척도** — 도넛 3개: 조문·판례·문제 (각 visited/total + %)
- **오늘의 진척도** — 오늘 학습 시간 진행 막대 + streak 배지 + 연속 학습일
- **과목별 진도** — 법률 5과목(특허법·상표법·디자인보호법·민법·민사소송법): 진도율 막대 + 정답률
- **자연과학 진도** — 1차 필수 4과목(물리·화학·생물·지구과학): 진도 막대. 아직 학습 기록이 없는 과목은 dim.

### F. 약점 (우선순위 3)
- **약점 우선 복습** — 오답 top 5. 문제 내용·난이도·전역 정답률. 클릭 시 문제 진입.
- **약점 단원 (체계도)** — 정답률 낮은 단원 4개. 과목·정답률·시도 회수. 각 행에 합격자 평균 대비 hint chip("합격자 평균 N회 · M% · +K회 더 풀어 보세요").

### G. 학습 패턴 (보조)
- **학습 히트맵** — 12주 × 7일 격자. 일별 학습 강도 블루 5단계. 범례 + 통계.
- **이번 주 학습량** — 7일 세로 막대 차트(시간 단위). 오늘 막대 강조.

### H. 재학습 진입 (보조)
- **재학습 진입점** — 4개 칩: 오답노트·즐겨찾기·메모·하이라이트 + 각 카운트.
- **즐겨찾기 빠른 접근** — 별점 높은 즐겨찾기 8개(조문/판례/문제). 태그 형태, 별점 표시.

### I. 최근 피드 (보조 — 하단)
- **최근 학습** — 최근 활동 12건(조문/판례/문제 통합). 타입별 색상 + 날짜.
- **신규 법 개정** — 최근 개정 5건. 법명·개정 번호·영향 조문 수.
- **최근 판례** — 최근 판례 5건. 판례명·판결일·본문 발췌.

> **조건부 노출**: C 그룹 전체, 이번 주 트랙, 마감 임박 과제는 데이터/표본이 없으면 카드를 숨기거나 "표본 부족 / 계획 미설정" 안내 배너로 대체. 디자이너는 **빈 상태(empty state) 디자인도 함께** 제공할 것 — 현재는 회색 안내문 한 줄뿐이라 개선 여지가 크다.

## 6. 위젯 디자인 가이드

- **카드 한 장 = 한 가지 질문에 답**. 제목(eyebrow 또는 굵은 헤딩) + 본문 + 선택적 CTA.
- **합격 진단 점수 카드**는 예외적으로 크게 — 게이지/점수가 카드의 주인공. 진입 시 점수 count-up.
- **숫자 강조**: KPI·점수·D-day·정답률은 Pretendard 800 ExtraBold + tabular-nums. 라벨은 작게.
- **차트는 절제**: 도넛·막대·히트맵 모두 블루 단색 명도 단계. 축·범례 최소화.
- **진입 링크**: 위젯의 항목은 대부분 클릭 시 학습 화면으로 이동 — hover 시 행 강조 + 화살표.
- **그룹 헤더**: 9그룹 각각에 작은 섹션 라벨(uppercase Latin eyebrow — `TODAY`, `PASS FORECAST`, `PROGRESS`, `WEAK SPOTS`, `ACTIVITY` 등)을 두면 긴 스크롤에서 위치 파악이 쉬움.

## 7. 애니메이션

- 카드 진입: in-view fade-up(opacity+translateY) stagger. `prefers-reduced-motion` 시 즉시.
- 숫자: count-up (KPI·진단 점수·D-day·정답률).
- 막대/도넛/게이지: 0 → 목표값 채워지는 transition (800ms 내외).
- 히트맵: 셀이 좌상→우하 wave 로 채워짐.
- hover: 카드 lift(`translateY(-2px)` + 그림자 강화), 행 강조.

## 8. loader 데이터 (구현 참고 — 디자인 시 데이터 형태 파악용)

대시보드 loader 가 18개 병렬 쿼리로 반환하는 데이터:

| 키 | 내용 |
|----|------|
| `user` | 이름, 기수 라벨 |
| `todayLabel` | 오늘 날짜 한글 포맷 |
| `goals` | 시험일(examDate), 주간 목표 시간 |
| `kpis` | 누적 풀이 시간, 총 문제 수, 평균 정답률, 각 지난주 수치 |
| `dailyStats` | 84일 일별(date·timeMs·attemptCount), currentStreak, 총 활동일, 일평균 |
| `overallProgress` | 조문·판례·문제 각 visited/total/pct |
| `subjectsProgress` | 법률 5과목 진도율·시도 문제·정답률 |
| `scienceProgress` | 자연과학 4과목 진도 |
| `weakAreas` | 오답 top 5 (problemId·lawCode·내용·난이도·전역 정답률) |
| `weakNodes` | 정답률 낮은 단원 4개 (nodeId·lawCode·정답률·시도 회수) |
| `topBookmarks` | 별점 높은 즐겨찾기 8개 (targetType·label·starLevel) |
| `passPrediction` | 합격 진단 — 점수 구성 요소(조문·문제·정답률·GS평균·streak·14일 활동·미완 과제 수) |
| `passerBenchmark` | 합격자 평균 5지표 (학습 시간·풀이·정답률·활동일·최장 streak) |
| `passerSummaries` | 합격자 후기 3건 (익명·결과 연도·점수·인증) |
| `passerLawAverages` | 법과목별 합격자 평균 |
| `recommendedActions` | 자동 생성 권장 액션 (priority·tone·아이콘·CTA·metric) |
| `weekTrack` | 현재 주차 커리큘럼 항목 (주차·제목·완료도·진입 링크) |
| `pendingAssignments` | 미완 과제 top 3 (제목·마감일·진행도) |
| `recentActivity` / `recentRevisions` / `recentCases` | 최근 학습 12건 / 법 개정 5건 / 판례 5건 |
| `blankSummary` | 빈칸 학습 통계 (시도·정답·정답률·약점 수) |

> 디자이너는 위 데이터로 채워질 자리에 **현실적인 mock 값**을 넣어 디자인하면 된다. 실제 연동은 코딩 단계에서 처리.

## 9. 절대 수정 금지 / Out of scope

- ❌ DB 스키마·loader 쿼리 — 본 작업은 시각 디자인. 데이터 형태(§8)는 고정.

## 10. 기술 제약 (코딩 단계 참고)

실제 구현은 React Router 7 + TypeScript strict + Tailwind v4 + shadcn + Vercel (Node SSR) 환경. 디자인 mockup 단계에서는 신경 쓸 필요 없지만, 디자인이 아래와 호환돼야 한다:

- 신규 npm 패키지·이미지/폰트 자산 도입 금지 (Pretendard·lucide 는 이미 있음).
- 차트는 외부 라이브러리 없이 SVG/CSS 로 구현 가능한 수준 (현재 도넛·막대·히트맵 모두 자체 SVG).
- 모바일 반응형 필수.
- `prefers-reduced-motion` 존중.

## 11. 우선순위 — 디자이너가 시간을 어디에 쓸지

1. **합격 진단 점수 카드** (C) — USP, 가장 공들일 카드.
2. **이번 주 트랙 + 추천 액션** (B) — "오늘 할 일", 진입 직후 첫 화면.
3. **셸**(사이드바·탑바) + 헤더(A) + KPI 띠(D) — 전체 인상을 좌우.
4. **합격자 벤치마크**(C) — 비교 시각화.
5. 진도(E)·약점(F) 카드군 — 카드 패턴 1~2개 정해 반복.
6. 학습 패턴(G)·재학습(H)·피드(I) — 보조, 일관 스타일로 빠르게.
7. **빈 상태(empty state)** — 각 그룹의 데이터 없는 경우.
