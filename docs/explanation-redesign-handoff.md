# 해설 재구조화·디자인 작업 인수 문서

작성 2026-09-12. 저장소에 `docs/explanation-redesign.md`로 두고 작업 시작 시 함께 읽히게 하세요.

이 문서는 **확정된 것과 확정되지 않은 것을 구분**하는 것이 목적입니다. 5절과 6절을 먼저 읽으세요.

---

## 1. 배경

변리사 시험 대비 플랫폼의 생성 해설을 스키마 필드로 재구조화하고, 그 구조에 맞는 해설 컴포넌트를 다시 설계하는 작업입니다.

출발점은 디자인 개선이었으나, 생성 텍스트가 길이와 구조를 통제받지 않으면 컴포넌트를 설계할 수 없다는 것이 드러나 순서가 바뀌었습니다. 감사 → 재구조화 → 디자인 순입니다.

---

## 2. 실측 사실 (2026-09, 노출 해설 1,622건)

전체 4,276건 중 소프트삭제 2,654건을 제외한 수치입니다. 삭제분을 포함하면 모든 지표가 무의미해집니다.

| 과목 | n | 평균 | p50 | p95 | p99 | max | 조문 | 판례 | 긴인용 |
|---|---|---|---|---|---|---|---|---|---|
| 민법 | 680 | 303 | 295 | 467 | 537 | 648 | 95.4% | 90.7% | 0.9% |
| 자연과학 | 679 | 382 | 371 | 581 | 664 | 793 | 0.1% | 0% | 1.0% |
| 특허 | 208 | 286 | 160 | 871 | 2,634 | 3,650 | 26.4% | 5.8% | 7.2% |
| 디자인 | 31 | 277 | 225 | 724 | 1,234 | 1,423 | 41.9% | 0% | 9.7% |
| 상표 | 24 | 623 | 582 | 1,371 | 1,511 | 1,551 | 83.3% | 37.5% | 33.3% |
| 전체 | 1,622 | 338 | 321 | 578 | 929 | 3,650 | 45.5% | 39.3% | 2.4% |

기타 실측:

- 구조 마커(`결론`+`근거` 동시 보유) 0.1% → 백필 불가, 재구조화 필요
- `함정|주의|유의` 보유 12.5% (자연과학 23.1%)
- 문단 수 p95 = 3 · 조문 인용 p95 = 6개 · 판례 인용 p95 = 5개
- 100자 미만 75건(4.6%) · 20자 미만 40건

**감사 결과: 확인된 환각 0건.** 26종 표본 조회에서 전부 실재였고, 미대조 223건 중 상당수는 조회 도구의 한계(법령정보센터 `OC=test` 커버리지 제한, casenote 빈 응답)입니다. 두 공개 DB에 없는 것과 실재하지 않는 것은 다릅니다.

## 3. 확정된 결정

### 3-1. 콘텐츠 처리

| 과목 | 처리 | 근거 |
|---|---|---|
| 민법 680 · 자연과학 679 | 재구조화 | 파일럿 30건 통과 100%, 인용 보존 30/30 |
| 특허 208 | **미확정** — 4절 참조 | p50 160 / p99 2,634. 이봉 의심 |
| 디자인 31 · 상표 24 | 재구조화 후 판단 | 양이 적어 개별 확인 가능 |

재구조화는 **내용을 새로 만들지 않습니다.** 기존 본문을 필드로 쪼개기만 하고, 검증은 조문·사건번호 집합이 입력과 완전히 일치하는지 봅니다.

### 3-2. 필드 스키마

| 필드 | 성격 | 비고 |
|---|---|---|
| `conclusion` | 필수, 추출 | 정답 판단. `unsplittable`이면 null |
| `reasoning` | 필수, 추출 | 조문→요건→적용→판례 순 |
| `statute_refs` | 배열, 추출만 | 입력 집합과 일치 검증 |
| `case_refs` | 배열, 추출만 | 동일 |
| `distractor` | 선택, nullable | **구 `pitfall`에서 개명** |
| `unsplittable` | 불리언 | 분할 불가 표시 |

`pitfall` → `distractor` 개명은 확정입니다. 필드명이 모델을 「함정」이라는 낱말로 유도했고 검증기도 그 낱말을 찾다가 정상 출력 6건을 실패 처리했습니다. 실제 내용은 오답 선지 분석이므로 이름을 고치면 낱말 매칭 검증이 불필요해집니다.

### 3-3. 파이프라인 순서

```
① 재구조화 (모델)      표기 보존. 내용 불변
② 표기 정규화 (정규식)  조문·판례·용어 통일. 모델 미사용
③ 문체 검증 (정규식)    금지 패턴 검출. 경고
④ 표본 육안 확인
```

**①과 ②를 합치면 안 됩니다.** 같은 패스에서 표기를 통일하면 ①의 집합 일치 검증이 무력해집니다.

### 3-4. 디자인

- **각주형 확정.** 우측 인용 레일 폐기 — 본문 폭을 눌러 명조 조판이 죽음
- 라벨은 `참조조문` / `참조판례` (판결문 관습)
- 각주 칩 상한 없음. p95 전량 표시
- 본문 인용: **조문 실선 밑줄, 판례 점선 밑줄.** 흑백에서 구분 유지
- 접기 임계 과목별: 민법·자연과학 800자 / 특허·상표·디자인 1,200자
- 본문 인용 ↔ 각주 칩 양방향 강조
- 서체: 본문 명조(Noto Serif KR) / UI 고딕(Pretendard)
- 색: 조문 감색 `#1F3A5F` / 판례 주색 `#8E2B26`
- 판례 검증 상태 3단: 확정 ● / 미확정 ○ / 미검증 ◌

### 3-5. v1/v2 공존

구조 마커가 0.1%라 전환 기간 동안 통짜(v1)와 스키마(v2)가 함께 노출됩니다. 해설 컴포넌트는 **두 렌더링 경로를 모두 갖고, 시각적으로 크게 달라 보이지 않아야** 합니다. 나중에 붙이면 폴백이 항상 못생겨집니다.

원본 `explanation_md`는 덮어쓰지 않습니다.

## 4. 즉시 실행 가능한 작업

우선순위 순입니다. 각 항목은 독립적으로 실행 가능합니다.

### A. 특허 208건 분포 확인 (SQL, 읽기 전용)

세 쿼리입니다. 결과에 따라 처리 방침이 갈립니다.

1. 길이 5분위 × 조문 보유율 — 이봉 여부와 원인
2. 100자 미만·20자 미만 건수 — 부실 해설이 특허에 몰렸는지
3. 월별 생성량과 평균 길이 — 프롬프트 버전 차이인지

가설: 짧은 무리(p50 160 이하)는 내용 자체가 부족해 재구조화 대상이 아니고 재생성이 필요합니다. 긴 무리는 민법과 같은 경로로 갑니다. 3번이 갈리면 원인이 콘텐츠가 아니라 파이프라인이므로 처방이 완전히 달라집니다.

### B. `pitfall` → `distractor` 개명

`source/restructure-explanations.mjs`의 프롬프트와 `validate()` 양쪽. 낱말 매칭 검증(`/(함정|주의|유의)/`)을 제거하고 선지 번호 존재 여부로 대체합니다.

### C. `subject` 매핑

현재 프롬프트 첫 줄이 `과목: civil`로 나갑니다. `law_code` → 한글 과목명 매핑이 필요합니다. 민법 단일 과목에서는 영향이 없었으나 전량에서는 과목별 인용 밀도가 크게 달라 맥락이 필요합니다.

### D. `CASE_MARKS` 단일 소스화

`scripts/lib/content-rules.mjs`와 `app/features/cases/lib/citation-guard.ts`에 사본이 둘 있고 이미 어긋나 있습니다(`카`가 스크립트에만 존재). 생성 단계 차단기가 해당 번호를 사건번호로 인식하지 못합니다.

번들 경계 때문에 공유가 어려우면 최소한 두 사본이 다를 때 실패하는 테스트를 넣으세요. 표기 정규화 함수도 같은 곳에 두어야 합니다.

### E. `verifyCaseNumber` 빈 응답 판정

응답 크기로 빈 껍데기를 구분할 수 있습니다. 실제 결과가 있는 조회는 88KB 수준, 빈 껍데기는 7.8KB 수준입니다. 임계값을 두면 판정이 **실재 / 부재 / 조회불가** 3단이 됩니다.

지금 223건이 못 쓰게 된 원인이 부재와 조회불가를 같은 칸에 넣은 것입니다.

### F. `\s` 오타

`verify-case-numbers.mjs`의 재시도 경로에 `replace(/s/g, "")`가 있습니다. 공백 없는 번호에는 무해하지만 공백이 들어오면 조용히 실패합니다.

### G. 컴포넌트 구현

`explanation-tokens.css`와 `explanation-components.md` 기준. `drafts` 테이블이 자연과학 스테이징으로 보이므로 거기서 먼저 시험하는 것이 안전합니다.

## 5. 원장 판단 대기

**조문 띄어쓰기.** 법제처는 `제33조제1항` 붙여쓰기가 표준이고 판결문·수험 교재는 `제33조 제1항` 띄어쓰기입니다. 문서는 후자로 잡았으나 **리담 교재 표기가 기준이어야 합니다.** 교재와 플랫폼이 다르면 통일 안 한 것보다 나쁩니다.

**용어 통일 목록.** 문서에 예시 4개만 있습니다. 실제 목록은 교재에서 나와야 합니다.

**교재 대조 7종.** `2011다108085 · 2011다15469 · 2011후2737 · 2011후3727 · 2017다245789 · 2019도14180 · 2021다257968`. 자동 판정 수단이 없고 교재 대조가 유일한 확정 방법입니다. 여기서 실제 환각이 나오면 156종으로 범위를 넓힙니다.

**상표 1,371자가 적정한가.** 민법의 3배입니다. 접기로 대응했으나 해설 자체가 긴 것일 수도 있습니다.

## 6. 하지 말 것

- **`--publish` 실행 금지.** 223건을 큐에 넣으면 대부분 오탐이라 검수 큐가 못 쓰게 됩니다
- **`cases`(판례 서술)를 `--verify` 스코프에서 제외.** 단, 삭제가 아니라 분리입니다. 표본 20종 중 FAIL 2건이 전부 판결문 원문 출처였고 오탐률 10%입니다. 제외 근거는 「이 소스는 안전하다」가 아니라 「현재 공개 DB로는 판정 불가」이므로 초안 생성 방식이 바뀌면 다시 켜야 합니다
- **원본 `explanation_md` 덮어쓰기 금지.** v1/v2 공존이 필요합니다
- **재구조화에서 표기 정규화 금지.** 3-3 참조
- **`허`·`후` 부호를 출처맹점으로 제외 금지.** 실측 결과 두 소스 모두 해당 부호를 갖고 있고, 확인된 환각 3건 중 2건이 이 부호였습니다. 가장 위험한 쪽을 가리게 됩니다
- **빈도로 환각 판정 금지.** `recurring`이 58종뿐이라 이 코퍼스에서는 단독 출현이 정상입니다. 빈도 가설은 기각되었습니다
- **커밋 전 확인.** 지금까지 모든 작업이 미커밋 상태입니다

## 7. 폐기된 안 (재논의 방지)

| 안 | 폐기 이유 |
|---|---|
| 우측 인용 레일 | 본문 폭 압박. 조문 6개가 안 들어가 `+n` 접기 필요 |
| 본문 인용 어깨번호 | 명조에 고딕 숫자가 올라가 행간 흔들림. `제450조 제2항³` → `제2항3`으로 읽힘 |
| 본문 인용 바탕색 | 조문 6개면 문장이 칩으로 덮임. 각주 칩과 형태 동일해 위계 소실 |
| 단일 접기 임계 800자 | 상표가 두 문단에서 끊겨 논리 소실 |
| 길이비 검증(실패 처리) | 스키마가 의도적으로 중복을 만듦(`conclusion`은 `reasoning` 요약). 구조적으로 약한 신호. 경고로 강등 |
| `pitfall` 낱말 매칭 검증 | 객관식 해설의 함정은 오답 선지 분석이고 「함정」이라는 낱말이 안 나옴 |
| 백필(기존 본문 파싱) | 구조 마커 0.1% |
| 크림 바탕 + 세리프 | 생성형 디자인 기본값. 종이 흉내가 이 제품에 불필요 |
