## 1. 조문 — 조문정리 제5판

- 목차 파싱: 268개 조문 전부 `제N조(의M) 【제목】 (★중요도) 페이지` 형태 — **페이지 번호 268/268 확보**. 설계 §11에서 "페이지 포기(3안)"로 출발하기로 했는데, 조문 축은 목차 덕분에 **1안급 페이지 매핑이 공짜로 성립**한다.
- DB 대조: 교재 268개 전부 DB `articles`(patent, 조 레벨 298개)와 일치. DB에만 있는 30개는 **전부 "(삭제)" 조문** — 교재가 삭제 조문을 생략한 것으로 완전 정합.

## 2. 판례 — 판례 제10판

- 항목 헤더("법원 + 선고일 + 사건번호 + 판결 【사건명】" 단독 문단) 723개 추출 → 고유 사건번호 **362개** (한 판례가 여러 절에 재수록되는 체계라 헤더 수 > 고유 수. 첫 등장 순서를 수록 순번으로 사용).
- DB 대조 (특허 판례 383건): **361건 직접 매칭**, 교재에만 1건, DB에만 22건.
- **교재에만 1건 = 제10판 오기 확정**: 교재 "2017다245789" → 법령정보센터에 0건, "2017다2457**98**"(대법원 2019.1.17 선고)이 실재하며 DB에 수록돼 있음. **역으로 교재 정오표 1호 후보** (Phase 3 발행 시 첫 항목감).
- DB에만 22건의 구성: ① 2026~최근 **최신판례 10건**(제10판 완고 이후 — 차기판 병합 대기, 축C `merge_status='pending'`의 실물) ② 제9판에 있었으나 **제10판에서 빠진 판례** 7건(2019다222782, 2018후12004, 2018다287362, 2014후2061, 2009허351, 93라38, 2023나11078) ③ 기타 2건 + 오기 대응 1건.
- **순서 변화**: 매칭 360건 기준 제9판 `source_seq` 대비 제10판 수록 순서 **역전 45건** — 제9판→제10판에서 부분 재배열됨. `source_seq`를 제10판 순으로 직접 덮으면 원본(제9판 흔적)이 사라지므로, **제10판 순번은 매핑 테이블(sort_key)에 저장**하는 쪽이 안전하다.

## 3. 객관식 — 제20판 (기출Ⅰ·예상Ⅱ)

투입된 hwpx 4개 파일이 `problem_source_docs`의 file_name과 **동일 파일**(기존 시드 원본) — FK 매칭이 이미 살아 있어 재매칭이 필요 없다. 잔여는 기출 미연결 특허 3건(백필 대상)뿐.
