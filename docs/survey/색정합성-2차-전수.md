## 2. 새 차트 팔레트 정합

- **SSOT 확인**: `chart-colors.ts` `scoreBgTone`(성과 emerald→lime→amber→orange→rose, null=`bg-muted-foreground/30`) — 전부 의미 클래스, light/dark 자동.
- **1차 이후 추가분에 신규 차트 없음** — 입력 허브·picker·cohort-weakness·과목별 필드·토글·SecondRoundScores는 폼/리스트/텍스트. 시각화 아님.
- **기존 시각화**: 대시보드 히트맵·막대·약점카드 = `dash.T`(brand blue=var(--primary), 성과 그라데이션은 T accent), 정답률/예측 막대 = `scoreBgTone`. 둘 다 SSOT·dark-safe.
- → **§2 조치 없음.** (dash.T accent hex와 chart-colors는 용도 분리된 이원 SSOT — 의도. 새 차트는 chart-colors 사용 규칙 유지.)

## 3. 판정 카드 색 (시험결과)

- 현재 `FirstRoundVerdict`(result-fields.tsx) + `STATUS_TONE`(my-exam-results.tsx) = **하드코딩 라이트 전용**(`text-*-700 bg-*-50`), 다크 미대응.
- **destructive 토큰 미채택 이유**: 판정은 단일 위험색이 아니라 **다중 의미색**(과락=rose 확정 / 합격권=emerald / 미달=amber / 대기=muted). 코드베이스 표준(chart-colors·dash.tsx·ox-diagnosis 전부)이 `의미색 + dark:` 패턴이므로 **destructive 단색이 오히려 비정합**. → 표준 패턴(`text-*-600 dark:text-*-400`, badge는 `*-50/700 + dark:*-950/300`) 채택.
- 대기(`pending`)·미입력은 `text-muted-foreground`(토큰) 유지.
