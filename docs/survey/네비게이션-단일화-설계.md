## ② 단일 정의(SSOT) 설계

**SSOT = `nav-groups.ts`의 `NAV_GROUP_POOL` 확장.** (이미 사이드바/하단탭이 소비 중·구조 정돈됨. 상단바·목업이 이쪽을 소비하도록 전환.)

1. **풀에 항목 union(누락 복구, 현행 그룹 위치 존중)**:
   - `manage` 그룹에 **OX 약점 진단 `/study/ox-diagnosis`** 추가(상단바에만 있던 것 → 풀로). → 사이드바/하단탭에 복구.
   - 상담코멘트·GS논점추출·판례쟁점훈련은 **이미 풀에 존재**(manage·mock) → 상단바가 풀을 소비하면 자동 복구.
   - 항목 union일 뿐 이동·이름변경·삭제 없음.

2. **표면별 렌더 매핑(같은 풀, 다른 렌더):**
   - **상단바**: 6 드롭다운을 풀 그룹 조합으로 정의하는 매핑 `TOPBAR_LAYOUT`(nav-groups.ts에 신설):
     | 상단바 드롭다운 | = 풀 그룹 조합 | 잠금 area |
     |---|---|---|
     | 학습관리 | today + review + manage | area_study_mgmt |
     | 학습과목 | subjects(SUBJECT_NAV_ITEMS) | area_subjects |
     | 학습지원 | aids | area_study_aids |
     | 학습정보 | info | (없음) |
     | 모의고사 | mock | area_mock_exams |
     | 커뮤니티 | community | (없음) |
     - leading flat = FLAT_HOME(대시보드), trailing flat = FLAT_ADMIN(운영관리, staff). → 현행 상단바 8 top-level 구조 그대로.
   - **사이드바/하단탭**: 현행 `useNavLayout()`(core=today·review·subjects·aids / secondary=manage·info·mock·community) **유지** — 풀 union 반영분 자동 노출.
   - 결과: 두 표면이 **같은 풀**을 소비, 렌더만 다름. (드롭다운 내 순서는 풀 순서를 따르며 미세 차이 가능 — 재분류 아님, 필요 시 풀 항목 순서로 미조정.)

3. **목업 `admin-nav-preview.tsx`**: 자체 내장 풀 제거 — (권장) **폐기** 또는 SSOT 풀 import로 전환(④).

> 라벨·라우트·그룹 위치 전부 현행. "정의를 하나로 + 누락 4건 진입점 복구"까지가 이번 범위.
