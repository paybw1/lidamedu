# 랜딩 문체 통일 — 역할 기반 2-레지스터 규칙 (SSOT)

> 랜딩(`/`, `app/features/home/`)의 한국어 카피 종결·마침표를 통일하기 위한 규칙. 결정: **카드·스텝·설명 문장은 서술어+마침표**(2026-06-26 사용자 승인). 원칙은 "전부 한 스타일"이 아니라 **역할마다 한 규칙**.

## 두 레지스터
- **라벨 레지스터** — 개조식(체언·명사구 종결), **마침표 ✗**. 짧고 명사형.
- **문장 레지스터** — 서술어 종결(`~합니다`/`~해요`/`~습니다`), **마침표 ✓**. 완결문.

## 규칙 표 (역할 → 종결 → 마침표)

| 역할 | 레지스터 | 종결 | 마침표 |
|---|---|---|---|
| eyebrow·배지·칩·태그 | 라벨 | 체언·명사구 | ✗ |
| 섹션 제목(heading) | 라벨 | 브랜드 보이스(서술어/체언 혼용 허용) | **✗ (고정)** |
| 카드·스텝 항목 **제목** | 라벨 | 체언·명사구(개조식) | ✗ |
| 소제목·설명 문단(subheading/body) | 문장 | 서술어 | ✓ |
| 카드·스텝 항목 **설명** | 문장 | 서술어 | ✓ |
| 버튼·CTA | 라벨 | 명사구·명령형 | ✗ |
| 통계·숫자 라벨 | 라벨 | 명사구 | ✗ |
| FAQ 질문 | — | `~나요?` | ✗ (물음표) |
| FAQ 답변 | 문장 | 서술어 | ✓ |

**핵심 한 줄**: *제목은 라벨(개조식·무마침표), 설명은 문장(서술어·마침표).*

### 보충 규칙
- **제목 마침표 금지**(예외 없음). 서술어 제목(`~함께 해요`)도 마침표 안 붙임 — 브랜드 보이스는 보존하되 마침표만 통일.
- 문장 레지스터에서 **끝 어절이 체언인 명사구 마무리**(예: `…나아가는 감각.`)는 가급적 서술어로(`…나아가요.`) — 단, 의미/리듬을 해치면 마침표는 유지하고 끝만 서술어화.
- 한 문자열이 두 문장이면 **각 문장마다** 규칙 적용(서술어+마침표).
- 서술어 종결인데 마침표 누락된 곳은 마침표 보충.

## 예외 (규칙 미적용)
- **미리보기 mock UI 인-월드 텍스트** — 실제 화면을 흉내 낸 가짜 UI(`어서오세요, 지원님 ☕`, mock 대시보드 라벨/스탯, 예시 카드 본문). 화면 캡처처럼 취급, 손대지 않음.
- **실데이터·고유명사** — 과목명, 날짜(`2026.01.15.`), 사건번호, 가격, `D-87`, `STEP 1` 등.
- **영문 eyebrow** — `WHY LIDAM`, `HOW IT WORKS`, `SUBJECTS` 등.
- **FAQ 물음표** — 질문은 `?`로 끝나고 마침표 없음(규칙대로).

## 적용 대상(주요 변경)
1. 제목 마침표 1곳 제거 — `preview-section.tsx` `…또렷해집니다.` → 마침표 삭제.
2. 카드·스텝 **설명** 서술어+마침표 통일 — `features-section`(체언 꼬리)·`passer-stats-section`(축 설명 개조식·기능 설명 명사구)·`flow-section`(꼬리 정리). `subjects-section`은 이미 서술어+마침표(유지).
3. 서술어 마침표 누락 보충 — `passer-stats-section` CTA 보조문 등.
4. 보조 CTA 통일 — `final-cta` `이미 계정이 있어요` → `로그인`(Hero와 일치).
5. eyebrow·통계 라벨·가격 includes·FAQ — 이미 규칙 일치(무변경).

## 유지보수
새 랜딩 카피는 이 표를 따른다. 같은 역할은 같은 레지스터로.
