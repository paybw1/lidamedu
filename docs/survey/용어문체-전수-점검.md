## 0. 한눈에 (요약)

- **용어**: 같은 개념을 화면마다 다르게 부르는 클러스터 **20+**. 가장 심한 3곳 — ① `mcq_packs` 객체 = **문제집/팩/모의고사** 3중 + 시험/통합/교시, ② **"회차" 동음이의**(내 시도 / 공식 시험회차 / 퀴즈세션), ③ **주석 4중**(포스트잇/메모/코멘트/해설). 더해 staff 호칭 4종·사용자 호칭 6종·브랜드명 3종.
- **설명 갭**: ★약점 진단·SRS·보완 흐름은 **매트릭스(`ox-diagnosis-view`)만 모범**, 나머지(대시보드 약점카드·SRS 원리·"다음 한 주" 보완 플랜)는 근거·개념 설명 부족. 통계/전문어(글로벌·백분위·z-score·과락·지식종류·통합본·rubric) 무설명. **내부어·미완성·영어 노출** 다수.
- **문체**: 큰 틀은 일관(평서 `~합니다` + 권유 `~하세요/보세요` + 라벨 명사형, 반말 0). 흔들림 — 해요체 단발 혼입, **위험 동작↔격식 역전**(데이터 손실에 `~할까요?`), **영어 노출**(account 카드·auth 실패·서버 에러·푸터·meta title).
- **즉시성 높은 모순(§A)**: 비밀번호 6자/8자, 학습데이터 동의 필수/선택, contact 부재인데 "문의하세요" 안내, 법무문서 내부 메모 노출 — 용어/문체와 별개로 빠른 처리 후보.

### 3-1. 관찰된 분포 (지배 패턴)

| 맥락 | 지배 종결 | 격식 |
|---|---|---|
| 설명·안내 문장 | `~합니다 / ~됩니다 / ~습니다` | 중~상 |
| 빈상태 제목 | 명사형 또는 짧은 평서 | 중 |

### 3-2. 흔들림 지점 (대표)

- **해요체 단발 혼입**: "채점은 없고 …읽어보라는 알림이에요"(`srs.tsx:477`), "오답 {N}건이 오답노트에 저장됐어요"(`quiz-result.tsx:158`, 주변 전부 `~습니다`인데 유일 해요체), "…받을 수 있어요/알려드려요"(`qna-new.tsx:239,170`).

### 4-2. 문체 가이드 초안

변리사 수험 = **신뢰감(정중) + 학생 친근(부담↓)**. 관찰된 지배 패턴을 규칙화(대전환 아님, 명문화).

1. **기본 평서 = `~합니다`체** (설명·안내·결과). 신뢰·정중.
2. **행동 유도 = `~해 보세요 / ~하세요`** (빈상태 CTA·도움말). 친근. → 둘의 경계: *상태 서술*은 `~합니다`, *권유*는 `~하세요`.
3. **해요체 단독(`~어요/~에요`) 지양** — 부드럽게 하려면 `~해 보세요`로(예: "저장됐어요"→"저장했어요" 또는 "저장됐습니다").
4. **버튼·탭·라벨·배지·KPI = 명사형** (현행 유지).
5. **confirm 어미 = 위험도 비례**: 비가역·데이터 손실·제출 = **`~하시겠습니까?`**(정중·경각), 가벼운 토글 = `~할까요?`. → §3-2 역전 교정.
6. **호칭 = `{이름}님`**, 이름 없으면 무지칭. **반말 금지**(현행 0 유지). 일반 3인칭 지칭은 "수험생".
7. **영어 금지** — 모든 UI 문자열·서버 에러·meta title·푸터 링크 한글(고유명사/약어 O·X·PDF·GS·AI 제외). eyebrow도 한글 영역명.
8. **전문어 = 첫 노출 1회 풀이/툴팁** (백분위·z·과락·지식종류·통합본·전역→전체). 내부어(보강 대기·분류·rubric·팩·origin·featID·티켓번호) 학생 노출 금지.
9. **이모지 = 환영/축하 1개 한도**, 본문 설명에 남발 금지.
10. **마침표·띄어쓰기 일관**: 완결 문장 마침표 통일, §4-1 표기 SSOT 준수.
