## ② 차수 의존 확인 (보존 필수)

차수(`next_exam_round`, feat-2-025 SSOT)는 stats에서 **탭 이름이 아니라 표시 게이트**로 쓰인다:
- `showFirst = examRound !== "second"` / `showSecond = examRound !== "first"` (stats.tsx:458-459, OverviewTab도 재선언).
- 쓰임: ㉠ **1차/2차 탭 트리거·콘텐츠** 조건 렌더(TabsList·TabsContent), ㉡ **한눈에 1차/2차 카드** 조건 렌더, ㉢ 숨긴 차수 탭 URL 진입 시 폴백(:465-469).
- 섹션 내부 과목 필터: `isFirstExamSubject`/`isSecondExamSubject`(FirstExamTab:1219-1221, SecondExamTab:1440-1442)로 과목 배열을 거른다.

★ **핵심**: 차수는 "1차 통계/2차 통계"라는 **탭 라벨**에 묶여 보이지만, 실제 로직은 **(a) 어떤 차수 탭을 보일지 + (b) 섹션이 어떤 과목을 거를지** 두 가지다. 탭을 학습 종류로 바꾸면 —
- (a) 차수-이름 탭이 사라지므로 **탭 게이트는 제거**.
- (b) 과목 필터(`showFirst`/`isFirstExamSubject`)는 **각 종류 탭 안으로 이동**(진도 탭이 차수에 맞는 과목만, 정답률 탭도 동일). → **SSOT·필터 로직 자체는 안 깨지고 위치만 이동**. 탭 라벨↔분기 분리가 가능.

## ③ 학습 종류 탭 구조 제안

### old → new 매핑 (누락 0)

| 현(차수 기반) 내용 | → 새(학습 종류) 탭 |
|---|---|
| 1차 KPI 시도·정답률 / 법률·자연과학 **정답률** 표 / 2차 평균 자기채점 | **정답률** |
| 1차 ArticlesSection·CasesSection·자연과학 attempted/total / 2차 조문·판례·답안수 | **진도** |
| 1차 약점 표(상위5) + 정오 약점 매트릭스(ox_diagnosis) + 오답큐 KPI | **약점** |
| 빈칸·암기(blanks) | **암기** |
| 한눈에 KPI·마일스톤·합격자 보정·히트맵·추세·WeakReview CTA | **한눈에**(요약 유지) |
| 한눈에 내 1차/2차 표 | → 진도·정답률로 흡수(한눈에선 **제거**, 중복 해소) |

→ **5탭(종류 기반): 한눈에 · 진도 · 정답률 · 암기 · 약점.** (현 5탭과 같은 수, 의미만 종류로.)

### 선택지 + tradeoff

- **(A) 5탭 한눈에·진도·정답률·암기·약점 ★권고**: 종류 분리 명확, 탭 수 동일, 2차 빈 탭 제거. 차수는 진도·정답률 탭 안에서 과목 필터로 흡수. tradeoff: 한눈에의 1차/2차 표를 걷어내야 진도·정답률과 안 겹침(트림 필요).
- **(B) 4탭(한눈에·문제·암기·약점, 진도+정답률 합침)**: 탭 적음. 단 **진도·정답률을 도로 한 탭에** = 지금 1차 탭의 혼재를 재현 → 재구성 취지 약화. 비권고.
- **(C) 6탭(한눈에·진도·정답률·조문판례·암기·약점)**: 조문·판례를 진도에서 분리. 너무 잘게 쪼갬 → 한눈에·진도와 중복·산만. 비권고.

→ **A 권고.** 종류 4축(진도·정답률·암기·약점)이 시험·학습의 자연스러운 갈래이고, 한눈에가 그 위 요약. 2차는 별도 탭 없이 진도·정답률 안에서 차수 필터로 처리(빈 탭 소멸).

### 중복 방지 (한눈에 vs 종류 탭)
- 한눈에 = **요약 전용**(KPI·마일스톤·추세·합격자 보정 + 각 종류로 가는 CTA). **풀 표는 종류 탭 소유**(한눈에의 1차/2차 표 제거).
- 약점: WeakReviewCard(한눈에)는 **CTA만**, 풀 약점(표+매트릭스)은 약점 탭.

## ④ 통폐합 · 디자인 이주(B)와의 관계

- **통폐합 산물 위치(재구성 후)**: 마일스톤·주별 학습시간·합격자 보정 → **한눈에**(요약 성격 유지). WeakReview CTA → 한눈에(CTA) + 약점 탭(본체). 목표 요약 띠 → 헤더 밴드(탭 무관, 불변).
- **B(Surface 51곳 변환)는 탭 재구성 *후*에** — 근거:
  - 재구성은 카드를 **이동·병합·삭제**한다(1차 표→정답률, 조문/판례→진도, 약점 표+매트릭스 병합, 2차 빈 탭 카드 삭제, 한눈에 1차/2차 표 삭제).
  - B를 먼저 하면 **변환한 카드를 곧바로 옮기거나 지우는 헛수고** + 충돌. 재구성으로 **카드 집합을 안정화한 뒤** Surface 변환하면 한 번에 새 구조 기준으로.
  - 즉 **순서: ① 골격(완료) → ② 탭 재구성 → ③ Surface(B)**. (이전 계획의 B를 재구성 뒤로 미룸.)

## ⑤ 단계안 (코드 0 → 결정 후 착수)

1. **차수 필터 추출(무시각 변화)** — `showFirst`/`showSecond` + `isFirst/SecondExamSubject`를 종류 탭 안에서 재사용할 수 있게 섹션 단위로 정리. 동작 동일.
2. **진도 탭 신설** — 조문 학습·판례 학습·과목 진도(객관식 attempted/total·주관식 답안수)를 1차/2차 탭에서 이동, 차수 필터로 과목 거름.
3. **정답률 탭 신설** — 법률·자연과학 정답률 표 + 정답률·시도 KPI(+2차 자기채점) 이동.
4. **약점 탭 통합** — 1차 약점 표 + 정오 약점 매트릭스(ox_diagnosis) + 오답큐를 한 탭으로.
5. **암기 탭** — 현 빈칸·암기 그대로(라벨 "암기").
6. **1차/2차 탭 제거 + 한눈에 트림** — 차수-이름 탭·콘텐츠 삭제, 한눈에의 1차/2차 표 제거(종류 탭과 중복 해소). 차수 게이트는 진도·정답률 안으로 흡수.
7. **(그 다음) B = Surface 51곳 변환** — 안정화된 새 탭 구조 기준으로 한 번에.
- 각 단계 typecheck + 시각 확인 게이트. 차수 필터 보존 회귀 테스트(1차 선택→1차 과목만, 2차→2차, 미선택→둘 다).
