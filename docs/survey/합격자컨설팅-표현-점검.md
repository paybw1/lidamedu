## 3. 코드/구조 vs 문구 (구분 — 유지 대상)

- **(2)의 코드·구조는 유지**: `isPasserBenchmarkEnabled`(fail-closed 게이트), `getPasserBenchmarks`/`getPasserLawAverages`/`getFailerBaseline`/`listPasserSummaries`, viewer-B(pool) 동의, `PassCriterionAnnouncementCard`(게이트 OFF 대체). **데이터 없으면 안 보임/빈 상태/공식 합격선 안내로 대체** — 구현은 해두되 작동은 데이터 후. **이 부분은 점검·수정 대상 아님.**
- **문제는 문구 오버프로미스뿐**: 코드 존재 ≠ 광고. 마케팅·온보딩·가격·하드코딩 통계가 (2)를 **현재 완전 가동**처럼 말하는 것. **코드는 그대로, 문구만 점검 대상.**
- **★문구 vs 데이터 모순 지점**: 랜딩(128명 등)·온보딩(즉시 활성화)은 게이트 OFF 인앱("현재 X/10")과 **같은 사용자가 동시에 보면 어긋남**. 일관 톤 필요(미래/조건형 + 실표본 노출).
