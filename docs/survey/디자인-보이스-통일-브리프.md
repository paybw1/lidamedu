## 0. 대원칙 — 하나의 언어, 두 표면

리담은 두 개의 제품 표면을 가진다.

| 표면 | 성격 | 대표 동선 |
|---|---|---|
| **학습 플랫폼** | 3-pane 독해·풀이 도구 | 조문·판례·문항·학습현황·복습 |
| **강의 플랫폼** | 카탈로그·플레이어 커머스 | 강의 홈·수강신청·영상 재생·강의노트 |

**IA·레이아웃은 표면별로 다르되, 디자인 언어(색·타이포·문체·컴포넌트 규칙)는 완전히 공유한다.**
사용자가 두 표면을 오갈 때 "같은 브랜드"임이 색 한 톤, 글자 한 자에서 느껴져야 한다.

## 1. 진단 — 기반은 튼튼, 갭은 좁다

- `app/app.css`는 라이트/다크·읽기 대비·surface·ink 단계·차트 팔레트까지 갖춘 **성숙한 토큰 시스템**.
- 문체 기준도 확정본 존재(`docs/survey/용어문체-전수-점검.md`, 2026-06-24 확정).
- 프로젝트 자체 색 감사(`docs/survey/색정합성-*.md`)는 **의미색 + `dark:` 쌍 = 정상**으로 결론.

즉 "통일감 결핍"은 전면 리스킨의 문제가 아니라 **몇 곳의 미수렴**이다.

| 상태 | 내용 |
|---|---|
| 양호 | 브랜드 네이비 `#2d5ba8` + 토큰 체계, 의미색+다크 쌍 |
| 실제 갭 ① | `dark:` 변형이 빠진 상태색 클러스터 ~9곳(감사 열거) — 다크 깨짐의 원인 |
| 실제 갭 ② | subjects 트리가 네이비를 `bg-[#2D5BA8]`로 하드코딩(3곳) → 토큰화 |
| 여지 | Pretendard 단일 글꼴 — 계층을 무게·자간으로 더 또렷이 |

## 2. 브랜드 본질 — 권위 · 정밀 · 격

변리사 시험은 법의 정확성으로 승부한다. 화면도 그 태도를 입는다.

1. **정밀함이 먼저** — 조문·판례 원문은 흔들리지 않게. 여백·행간은 가독 도구.
2. **권위는 네이비로** — 딥 로열블루가 시스템의 목소리. 링크·강조·기본 행동은 이 한 색으로 수렴.
3. **격은 금(金)으로, 아끼며** — 금박은 합격·마일스톤·합격자 등 '성취'에만. **1화면 1금.**
4. **조용한 표면** — 그림자 최소, 평면적 표면. UI는 콘텐츠 뒤로 물러선다.

## 3. 색 시스템

모든 색은 **토큰으로만** 소비한다(`bg-primary`·`text-link`·`text-ink-soft`…). 하드코딩 hex 금지.
다크는 같은 hue의 명도만 올려 대응하고, 의미색은 반드시 `dark:` 변형을 동반한다.

### 권위 — 네이비
| 토큰 | Light | Dark | 용도 |
|---|---|---|---|
| Primary | `#2d5ba8` | `#3b6fc4` | 기본 행동·링크·활성 |
| Navy Deep | `#1e4789` | `#9cc0f0` | 그라데이션 끝점·강조 텍스트 |
| Navy Prestige | `#22406e` | — | 강사·합격 등 격 있는 표면(instructor 테마) |

### 격 — 금박 (절제) · 실제 브랜드 gilt 값
| 토큰 | Light | Dark | 용도 |
|---|---|---|---|
| Gilt | `#977224` | `#c9a44e` | 합격·마일스톤·합격자 |
| Gilt Bright | `#b08a35` | `#d8b968` | 금 헤어라인·eyebrow·지표 |

> **금은 accent가 아니라 상(賞)이다.** 버튼·링크·아이콘 기본색으로 쓰지 않는다. 한 화면에 금이 둘 이상이면 과용.
> 중요도 별점 앰버 `#f7b500`와 구분: **앰버=중요도 신호, 금=성취.**

### 바탕 — 슬레이트 뉴트럴 (블루 편향)
| 토큰 | Light | 용도 |
|---|---|---|
| Paper(background) | `#ffffff`/`#fbfcfd` | 앱 바탕(순백 아님, 미세 슬레이트 편향) |
| Surface-2 | `#f8fafc` | 섹션 배경·서브카드 |
| Foreground(ink) | `#2e2e2e` | 본문(순흑 대신 톤다운) |
| ink-soft | `#475569` | 본문 보조 |
| ink-faint | `#94a3b8` | 캡션·메타·라벨 |
| border(hairline) | `#e5e9ef` | 경계·구분선 |

### 의미색 — accent와 분리 (판정/상태 전용, `dark:` 필수)
- **Good**(emerald) — 정답·완료·합격
- **Warn**(amber) — 주의·마감 임박·미납
- **Critical**(red) — 오답·실패·삭제

## 4. 타이포그래피 — 한 글꼴, 계층은 무게·자간

폰트는 **Pretendard 단일 패밀리**로 이미 통일돼 있다(과거 명조 시안을 직접 걷어낸 결정 — 이 문서는 그 결정을 존중한다).
격은 새 글꼴이 아니라 **무게(400·600·700·800)·크기·자간·네이비**로 세운다.

| 역할 | 무게 | 크기 |
|---|---|---|
| Display | 800 | 40 |
| H2 | 800 | 26 |
| H3 | 700 | 19 |
| Body | 400 | 16 |
| Label/Caption | 700 | 13 (대문자 letter-spacing 0.06em, 한글 라벨은 대문자 변환 금지) |

**규칙**
- 타입 스케일 고정: **40 / 26 / 19 / 16 / 13**. 임의 크기 금지.
- 숫자가 줄 맞춰 늘어서는 표·통계 = **tabular-nums** 필수.
- 조문·판례 원문: 행간 1.9 · 본문 배율(`--study-fs`) 존중 · 인용 라벨만 네이비 굵게 · 읽기 폭 62–66자.
- Caveat(필기체, 이미 CDN 로드)는 **환영·축하 1회**에만. 본문 금지.
- **폰트 로딩**: root.tsx `<link>`(CDN: Pretendard·Geist·Noto Sans KR·Caveat). 새 글꼴 도입 시 self-host 여부 결정 필요.

**[선택·별건] 세리프(명조) 재도입** — 헤딩에 세리프를 얹으면 격이 살지만 **과거에 직접 되돌린 결정**이라 기본 권고에서 제외.
원하면 `public/fonts/NanumMyeongjo`(현재 PDF 전용)를 `@font-face`로 얹어 **H1·조문 인용에만** 제한 적용. **명시 승인 후에만.**

## 5. 보이스 & 문체

확정 SSOT: `docs/survey/용어문체-전수-점검.md`.

### 표준 용어 (확정)
| 표준 | 쓰지 않음 | 메모 |
|---|---|---|
| 문항 | 문제/지문(혼용) | 단위·계량 모두 '문항' |
| 학생 · 수험생(3인칭) | 유저/회원 | UI 호칭은 `{이름}님`, 폴백 '학습자' |
| 문제집 | 팩(전면 폐기) | mcq_packs 묶음 |
| 회차 · 시도 · 풀이 | '회차' 남용 | 공식 시험번호=회차 · 내 N번째=시도 · 퀴즈 단위=풀이 |
| 정오문제 | OX(단독) | 안내문 "맞으면 O·틀리면 X" |
| 강의노트 | 강의자료/통합본 | 통합=통합 강의노트 |
| 운영자 · 강사 | 원장/답변자 | 딱 2역할 |

### 어투 (10규칙 핵심)
1. 기본 평서 = **합니다체**(설명·안내·결과). 행동 유도 = **~해 보세요/하세요**.
2. **해요체 단독 지양** — "저장됐어요" → "저장했습니다".
3. 버튼·탭·라벨·배지·KPI = **명사형**("저장하기" ✗ → "저장" ✓).
4. 확인 어미 = **위험도 비례**: 비가역·삭제 = "~하시겠습니까?" · 가벼운 토글 = "~할까요?".
5. 호칭 = `{이름}님`, 없으면 생략. **반말 금지.**
6. UI·서버 오류·meta 전부 **한국어**(고유명사·O·X·PDF·GS·AI 예외).
7. 전문어는 첫 노출 1회 풀이/툴팁. 내부어(팩·origin·rubric·featID) 학생 화면 금지.
8. 이모지는 환영·축하 1개 한도, 본문 산재 금지.
9. 오류는 사과·모호함 없이 **무엇이 잘못됐고 어떻게 고치는지**.
10. 사용자 작성 콘텐츠 노출 = 존중하되 `trusted=false`로 XSS 차단.

## 6. 컴포넌트 & 레이아웃 (두 표면 공유)

| 토큰 | 값 | 용도 |
|---|---|---|
| Radius | `--radius 0.65rem` | 카드=lg · 칩=full · 입력=md. 임의 rounded 금지 |
| Elevation | flat + 옅은 그림자 | 강조는 경계·틴트로 |
| Spacing | 4·8·12·16·24·32 | gap 기반 배치, per-element margin 지양 |
| Card | `bg-card` + `border-border` | 1px 경계 + 조용한 그림자, 배경 하드코딩 금지 |

**상태 렌더링 순서(필수)**: `error` → `loading(no data)` → `empty` → `data`.

**배지·칩 3층위 — 섞지 않는다**: 네이비=중립 정보(origin·format·단원) · 의미색=상태(정답·주의·오답) · 금=성취(합격·마일스톤).

## 8. 표면 B — 강의 플랫폼

- **IA**: 사이드바 없는 **상단바 레이아웃**(`lecture.layout.tsx`) — 브랜드 → **플랫폼 스위처** → LectureNav → 장바구니·알림·유저메뉴 → 푸터. 카탈로그는 공개(비로그인 열람).
- **플랫폼 스위처**(`platform-switch.tsx`): 강의↔학습 **2탭 pill**, **전원 노출**(staff 전용 아님), 활성 표면은 pathname 파생(`/lecture*`·`/about*`·`/location`=강의). 활성 탭은 글로벌 토큰(`bg-primary`). → 두 표면을 잇는 **유일한 공유 브랜드 접점**이므로 정체성 일관이 특히 중요.
- **네임스페이스**: `/lecture/*` + `/about*` + `/location`(리담안내가 학습으로 튀지 않도록 lecture.layout 아래 배치).

### 화면 인벤토리 (구축 상태)
| 상태 | 화면 |
|---|---|
| 구축 | 강의 홈(`/lecture/home`) · 수강신청 카탈로그 · 장바구니 · 내 강의실(진도·시청잔량·기기 셀프리셋) · 주문 · 포인트 · 수료증 인쇄 · 도서몰(카탈로그/상세/위시리스트) · 고객지원 · 리담안내(강사·오시는길) |
| 스텁 | 수료증 목록 · 결제내역 · 쿠폰함 (`MyPagePlaceholder`) |
| **미구축(greenfield)** | **학생용 영상 플레이어** — 재생 화면이 없다. 백엔드(재생 grant·시청 하트비트·기기 제한)만 존재하고 내 강의실에 재생 링크도 없음. **공유 언어 안에서 새로 설계** 필요(Kollus/스타플레이어 임베드 · 진도 · 기기 제한 UI). |

### 커머스
카탈로그(강좌·T-pass) · 장바구니 · 결제(Toss) · 쿠폰(장바구니 프리뷰 `preview-cart-coupon`) · 주문/수료 · 도서몰.
DRM 벤더 = **Kollus**(admin `drmProvider` select, 클라 플레이어 미연동). LMS·커머스 화면은 **이미 공유 토큰 클린** — 목표는 리스킨이 아니라 정합 유지.

### 강의 브랜드 정체성 — 3중 중복 통합 (강의 표면 P1)
"프리미엄 학원" 네이비+금박 정체성이 **세 곳에서 각기 다른 hex로** 재인코딩돼 있다:

| 위치 | navy | gilt | 폰트 |
|---|---|---|---|
| instructor-theme `.instr` | `#22406e` | `#977224` | Pretendard |
| 랜딩 `.llx` | `#16294a` | `#9a7526` | 자체 `--lfont` |
| 수료증 인쇄 | `#22406e`(arb) | `#9a7526`(arb) | 자체 font-family |

→ **단일 `prestige` 토큰(prestige-navy + gilt)을 `app.css`로 승격**하고 세 곳이 공유하게. 스위처·LMS는 이미 글로벌 토큰인데 랜딩/수료증만 평행 우주다.

### 레이아웃 규칙 (학습과 다른 점)
사이드바 없음 · 상단바 + **카탈로그 그리드/카드 + 플레이어** 중심. 커머스 카드(가격·CTA·쿠폰·재고·할인)는 상태를 **모양+색**으로. 3층위 배지 규칙(§6)은 강의에도 동일 적용.

## 9. 정리 우선순위
