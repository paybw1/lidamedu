## §0. 마스터 프롬프트 (매 세션 처음 1회)

```
리담변리사학원(대한민국 변리사 시험 학습 SaaS)의 화면을 디자인한다.
아래 디자인 언어를 모든 화면에 일관되게 적용하라.

[브랜드] 권위 있고 정밀하며 '격'이 있는 학원. 과장 없이 또렷하게.

[색 — 토큰 기반, 하드코딩 hex 금지]
- Primary 네이비 #2d5ba8 = 링크·기본 행동·활성 상태(시스템의 목소리).
- 금박 #977224 = '성취'(합격·마일스톤·합격자)에만 아껴서. 한 화면에 금은 한 곳(1화면 1금). 버튼·링크 기본색으로 쓰지 말 것.
- 바탕 = 슬레이트 뉴트럴(배경 #fbfcfd, 서브표면 #f8fafc, 본문 잉크 #2e2e2e, 보조 #475569, 캡션 #94a3b8, 경계 #e5e9ef).
- 의미색은 accent와 분리: 정답/완료=emerald, 주의/마감=amber, 오답/실패=red. 반드시 라이트·다크 양쪽 정의.
- 라이트·다크 both 설계. 다크는 같은 hue 명도 상향.

[타이포] Pretendard 단일 글꼴. 계층은 무게(디스플레이 800·헤딩 700·본문 400)와 크기(40/26/19/16/13)·자간으로. 세리프/명조 쓰지 말 것. 숫자 정렬 표는 tabular-nums.

[문체 — 한국어 단일]
- 기본 평서 = 합니다체. 행동 유도 = ~해 보세요/하세요. 해요체 단독("~됐어요") 지양.
- 버튼·탭·라벨·배지·KPI = 명사형("저장하기"✗ → "저장"✓).
- 확인 어미는 위험도 비례: 비가역·삭제="~하시겠습니까?", 가벼운 토글="~할까요?".
- 반말 금지, 호칭은 "{이름}님". 오류는 무엇이·어떻게 고치는지 명확히.
- 용어 고정: 문항(문제✗) · 학생 · 문제집(팩✗) · 회차/시도/풀이 · 정오문제 · 강의노트 · 운영자/강사.

[컴포넌트] shadcn/ui(New York) + Radix 계승, 아이콘 Lucide. radius 0.65rem(카드 lg·칩 full·입력 md). 평면적(그림자 최소, 강조는 경계·틴트로). 간격은 4/8/12/16/24/32 gap 기반.
배지 3층위 안 섞기: 네이비=중립 정보(origin·format·단원) / 의미색=상태 / 금=성취.

[하지 말 것] 강의 홈·강사 소개의 프리미엄(딥네이비+금박) 룩을 평범한 뉴트럴로 납작하게 만들지 말 것. 랜딩 예시 목업 수치는 데모(실통계 아님). 마케팅식 과장 금지. 법무 문구(약관·개인정보·동의)는 손대지 말 것.
```

## §1. 학습 플랫폼 화면 프롬프트

### 학습현황(대시보드)
```
학생 대시보드 "학습현황". 상단에 오늘의 다음 행동 카드(약점→복습/과제 유도)와 이어서 학습 카드. 아래로 이번 주 진도(합니다체 문장, 예 "진도의 62%를 마쳤습니다"), 약점 단원, 마일스톤. 데이터 없는 신규 학생은 목표 설정 유도 빈 상태. KPI는 명사형 라벨 + tabular-nums.
```

### 조문 뷰어 (3-pane, 반응형)
```
법령 조문 학습 뷰어. 데스크톱 3-pane: 좌=조문/체계도 트리, 중=조문 본문(행간 넉넉, 읽기 폭 62~66자, 본문 크기 조절), 우=학습보조 패널(즐겨찾기·포스트잇·판례·유사문제·정오문제·Q&A 탭). 모바일에서는 좌/우 패널이 Sheet로 전환. 조문 헤더 아래 "이 조문 연결" 배지(판례 N·문제 N·정오문제 N·빈칸 N)로 우측 패널 원클릭 이동.
```

### 문항 러너 (객관식/OX)
```
문제 풀이 화면. 발문 + 선지(객관식) 또는 O/X. 정답 제출 후 정답/해설 공개(정답=emerald, 오답=red). 상단 진행 표시·타이머(선택), 하단 이전/다음. 우측에 같은 조문 유사 문제·판례. 문항 번호는 명사형("12번").
```

### 복습 / 암기 카드
```
복습 허브. "복습"(자동 큐, /study/srs)과 "암기 카드"(직접 넘기는 플래시카드, /srs)는 다른 시스템 — 구분해서. 오늘 복습할 항목 수, 시작 CTA, 남은 카드. 성취(연속 학습일 등)에만 금박 절제 사용.
```

### 운영자 목록(강사·원장)
```
운영자용 데이터 테이블 화면(학생·주문·문항 등). 밀도 높은 표 + 필터/검색 + 상태 배지(의미색). 행 액션. 라이트/다크. 표는 tabular-nums, 상태는 색+모양으로 한눈에.
```

## §2. 강의 플랫폼 화면 프롬프트

> 레이아웃: 사이드바 없는 상단바(브랜드 → 플랫폼 스위처[강의|학습] → 강의 nav → 장바구니·알림·유저). 카탈로그·플레이어 중심.

### 강의 홈 (프리미엄 랜딩)
```
강의 플랫폼 마케팅 홈. 딥네이비+금박의 격조 있는 히어로(캐러셀), 현장강의 일정 스트립, 강사진, 수강 등급(가격), 수강 후기, 리담소식, 도서, FAQ. 프리미엄 학원 톤 — 단, Pretendard 단일 글꼴 유지(세리프 금지), 금박은 강조 포인트에만.
```

### 수강신청 카탈로그
```
강좌 카탈로그(수강신청). 강좌/T-pass 카드 그리드: 썸네일·제목·강사·가격(정가 취소선+할인)·CTA. 재고/할인/마감은 상태 배지(모양+색). 필터·정렬·검색. 담기/바로구매.
```

### 내 강의실
```
"내 강의실". 수강 중 강좌 리스트: 진도율 바, 남은 시청 시간, 재생 CTA, 일시정지 신청, 기기 셀프 초기화. 완강/수료 상태(성취=금박 절제). 빈 상태는 카탈로그 유도.
```

### 영상 플레이어 (신규 설계 · greenfield)
```
강의 영상 재생 화면(현재 미구축, 새로 설계). 중앙 대형 플레이어(Kollus/스타플레이어 DRM 임베드 자리), 하단 진도 바 + 이어보기, 우측 커리큘럼(회차 목록·완료 체크), 배속·화질·자막 컨트롤. 상단에 시청 기기 제한 안내(동시접속/기기 수), 워터마크 고지. 다크를 기본 톤으로(영상 몰입). 합니다체 안내 문구.
```

### 장바구니 / 결제
```
장바구니 + 결제. 담은 강좌/도서 목록(수량·가격·삭제), 쿠폰 적용(대상 금액 할인 미리보기), 합계, 결제 수단(토스/무통장). 확인 어미 위험도 비례("결제하시겠습니까?"). 결제 후 완료·수강 시작 유도.
```
