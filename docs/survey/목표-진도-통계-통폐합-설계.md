## ③ 통폐합 선택지 (A 한 화면 중심 · B·C 대안)

> 세 선택지를 **"어느 라우트를 본체로 두는가(host)"** 로 구분한다. "새 화면"이라도 결국 한 라우트를 본체로 삼고 나머지는 redirect — 본체 선택이 곧 blast radius를 결정한다.
> **6탭 처리(핵심 쟁점)**: 통계는 이미 5탭. 목표를 합칠 때 *읽기 전용 섹션*(마일스톤·합격자보정·12주추세·D-day)은 **한눈에 탭으로 흡수**하면 탭 수 불변. 남는 건 **목표 폼 하나** — 이걸 어디 두느냐가 6탭이냐 아니냐를 가른다.

### 선택지 A — 한 화면 완전 통합 "내 학습 현황" 〔사용자 선호〕

목표+진도+통계를 한 화면으로. 폼 위치 2변형:

- **A-띠 (★이 안을 권고, ⑤ 상술)**: 상단 = **목표 요약 띠**(D-day·차수·전체 진도·"목표 설정" 버튼→**Sheet 폼**) / 본문 = 기존 5탭(분석). 목표 폼은 평소 숨고 편집 시 Sheet. **탭 수 5 유지**.
- **A-탭**: 1번째에 "목표/계획" 탭 신설 → **6탭**. 폼·목표 요약을 탭1에, 분석을 탭2~6에.

| | tradeoff |
|---|---|
| 통합도 | 최고 — 학생이 "내 현황"을 한 화면에서 본다(사용자 목표 충족) |
| 6탭 처리 | A-띠=5탭 유지(폼=Sheet, 읽기섹션→한눈에) / A-탭=6탭(폼=탭1) |
| 동선 | 목표↔분석 이동 없음. 단 A-띠는 D-day 항상 보임 ↔ A-탭은 탭1 안에 묻힘 |
| 화면 비대 | 한눈에가 길어짐(목표 요약 흡수) → 띠로 압축 필요. 폼을 Sheet로 빼면 본문 안 비대 |
| 규모 | 중~대 — 본체 선택(아래)·폼 이전·읽기섹션 이전·nav 병합·redirect |

### 선택지 B — 통계 허브 (stats가 흡수) · host=`/study/stats`

통계를 본체로, `/goals`→`/study/stats` redirect. 표시명 "통계"→"내 학습 현황" rename.

| | tradeoff |
|---|---|
| 통합도 | 높음 — 통계가 이미 분석 5탭 大화면, 목표를 그 위/안에 얹음 |
| **blast radius** | **최소** — stats는 들어오는 redirect 2개(`?tab=ox_diagnosis`/`blanks`)·`?tab=` 딥링크·외부 링크 ~12곳을 이미 보유. 본체로 두면 **이 전부가 무변경**. 반대로 /goals(들어오는 참조 ~10곳, 대부분 nav·대시보드 CTA)는 redirect로 돌리기 **싸다** |
| 6탭 처리 | A와 동일(띠 or 탭) |
| 이름 | "통계"가 목표설정까지 포함 → rename 필요(meta title·nav 라벨) |
| 규모 | 중 — host 유지라 redirect·이전만 |

> ★ **A의 UX 목표는 B의 배관으로 가장 싸게 달성된다**: 새 라우트를 만들지 않고 `/study/stats`를 본체로 두면, "한 화면"이라는 결과는 같으면서 stats의 redirect·딥링크·탭을 한 줄도 안 건드린다. → **권고는 "A-띠 외형 + B host"**(⑤).

### 선택지 C — 목표 허브 (goals가 흡수) · host=`/goals`

목표를 본체로, `/study/stats`→`/goals` redirect.

| | tradeoff |
|---|---|
| 통합도 | 높음(명목) |
| **blast radius** | **최대(비권고)** — stats의 들어오는 redirect 2개 + `?tab=` 딥링크를 **전부 `/goals?tab=…`로 재배선**해야. 50+ SQL 분석 5탭을 설정 화면(goals)에 이식 = goals loader 폭증 |
| 동선 | 설정 화면이 분석까지 떠안아 성격 혼탁 |
| 규모 | 대 — 재배선 많고 위험 높음 |

## ⑤ 권고 — "A-띠 외형 + B host" + 단계안

### 권고 구조 (A의 한 화면 = `/study/stats` 본체)

```
┌─ 내 학습 현황 (/study/stats, 표시명 변경) ───────────────┐
│ [목표 요약 띠]  D-7 · 1차 · 목표 720점 · 전체진도 42%   │
│                                      [목표 설정 ⚙]→Sheet │  ← 폼은 Sheet(시험일·차수·주간목표·목표점수·메모)
├─ sticky 영역 토글(학습관리) ────────────────────────────┤
│ [ 한눈에 | 1차 통계 | 2차 통계 | 빈칸·암기 | 정오문제 약점 ] │  ← 5탭 유지
│                                                          │
│  한눈에 = (기존 분석) + 마일스톤 + 합격자 보정 + 12주 추세 │  ← 목표의 읽기섹션 흡수
│         + 약점→복습 카드(기존)                            │
└──────────────────────────────────────────────────────────┘
/goals → redirect → /study/stats   (북마크·외부링크 보존)
```

- **왜 띠+Sheet**: 시험일·차수·주간목표는 **자주 보지만 드물게 고침**. 요약(D-day·차수·진도)은 띠로 상시 노출, 폼은 Sheet로 빼 본문 비대 회피, 분석 5탭은 본문 그대로 → **탭 수 안 늘고**(6탭 문제 해소) "한 화면" 달성.
- **왜 통계 host**: ③-B — 들어오는 redirect·딥링크·탭이 가장 많은 쪽을 본체로 둬 blast radius 최소.

### 단계안 (안전한 것부터 · 각 단계 독립 배포·검증 가능)

- **1단계 — 겹침 제거** *(위험 낮음, 두 화면·URL·nav 전부 유지)*: goals의 과목별 진도표·진도 3종을 **요약 + "과목별 자세히 → 학습 통계" 링크**로 축소(중복 수치 제거). 누적 학습시간 표시를 한쪽 경로로 통일. → relearn 0, "같은 수치 두 곳" 혼란만 해소.
- **2단계 — 목표 읽기섹션을 통계 한눈에로 흡수** *(read-only만, 폼은 아직 goals)*: 마일스톤·합격자 보정·12주 추세·D-day를 한눈에(또는 상단 띠)로. 통계=분석+목표현황, goals=폼만 남김. 두 화면 여전히 생존, nav 그대로.
- **3단계 — 폼 이전 + 라우트 병합** *(중위험, 최종)*: 목표 폼을 통합 화면 상단 띠 Sheet로 이전 → `/goals`→`/study/stats` redirect → nav manage 두 항목을 **"내 학습 현황" 하나로 병합**(SSOT 1줄) → 표시명 rename → `recommendations.ts` ctaUrl·`study-mgmt-tabs` 매핑 정리. (병행: 한눈에 외 탭 지연 로드로 loader 경감.)
- 각 단계 후 **검증**: `npm run typecheck` + 두 모드(topbar/sidebar) + 모바일 + **모든 진입점 보존 grep**(`/goals`·`?tab=` redirect 유지) + 단계 격리 커밋(`[[nav-consolidation-push-gate]]` 식 — 3단계 완료 전 push=배포 금지).
