## ① 통폐합 대상 정밀 정리

### (가) 중복 — 오답노트 2개
| | `/study/wrong-note` "오답노트" | `/me/ox-wrong-note" "정오문제 오답 노트" |
|---|---|---|
| nav | **aids(학습지원)에 노출** | **메뉴 없음**(my-ox-sessions의 "오답 노트" CTA로만 진입) |
| 데이터 | 객관식 오답(`listWrongAttempts`) + 정오문제 오답(`listOxWrongAttempts`) | 정오문제 오답(`listMyOxWrongNoteItems`) |
| 기능 | **열람·필터·인쇄**(수동 review, StudyAidsShell) | **다시 풀기 러너**(O/X 재응시 → attempt·SRS 기록, action 有) |
> 데이터는 겹치나(둘 다 정오문제 오답) **용도가 다름**: 열람 vs 능동 재풀이. → "삭제 통합"보다 **진입 일원화/교차링크**가 안전.

### (나) 흩어진 사이클 — 정오문제(OX) 한 흐름이 5개 그룹에 분산
- **진단**: 정오문제 약점 진단(`/study/ox-diagnosis`) → **manage(학습관리)**
- **응시**: 1차 모의고사 팩 OX 모드 → **mock**, 과목 OX(`/subjects/:s/ox`) → **subjects**, OX SRS(`/study/srs/ox`)
- **이력**: 정오문제 응시 이력(`/me/ox-sessions`) → **manage**
- **오답**: 오답노트(`/study/wrong-note`) → **aids**, 다시 풀기(`/me/ox-wrong-note`) → 메뉴 없음
- **복습**: OX SRS(`/study/srs/ox`) → **review("복습")**
→ 한 학습 사이클이 manage·mock·subjects·aids·review 5곳에 흩어짐(가장 큰 분산).

### (다) nav 없는 기능 — 합격자 분석 3화면
- `/study/passer-summaries`(합격자 통계) · `/study/passer-trend`(합격자 추이) · `/study/electives-guide`(선택과목 가이드)
- exam-results feature, `/study/*` 라우트지만 **nav 미등재** → 대시보드 합격예측 영역 딥링크로만 도달.
- ★ 사이드바 모드 학생은 도달 경로 없음(1단계서 OX 약점진단이 겪던 문제와 동일 구조).

### (라) 복습 ↔ 암기 카드 — 이미 한 그룹, 문제는 라벨·관계
- review 그룹 = 복습(`/study/srs`, 자동 SRS 큐) + 암기 카드(`/srs`, 능동 플래시카드). **이미 같은 그룹**.
- 문제 1: **그룹 라벨 "복습"** + **항목 라벨 "복습"** 충돌(사이드바에서 "복습" 안에 "복습").
- 문제 2: 암기 카드 화면 내부가 자기 행위를 "복습"이라 칭함(2단계서 보류) → 두 기능 경계 흐림.

### (마) 혼합/catch-all
- **manage(학습관리)**: 목표·진도 / 학습 통계 / 정오문제 약점 진단 / 과제 / 상담 코멘트 / 정오문제 응시 이력 — **성격 혼재**(분석 + OX + 강사상호작용 과제·상담). catch-all 화됨.
- **aids(학습지원)**: 오답노트 + 하이라이트·즐겨찾기·메모·포스트잇 + AI Q&A — 비교적 일관(개인 학습도구)이나 오답노트는 "문제 사이클" 성격.

## ② 묶음 체계(taxonomy) 선택지

출발점: 현행 8개 풀 그룹(today·review·subjects·aids·manage·info·mock·community) + flat(대시보드·운영관리).

### 선택지 A — 현행 그룹 유지 + 항목 재배치·노출만 (최소 변경)
- 그룹 틀 그대로. 변경: ㉠ 합격자 분석 3화면을 manage(학습 통계 근처)에 **추가 노출**, ㉡ 정오문제 사이클은 **약점 진단 허브 + 교차링크**로 연결(이동 X), ㉢ review 그룹 라벨 충돌만 해소.
- **tradeoff**: 학생 친숙도 100% 유지, 위험 최소(거의 추가만). 단 OX 사이클 분산·manage catch-all은 **그대로** 남음(정리도 낮음).
- 영향 범위: nav-groups 항목 추가 5~6줄 수준.

### 선택지 B — 그룹 재구성 (기능 축으로 재편)
예시 축(강요 X): **학습 흐름**(오늘·복습·암기) / **시험·문제**(모의고사 1·2차 + 정오문제 진단·응시·이력·오답 + 판례훈련) / **콘텐츠 열람**(과목 + 법령·판례·논문·정오표) / **학습 분석**(통계 + 합격예측·합격자분석 + 목표·진도) / **학습 도구**(하이라이트·즐겨찾기·메모·포스트잇·AI) / **소통·관리**(커뮤니티 + 상담·과제).
- **tradeoff**: 멘탈 모델 명확, OX 사이클·분석 화면이 한곳에 모임(정리도 높음). 단 **전면 relearn**(모든 학생 근육기억 교란), "어디 갔지?" 위험 최대, 상단바 6드롭다운/사이드바 core+secondary 구조와 재매핑 필요(영향 범위 큼).

### 선택지 C — 하이브리드 (A 먼저 → 부분 B) ★권고
- **A(추가·교차링크·라벨)부터 즉시**(위험 0) → 효과 확인 후 **B를 "명백히 이득인 곳만 부분 적용"**(예: OX 사이클을 시험·문제 축으로 모으기, 합격자분석을 분석 축으로). 전면 재편은 지양.
- **tradeoff**: 위험을 단계로 분산, 큰 이득(분산 해소·노출)부터 회수하고 친숙도 급변은 피함. 단 과도기엔 "A의 임시 배치 → B의 최종 배치" 2번 바뀔 수 있음(해당 항목 한정).

## ③ 기능별 통폐합 옵션 + 권고

### (가) 오답노트 2개
- (a) **완전 통합**: `/study/wrong-note` 정오문제 섹션에 "다시 풀기" 모드 내장, `/me/ox-wrong-note` 흡수. → 한 곳. 단 열람 화면에 러너 결합 = 빌드·위험 ↑.
- (b) **진입 일원화 + 교차링크** ★권고: 둘 다 유지(열람 vs 재풀이로 용도 분리), `/study/wrong-note` 정오문제 섹션에 **"정오문제 오답 다시 풀기 →"** CTA로 `/me/ox-wrong-note` 연결. nav 중복 없음, 두 라우트 보존, 위험 낮음.
- (c) **재풀이를 OX SRS로 흡수**: `/me/ox-wrong-note` → `/study/srs/ox`로 유도. 단 "전체 오답" vs "due 스케줄"로 대상이 달라 의미 손실.

### (나) 정오문제 사이클
- (a) **한 묶음으로 모음**(B 채택 시): 진단·응시·이력·오답을 "시험·문제" 그룹 하위 **정오문제** 소그룹으로. → 사이클 일관. 그룹핑 레이어 추가.
- (b) **약점 진단을 허브화 + 분산 유지** ★권고(A/하이브리드): 항목은 기능 그룹에 두되, 정오문제 약점 진단 화면을 **사이클 허브**로(응시·이력·오답·복습 딥링크 카드). 이동 0, 발견성 ↑. (약점 진단은 이미 단원→체계도 딥링크 보유.)

### (다) 합격자 분석 3화면 — ★노출 필요(현행 사이드바 도달 불가)
- (a) **분석 묶음에 노출** ★권고: 학습 통계 근처(A=manage 안 / B=학습 분석 그룹)에 노출. **개별 3항목 vs 1개 허브("합격자 분석")** 선택 필요 — manage가 이미 6항목이라 **1개 허브 항목**으로 진입 후 화면 내 탭 권고.
- (b) **응시 결과 근처**(mock 그룹, `/me/exam-results` 옆): 합격자 비교 성격상 응시 결과와 인접. 
- (c) **현행 딥링크 유지**: 비권고(사이드바 모드 미도달 지속).

### (라) 복습 / 암기 카드
- (a) **그룹 라벨 충돌 해소** ★권고(필수): review 그룹 라벨 "복습" → **"복습·암기"**(또는 "SRS 학습") 로. 항목은 복습(/study/srs)·암기 카드(/srs) 유지. 사이드바 "복습 안에 복습" 해소.
- (b) **항목 설명으로 관계 명확화**: 복습="자동 일정 복습"(SRS 큐), 암기 카드="능동 플래시카드" meta/desc 부여. 
- (c) **화면 내 "복습" 용어 정리**(2단계 보류분): `/srs`·`/srs/stats`(암기 카드 화면)의 "오늘 복습"·"누적 복습"·"복습 카드" 등 → "오늘 암기"·"누적 암기"·"암기 카드" 로(이 화면 한정). tradeoff: 경계 명확 ↔ "복습"이 플래시카드에도 자연스러운 말이라 과교정 우려 → **부분 적용**(가장 헷갈리는 제목/카운터만) 권고.

## ⑤ 단계적 적용안 (안전한 것부터)

- **3-1차 (위험 0, 추가·링크·라벨)**: ㉠ 합격자 분석 노출(권고: "합격자 분석" 허브 1항목, 학습 통계 근처) ㉡ 오답노트 교차링크(③-가-b) ㉢ review 그룹 라벨 충돌 해소(③-라-a) + 복습/암기 desc(③-라-b). → 이동 0, 입구만 늘거나 라벨만.
- **3-2차 (낮은 위험, 용어)**: 암기 카드 화면 내 "복습" 부분 정리(③-라-c).
- **3-3차 (중위험, 재배치 — B 채택 시만)**: OX 사이클 모으기/분석 축 신설 등 그룹 이동. 항목별 양쪽 노출 과도기 검토.
- 각 단계 후 **검증**: typecheck + 두 모드(topbar/sidebar) + 모바일 + **모든 진입점 보존 grep**(라우트 `to` 유지) + 단계 격리 커밋(푸시는 1~3 묶음).

## ⑥ 결정 포인트 (사용자 선택)

1. **묶음 체계**: A(현행+재배치, 최소변경) / B(전면 재구성) / **C 하이브리드(권고: A 먼저→부분 B)** 중?
2. **합격자 분석 3화면**: 노출 위치 = 학습 통계 근처(권고) / 응시 결과 근처 / 딥링크 유지? 형태 = **1개 허브 항목(권고)** / 3개 개별?
3. **오답노트**: (b) 교차링크(권고) / (a) 완전 통합 / (c) SRS 흡수?
4. **복습/암기**: 그룹 라벨 "복습"→"복습·암기"(권고) 수용? 화면 내 "복습"→"암기" 정리는 (부분 적용 / 전체 / 안 함)?
5. **정오문제 사이클**: (b) 약점진단 허브+분산유지(권고, A/하이브리드) / (a) 한 묶음으로 모음(B)?

> 위 5개를 정해주시면, 그에 맞춰 **3-1차(위험 0)부터** 구현 설계로 넘어갑니다. (코드 착수 전 단계별 승인.)
