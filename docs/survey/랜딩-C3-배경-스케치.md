# 랜딩 C3 — 배경 분위기 스케치 (절제된 깊이)

> 단계: 랜딩 A(구조)·B((2) 보강)·C1(토큰·다크)·C2(명조 제목) 완료 → **C3 = 배경 분위기(마지막)**.
> 이 문서 = **스케치/계획(코드 0)**. 확인 후 구현.
> 기준: `frontend-design` SKILL — "Create atmosphere and depth rather than defaulting to solid colors" + "refined designs need **restraint**, precision". slop의 정의(명시) = *purple gradients on white*. → C3는 **차분·신뢰**의 깊이.

---

## 0. 현황 (왜 평면인가)

- 12섹션 전부 `<section style={{ maxWidth:1200, margin:"0 auto", padding:"72px 24px" }}>` — **배경 없음**. 색은 루트 `home.tsx`의 `background: var(--background)` 하나뿐. → **모든 섹션이 같은 한 톤** 위에 떠 있음 = 평면.
- 내부 카드만 `var(--card)`. **라이트에서 `--card`(#fff) == `--background`(#fff)** → 카드가 배경과 **같은 색**, 오직 `1px border`로만 구분 = 부유감 0.
- 헤더: `SectionHeader`(`align` prop 이미 지원, 기본 `center`)를 **8섹션이 전부 중앙정렬**로 사용 → 7~8회 반복되는 동일 리듬.

### 토큰 실값 (색차 = 절제의 근거)

| 토큰 | 라이트 | 다크 | 용도 |
|---|---|---|---|
| `--background` | `#ffffff` | `#252525` | 페이지 베이스 |
| `--surface-2` | `#f8fafc` | `#2a2a2a` | **주석: "섹션 배경, sub-card"** ← C3 밴드용 |
| `--card` | `#ffffff` | `#333333` | 카드 |
| `--border` | `#e5e9ef` | `rgba(255,255,255,.1)` | |

→ **`background` ↔ `surface-2` 색차 = 라이트 약 2%·다크 약 3% 명도차.** 줄무늬로 인지되기 **직전**의 미묘함. 이 토큰은 **이 용도로 이미 정의**돼 있고 랜딩에서 **미사용**(충돌 없음). 다크 자동(C1 토대).

> **부수 이득**: 라이트에서 흰 카드(#fff)를 `surface-2`(#f8fafc) 밴드 위에 얹으면 카드가 **비로소 떠 보임**(지금 card==bg라 안 뜸). 밴드가 깊이 + 카드 정의를 동시에 해결.

## 1. 섹션 배경 교대 맵 (핵심)

**Tone A = `var(--background)`** (에어리한 캔버스, 기본)
**Tone B = `var(--surface-2)`** (은은한 shelf)

### 권장안 — 잔잔한 교대 (A 시작, 별 섹션이 첫 shelf)

| # | 섹션 | Tone | 근거 |
|---|---|---|---|
| 1 | Hero | **A + wash** | 진입 = 클린 캔버스 + 단 한 곳의 깊이(§2 wash) |
| 2 | **WeaknessEngine ★** | **B** | 차별화 핵심 — 첫 shelf로 "여기가 제품" 신호 + 라이트 카드 부상 |
| 3 | Preview(대시보드) | A | 숨 고르기 |
| 4 | Features | **B** | 카드 4장 — shelf서 부상 |
| 5 | IntegratedFlow | A | |
| 6 | Subjects | **B** | 카드 2장 |
| 7 | PasserStats | A | 이미 자체 카드(그림자)라 **이중 액자 회피**(배경 단순) |
| 8 | Latest | **B** | 카드 6장 |
| 9 | Pricing | A | |
| 10 | Flow(How) | **B** | 카드 3장 |
| 11 | FAQ | A | |

→ B 밴드 = **#2·4·6·8·10 (5곳)**. ABABAB… 규칙적 호흡. 색차가 미세해 5곳이어도 "줄무늬" 아님.

### 절제 다이얼 (사용자 선택)

- **더 절제(3밴드)**: B를 **#2·6·10만** — 별/중간/시작-안내 3지점만 shelf. 나머지 전부 캔버스. "거의 평면인데 가끔 모듈이 도드라짐" 톤.
- **권장(5밴드)**: 위 표.
- *(6밴드 이상·진한 톤은 줄무늬 위험 → 미채택.)*

→ **둘 다 같은 코드, 밴드 적용 섹션 목록만 다름.** 라이트·다크 보고 강도 결정.

### 구현 방식 (섹션 무수정)

섹션들이 자체 `maxWidth+padding`을 이미 가지므로, **full-bleed 래퍼**로 감싸기만 하면 됨:

```tsx
// landing.tsx — 신규 (≈10줄)
export function Band({ tone, children }: { tone?: "shelf"; children: ReactNode }) {
  return (
    <div style={{ background: tone === "shelf" ? "var(--surface-2)" : "transparent" }}>
      {children}
    </div>
  );
}
// home.tsx — 적용 (섹션 파일 0 수정)
<Band tone="shelf"><WeaknessEngineSection /></Band>
<PreviewSection />
<Band tone="shelf"><FeaturesSection /></Band>
...
```

→ **12개 섹션 파일 전부 무수정**, `home.tsx` + 작은 `Band`만. (C1의 "PALETTE→var 레버"와 같은 최소 표면 철학.)

## 2. wash / 그라데이션 위치 (1~2곳, 절제)

깊이를 더할 **소수 지점**에만 은은한 방사형 wash. **남발 금지.**

### 권장 — Hero 상단 단 1곳

- Hero(`position:relative` 이미 있음) 뒤에 `aria-hidden` 레이어 1장:
  `radial-gradient(circle at 72% -10%, var(--lp-wash), transparent 60%)`
- 강도: 브랜드 블루 **불투명도 ~5%**(라이트)·~7%(다크)로 **거의 안 보이는** 틴트. 상단 우측에서 페이드아웃 → hero에 "빛이 든" 깊이.
- **신규 토큰** `--lp-wash`(app.css `:root`/`.dark`)로 SSOT·다크 제어. (C1-0에서 `--lp-*` 추가한 방식 그대로. 하드코딩 hex 금지 — C1 정신 유지.)

### 선택 — FinalCta 1곳 (보류 가능)

- FinalCta는 이미 그라데이션 카드 + 흰 원형 장식이 있어 자체 깊이 충분. **추가 wash 불필요** 판단 → 권장은 **Hero 1곳만**.

> **slop 회피**: mesh 그라데이션·노이즈·다색 금지. 단색 브랜드 블루 <7% 방사형 1장 = 분위기(atmosphere)지 장식(decoration) 아님.

## 3. 헤더 변주 (단조 탈피, 가장 선택적)

중앙정렬 헤더 8회 반복 → 변주. 단 **전부 좌정렬 = 또 다른 단조**이므로 규칙 기반으로 소수만.

### 권장 — "흐름형 섹션만 좌정렬" + 공통 eyebrow 악센트

1. **공통(일관성)**: `SectionHeader` eyebrow 앞에 **24px 짧은 컬러 룰**(`--link`) 추가 — 전 헤더 동일 적용. 변주가 아니라 **공통 디테일 격상**(frontend-design "decorative borders"). 중앙 헤더는 룰을 텍스트 위 중앙, 좌 헤더는 텍스트 앞.
2. **변주(좌정렬 2곳)**: 내용이 **L→R로 읽히는** 섹션의 헤더만 `align="left"`로:
   - **IntegratedFlow**(#5, 조문→판례→문제 가로 흐름)
   - **Flow/How**(#10, STEP 1→2→3 가로 흐름)
   → 가로 흐름 ↔ 좌정렬 헤더가 **의미적으로 정합**(임의 아님). `SectionHeader`가 `align="left"` 이미 지원 → call-site 2곳만 수정.

- 나머지 6개 헤더 = **중앙 유지**(중앙 = 차분·신뢰, 변리사 브랜드에 적합). 좌 2 / 중앙 6 = 리듬은 깨되 산만하지 않음.

### 더 절제(선택)

- eyebrow 악센트 룰만 적용하고 좌정렬은 보류 → 변화 최소. (헤더 변주는 3축 중 **영향·우선순위 최하**, 생략해도 무방.)

## 4. 절제 근거 (왜 slop이 아닌가)

| 제안 | slop이 아닌 이유 |
|---|---|
| 섹션 교대(surface-2) | 색차 **2~3% 명도** = 줄무늬 직전의 미세함. SKILL의 slop 예시(*purple gradient on white*)와 정반대. 이미 정의된 의미 토큰 재사용 |
| wash 1곳 | 단색 브랜드 블루 **<7%** 방사형 1장. mesh·노이즈·다색 전무 = 분위기지 장식 아님 |
| 헤더 변주 | 좌정렬을 **콘텐츠 방향(가로 흐름)에 결속** = 규칙 기반(임의 아님). 중앙 기본 유지 = 차분·신뢰 |
| 토큰 기반 | 전부 `var(--token)` → **다크 자동**·앱 일관·1곳 SSOT. light-only 일회성 플러시 아님 |
| 구조 | 전부 가산적·가역적. **레이아웃/구조 0 변경**(Layer 2 "작은 코어") |

→ 변리사 수험 플랫폼의 톤 = **신뢰 > 화려함**. "은은히 구분되고 평면적이지 않은" 정도. 눈에 띄게 화려한 것 아님.
