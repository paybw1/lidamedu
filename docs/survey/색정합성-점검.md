**차트 라이브러리 없음**(recharts/chart.js 미사용). 전부 손수 만든 SVG/`div` 막대. 색이 컴포넌트마다 따로.

### 부조화 핵심
1. **히트맵 2종이 다른 hue** — 대시보드=파랑(`BLUE_SCALE`) vs 학습=초록(emerald). 같은 "활동량" 의미인데 색 불일치. ★
2. **막대 hue 제각각** — 대시보드 학습량=파랑 / srs 복습=초록 / srs 예정=빨강·주황 / 스파크라인=하늘.
3. **합격자 12주 곡선** — 본인선이 **검정(`#111827`)이라 다크모드에서 사라짐**, 3개 카드가 보라/하늘/초록 제각각, grid·축·라벨이 고정 회색 hex라 다크 깨짐. 가장 심각.
4. **의미색 그라데이션**(정답률·합격예측 추이의 emerald→rose)은 **이미 일관·다크 OK** — 이건 유지·확산 대상.
5. **`--chart-1~5` CSS 변수** — `app.css`에 정의됐으나 손수 만든 차트들이 **안 씀**(고아). 게다가 light(주황·갈색 #d08829·#e6983d)와 dark(파랑·청록 #60a5fa·#5ea699) hue가 **서로 달라** 그대로 쓰면 모드 전환 시 색이 튐.

## ③ 통일 팔레트안

원칙: **성과(정답률/점수)는 의미 그라데이션, 활동(볼륨)은 단일 hue**. 전부 테마 토큰·`dark:` 기반.

### A안 — 의미색 일관 + 활동 단색 ★권고
- **성과 차트**(정답률 추이·합격예측 추이·OX·합격자 비교): `emerald(좋음)→lime→amber→orange→rose(나쁨)` 의미 그라데이션으로 통일. (stats가 이미 이 방식 → SSOT 헬퍼로 추출해 공유.)
- **활동·볼륨 차트**(히트맵 2종·주별/일별 학습량·due count): **단일 hue 명도 스케일**로 통일. → **두 히트맵을 한 색으로**. 권고 hue = **primary(파랑)** — 브랜드(`--primary`)·대시보드 기존 파랑과 일치. (학습 히트맵 emerald→파랑 1곳만 전환.)
- **합격자 12주 곡선**: 본인선 검정 → **`--foreground`**(또는 primary), 합격자선 → **`--muted-foreground`**, grid → **`--border`**, 축 라벨 → **`--muted-foreground`**, 현재주 마커 → **`--destructive`**. 3카드 본선 색(보라/하늘/초록)은 단일 primary 또는 의미색으로.
- **`--chart-*` 변수**: light/dark hue 정합 재정의 후 SSOT로 채택하거나, 미사용이면 정리.

### B안 — 전체 단색(primary) 그라데이션
- 모든 차트를 파랑 명도만으로. 가장 차분·일관되나 **정답률 good/bad 신호(초록/빨강) 상실** → 성과 진단 가독성 저하. 비권고.

> **권고: A안.** 활동=primary 파랑 단색(히트맵 2종 통일), 성과=의미 그라데이션 유지·확산, 합격자 곡선만 토큰화. hue 선택(활동을 파랑 대신 emerald로 통일할지)만 확인되면 적용.
