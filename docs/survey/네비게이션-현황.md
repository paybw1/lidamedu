## 0. 구조 요약 (가장 먼저) — 학생 네비가 **2시스템·3사본·3중**

| 표면 | 정의 파일 | 활성 조건 | 그룹 소스 |
|---|---|---|---|
| **학생 상단바(top-bar)** | `app/core/components/navigation-bar.tsx` (`:55~110` 하드코딩 배열) | 쿠키 `studentNavMode=topbar` (**기본값**) | 파일 내 하드코딩(studyItems·latestItems·mockExamItems·communityItems …) + **영역 잠금(feature flag)** |
| **학생 사이드바 + 모바일 하단탭** | `app/core/lib/nav-groups.ts` (`NAV_GROUP_POOL`, `:32~117`) | `studentNavMode=sidebar`(사용자 토글) / 모바일은 항상 하단탭 | `student-sidebar.tsx`·`student-bottombar.tsx`가 `useNavLayout()`로 소비. **잠금 없음** |

## 1. 전체 네비게이션 트리

### 1-B. 학생(로그인) — 상단바(topbar 모드, 기본)
1-A 상단바와 **항목 동일**. 차이: 우측이 `UserMenu`(대시보드 /dashboard · 내 계정 /account/edit · 로그아웃 /logout), 알림 벨 노출(`inboxHref=/inbox`), 잠긴 그룹 🔒 표시, `운영관리`는 isStaff=false라 미노출. 모바일(<md)은 상단바 숨고 **하단탭**(1-C) 사용.

## 2. 용어 불일치 (★ 통일 대상)

### (a) OX vs 정오문제 — **불일치**(같은 기능군을 두 단어로)
| 표기 | 쓰이는 곳 |
|---|---|
| **OX** | 메뉴 "OX 약점 진단"(navigation-bar.tsx:69), 화면 제목 ox-diagnosis.tsx:16,64, "OX 오답 노트"(my-ox-wrong-note.tsx:38), 운영자 "OX 검수"·"객관식 문제 · OX"(admin-shell.tsx:99,89), 주석 "OX 지문/박스 항목", **DB enum** `problem_format='ox'`·`srs_item_type='ox'`·`ox_truth`(database.types.ts) |
| **정오문제** | 메뉴 "정오문제 응시 이력"(3사본 공통), 화면 my-ox-sessions.tsx:25,62, 버튼 "정오문제 시험/학습"(mcq-pack-detail.tsx), 조문 패널 라벨(article-right-panel.tsx:89), 대시보드 "정오문제 응시 추세"(dash-ox.tsx:61) |
→ **같은 기능이 "OX 약점 진단" ↔ "정오문제 응시 이력"으로 한 메뉴(학습관리) 안에서도 단어가 갈림.** URL/DB는 전부 `ox`.

### (b) 진단 — **불일치 + 단어 충돌**
- 약점진단: "OX 약점 진단"(spaced) vs "약점진단"(no space, welcome.tsx:354·동의문구·exam-results 쿼리) vs "약점 단원/약점 우선 복습/약점 재시도" 파생.
- ★ **"진단" 단어가 3개 다른 기능에 중복**: 약점 진단(OX) · **합격 진단 점수**(pass-predict, dash-forecast.tsx) · **완성도 진단**(법령, admin-law-completeness). 맨단어 "진단" 공유 = 혼란원.

### (c) 복습 / 카드 암기 / 암기 / SRS — **가장 심한 불일치**(한 SRS 엔진을 4+ 단어로)
| 화면 | 메뉴 라벨 | 화면 제목 |
|---|---|---|
| `/study/srs` (자동 복습 큐) | **복습** | "오늘의 복습" / Eyebrow "자동 일정 복습" |
| `/srs` (능동 카드 암기, beta) | **카드 암기** | "카드 암기" / h1 "오늘의 카드" / 주석 "카드 복습" |
- 두 화면을 **묶는 사이드바 그룹 자체가 "복습"**(nav-groups.ts:41). + "암기"는 빈칸/조문에도(blank-stats-tabs·assignments/curricula labels "조문 암기"). + 동의·법무 문구가 **"복습"과 "암기"를 별개 기능으로 나열**(analytics-consent.mdx:22). + **운영자 UI엔 raw "SRS" 노출**(admin-student-detail.tsx:743 "SRS 복습 큐", cohort-stats "SRS 코호트 인사이트") — 코드 주석은 "학생에겐 SRS 용어 숨김"이 취지(navigation-bar.tsx:60). DB는 `srs_*`.
- ※ "플래시카드/flashcard"는 **UI 미사용**(seed 문구 1회뿐).

### (d) 모의고사 / 합격자 — **불일치**
- 모의고사: **같은 화면 `mcq.tsx`가 shell에 따라 머리말이 갈림** — LatestShell "1차 기출문제" vs MockExamShell "1차 진도별 모의고사"(메타 제목은 `mcq.tsx:56` "1차 기출문제"로 **모의 팩에도 잘못 고정**). 종류 라벨도 "전체 모의고사"(`mcq-packs/labels.ts:11` mock_full) vs "통합 모의고사"(shell/admin) vs "1차 모의고사"(메뉴)로 충돌. "진도별 모의고사"=mock_progressive.
- 합격자: "합격자 벤치마크"(dash) vs "합격자 평균 대비 비교"(subscriptions/labels.ts:70, 같은 비교) + 곡선비교/후기모음/사례/분석. 코드는 `passer`/`benchmark`. ※ "합격데이터" 문자열은 **app/에 없음**(확인).

### (e) 학습 통계 / 학습 분석 / 내 분석 / 대시보드 — **불일치**
- 같은 `/study/stats`가 메뉴·탭·제목엔 "학습 통계"(spaced), 동의·법무 문구엔 "학습통계"(no space). 이를 게이트하는 토글은 "내 학습 분석(A)"·"내 분석"·"약점 분석"으로 제각각(my-exam-results.tsx:270, exam-results/labels.ts:65). "대시보드"(/dashboard)는 일관.

### (f) 기출 / 객관식 / MCQ — **대체로 일관**, 소소한 마찰
- "기출문제"(DB past_exam→라벨 "기출문제", 단축 "기출") 일관. 마찰: 운영자 통계 UI에만 영문 "MCQ" 노출(admin-problem-stats.tsx:166), 그 외 "객관식". 영역명이 메뉴는 "기출"(출처축)인데 내부는 "객관식"(형식축).

### (g) 커뮤니티 / 반별 게시판 — **불일치**(두 게시판 시스템 병존)
- `community_*`(자유/스터디/후기, community/labels.ts) vs `cohort_board_*`(반별, 공지형/소통형) — 한 "커뮤니티" 메뉴 그룹에 나란히. 학생용은 **"반"**(반별 게시판/반 목록/반 공지)인데 운영자 분석 화면·주석은 **"코호트"**(admin-cohort-stats.tsx:468). 코드/DB는 `cohort`. ※ "기수" 문자열은 **app/에 없음**(확인).

> ★ 근본 원인: 학생 nav가 3사본(navigation-bar.tsx · nav-groups.ts · admin-nav-preview.tsx)이라 라벨이 이미 표류. **용어 통일 전, 정의를 단일 소스로 수렴**해야 재발 안 함.
