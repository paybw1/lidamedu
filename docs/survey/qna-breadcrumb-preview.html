데이터는 이미 다 있습니다 — 표시 방식만 바꾸면 됩니다. 현재 resolveTargetDisplay() 가 단일 문자열(예: 판례 2001후2801)만 반환해서 리스트에 파편만 보이는 상태입니다. 이를 4개 세그먼트 객체로 확장합니다.
세그먼트출처 (기존 테이블)
① 과목laws.short_label / thread.subject
② 유형thread.target_type (조문·판례·문제)
③ 식별자 조문 = articles.article_number + title
판례 = cases.case_number (+ court·decided_at)
문제 = origin+year+problem_number (+ P-code)
④ 쟁점
(체계도)		 조문 → article_systematic_links → systematic_nodes.display_label
판례 → 판례에 연결된 조문/노드 (없으면 ④ 생략)
문제 → problems.primary_node_id → systematic_nodes
④가 없는 경우(연결 미지정·공부방법·일반)는 세그먼트를 자동 생략합니다. 조문이 여러 노드에 걸리면 primary/첫 노드 1개만 표시(중복 방지).
