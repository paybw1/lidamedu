## 2. ★ 연결(배선) — 목표가 학습을 바꾸는가? → **거의 안 바꾼다**

### 2.1 `study_goals` 를 읽는 곳 / 안 읽는 곳 (grep 전수)
`study_goals` 참조 = **단 2모듈**:
- `goals/queries.server.ts`(get/upsert) · `dashboard.tsx`(`:125` 온보딩 판정, `:181` getStudyGoals).
- **안 읽는 곳(중요)**: `today-summary.server.ts`·`daily-menu.server.ts`·`recommendation-*`·`srs/*` — grep 0건. → **오늘 할 일·추천·복습이 목표를 전혀 안 본다.**

즉 `study_goals` 영향 범위 = **대시보드 D-day·주간 시간 KPI + /goals 화면 자신**뿐.
- `exam_type`(1·2차): 저장만 되고 **대시보드조차 안 씀**(대시보드는 examDate·weeklyHours만 사용) → **사실상 write-only**.
- `target_score`: 폼에 다시 보여줄 뿐, 합격예측·어디에도 미사용.

### 2.2 왜 안 읽나 — 파이프라인은 `profiles.next_exam_*` 를 본다
학습 맥락(시험차수)을 추천·예측은 **`profiles.next_exam_round`/`next_exam_year`** 에서 가져온다(`study_goals` 아님):
- `daily-menu.server.ts` `pickGapProblems` — `profiles.next_exam_round` 로 1차/2차 과목 분기(`round==="second"? [...민소]:[...민법]`).
- pass-predict 차수 분기 `next_exam_round`(`dashboard.tsx:147`), 온보딩 게이트 `next_exam_year`(`:120`), exam-results·cron 도 `next_exam_*`.
→ 추천이 보는 차수와 /goals 가 쓰는 차수가 **다른 컬럼**이라, /goals 에서 "2차" 골라도 추천은 안 바뀐다.

### 2.3 profiles vs study_goals 중복·권위 모호 (★단절 원인)
| 개념 | study_goals (/goals 설정) | profiles (온보딩 설정) | 파이프라인이 읽는 쪽 |
|---|---|---|---|
| 시험 **차수** | `exam_type` ("first"/"second") | `next_exam_round` (enum first/second) | **profiles** (추천·예측·cron) |
| 시험 **시점** | `exam_date` (YYYY-MM-DD) | `next_exam_year` (연도) | 분리 — D-day=study_goals.exam_date / 그 외=profiles.next_exam_year |
- **같은 의미(차수)가 두 컬럼**, 동기화 코드 없음. `welcome.tsx`(온보딩)는 `profiles.next_exam_*` 설정, `/goals`는 `study_goals` 설정 — **두 화면이 서로 다른 저장소에 같은 정보를 따로 쓴다.**
- 권위 모호: 차수의 "정답"이 profiles인데 학생이 자주 보는 /goals 는 study_goals 를 고쳐 → **불일치 가능**(예: /goals=2차, profiles=1차 → 추천은 1차).

### 2.4 연결 지점(어디를 손대면 목표가 학습을 바꾸나 — 가능성만)
- (가) **차수 단일화**: /goals 저장 시 `profiles.next_exam_round/year` 도 함께 갱신(또는 study_goals 차수 폐기·profiles로 일원화) → 추천·예측이 자동으로 학생 선택 반영.
- (나) **추천 필터**: `composeDailyMenu`가 차수(단일화된 소스)로 gap_problems·약점 슬롯 과목을 1·2차로 필터.
- (다) **시험일 우선순위**: `today-summary`/추천이 `exam_date`(D-day)로 임박 시 복습·약점 비중↑.
- (라) **목표점수 활용**: 합격예측에 `target_score` 대비 격차 표시.
- (마) **하드코딩 제거**: `EXAM_DATE_FALLBACK_ISO` 대신 미설정 시 D-day 숨김/안내.
