# Phase 3 + B1 — 실전 테스트 가이드

> 대상: 운영자(임병웅). 소요 약 30~40분. 운영 게이트 1주차("운영자 셀프 사용")와 사람 검수 항목 3건을 한 번에 커버한다.
> 원칙: **실운영 반(27년대비 1차 종합반)을 건드리지 않는다** — 테스트 전용 반에서 진행하고 끝나면 정리한다.

---

## 0. 사전 준비 (5분)

1. `/admin/cohorts` → 반 생성: 이름 **`테스트반(삭제예정)`**
2. 반 상세 → **[멤버 추가]** → 본인 계정(임병웅)을 멤버로 추가
   - 학생 화면(/study/plan)은 역할이 아니라 **반 멤버십**으로 열리므로, 본인 계정 하나로 학생·상담자 양쪽 흐름을 다 돌 수 있습니다.
   - 카카오 단일 로그인이라 별도 테스트 계정을 만들기 번거로우면 이 방식이 가장 빠릅니다.
3. (선택) 진짜 "신규 학생" 빈 상태 검수용 — 여분 카카오 계정이 있으면 가입시켜 테스트반에 추가. 없으면 §검수 1-1은 2주차 동반 작성 때 실제 신규생으로 확인.

---

## 시나리오 A — 상담자: 종이 없는 상담 1회 (10분)

> Stage 2 완료 판정 기준. 진단 → 검토 → 승인이 한 화면 흐름으로 이어지는지.

1. `/admin/cohorts/{테스트반}` → 상단 **[월간 계획]** 버튼 → 계획 현황 표 진입
   - ✅ 학생별 "진단 미입력" 앰버 칩, 계획 "미작성" 표시 확인
2. 본인 행의 **[상담]** 클릭 → 상담 화면
3. **좌측 상단 — 초기 진단**: 초시/재시 선택, 평일 `300` · 주말 `600` 입력 → [진단 저장]
   - ✅ 저장 후 값 유지되는지
4. **좌측 하단 — 과목별 수준**: 특허법 수준 "수강 전" 선택 → [저장]. 화학에 상중하 "중" 수기 선택 → [저장]
   - ✅ 화학 행에 **"수기"** 출처 배지가 붙는지 (진단 테스트로 갱신되면 "진단 테스트"로 바뀜 — 시나리오 C)
5. 우측 "이번 달 계획"은 아직 "학생이 아직 계획을 만들지 않았습니다" — 시나리오 B 후 다시 옴

## 시나리오 B — 학생: 계획 작성 → 제출 → 회수 → 승인 → 일일 기록 (15분)

1. 상단 nav **종합반 > 월간 계획** (또는 `/study/plan`) → **[이번 달 계획 시작]**
2. **[항목 추가]** — 검수 포인트 3건이 여기 있습니다:
   - 제목 `민법 기본강의 (4강)`, 활동 `강의 수강`, **하루 목표 200분**, 요일 `평일`, 기간 기본값
   - **[단원 선택]** 클릭 → ★**검수 1-1**: 본인 계정은 풀이 이력이 있어 "약점 추천" 칩이 뜹니다. *신규 계정으로 열면* 약점·최근이 비고 — 시나리오 A-4에서 특허 "수강 전"을 넣었으므로 **수준 기반 제안(특허 상위 단원)이 그 자리를 채우는지**가 검수 대상
   - ★**검수 1-3**: 추천 칩 경로 = [단원 선택]→칩 클릭 **2탭**, 전체 탐색 = +과목 선택+목록 클릭 **4탭** — 실제 손맛 확인
   - [추가] 후 두 번째 항목: `특허 문제풀이`, `문제 풀이`, **하루 150분**, 요일 `매일`
3. ★**검수 1-2 — 과욕 지수 실시간**: 두 항목을 넣는 순간 상단 배너가 **"평일 350분 (가용의 117%)"** 빨간 경고로 바뀌는지 (제출 전에 보여야 의미 있음). 진단을 안 넣었다면 "진단 미입력" 안내가 뜨는지도 확인
4. **[제출]** → 상태 "제출됨" → **[회수하고 수정]** 클릭 → "작성 중"으로 복귀 + 항목 편집이 다시 열리는지 → 다시 **[제출]**
5. 상담 화면(시나리오 A 탭)으로 → 우측 계획 패널에 **자동 검토 신호** 확인:
   - 과욕 지수: 평일 117% 빨강 / 약점 회피: "상위 약점 N개 중 M개 미포함" + 미포함 단원명
6. 코멘트 없이 **[승인]** → 학생 화면 새로고침:
   - ✅ 상태 "승인됨" + 항목에 자물쇠(편집 버튼 사라짐) + **[오늘 기록 →]** 버튼 등장
   - ✅ [계획 수정 (새 버전)] 눌러보면 v2 draft가 생기고 "이 달 계획 2회 변경" 표기 (테스트 후 v2는 그냥 두거나 제출→반려로 상태 구경)
7. **[오늘 기록 →]** (`/study/plan/log`):
   - ✅ 오늘이 평일이면 두 항목, 주말이면 "매일" 항목만 — 요일 파생 확인 (상단 ◀▶로 날짜 이동해 교차 확인)
   - ✅ **[완료 200분] 1탭** → 카드가 초록 완료 상태로
   - ✅ [부분] → 프리셋 30분 → [기록] (2탭+저장)
   - ✅ 완료 카드의 ↩(취소) → 기록이 사라지되(역방향 레코드) 다시 기록 가능
   - ✅ **[계획에 없던 학습 추가]** → 활동 `기타` 30분, 단원 미선택으로 기록 — "미분류" 표시
8. 다시 `/study/plan` → **"이번 달 달성 현황"** 섹션: 항목별 실제/기대 분·완료 일수 바, 상단에 미분류 % 표시
9. 상담 화면 새로고침 → "진행 지표"(과제 이행률 병기)와, **체크포인트는 이번 달 14일·28일이 지나야** 자동 생성됨(지연 생성) — 지금은 없어도 정상

## 시나리오 C — 자연과학 진단 테스트 (G3, 5분)

1. 테스트반 상세 → 과제 만들기(`진단용 과제`) → 과제 편집 → **오프라인 테스트 새로 만들기**: 과목 `자연과학: 화학`
2. 빌더 → **[시험 정보 편집]** → ✅ **"진단 테스트" 체크박스**(자연과학에만 보임) 켜고 저장 → 문항 후보에서 객관식 10문항 담기 → 상단 **[배포]**
3. **[결과 입력]** → 본인 행 "응시" → 오답 3개 클릭(=7/10) → 저장
   - ✅ "진단 반영 — 자연과학 수준 1명 자동 갱신됨" 메시지
4. 상담 화면 → 화학 행: ✅ 상중하 **"상"** + `7/10` + **"진단 테스트"** 배지 (수기였던 값이 덮임)
5. 결과 화면에서 본인을 "미응시"로 바꿔 재저장 → ✅ "진단 철회 1명 — 재확인 필요" 경고 + 상담 화면 화학 행에 빨간 재확인 문구
6. (덤 — Phase 1 확인) 빌더에서 배포된 시험지의 문항 편집 버튼이 잠겨 있는지, 학생 `/assignments` 과제 상세에 시험 카드가 보이는지

## 시나리오 D — B1 수정 확인 (5분)

1. `/latest/mcq` → 아무 문제집 팩 → **OMR 시트**로 3~4문항을 서로 다른 간격(예: 5초, 20초, 40초)으로 응답 — 순서를 건너뛰며(1→7→3) 풀어볼 것
2. 확인(둘 중 편한 쪽):
   - 터미널: `node tmp/b1-diagnosis/stage0-refined.mjs` → 새 세션이 "누적 확정"에 **안 잡히면** 정상 (Stage 2 게이트 증거로도 사용)
   - 또는 `/study/stats` 주별 공부량이 실제 소요와 비슷한 자릿수인지
3. 같은 문항의 답을 바꿔보기 → 시간이 불어나지 않아야 함(수정=0ms)

## 정리 (테스트 후)

- 테스트반의 시험지·과제 삭제 → 반 상세에서 본인 멤버 제거 → 반 삭제
- `/study/plan`의 본인 계획: 테스트반 삭제 시 cascade로 함께 삭제됨(계획·항목·기록·체크포인트 전부 반 FK 아님 — 계획은 cohort FK cascade, **study_logs는 user 귀속이라 남음** → 본인 로그가 통계에 남는 게 싫으면 알려주시면 정리 스크립트로 지웁니다)
- 운영 게이트 측정에는 영향 없음(측정 스크립트는 27년대비 반 한정)
