## 3. 롤아웃 체크리스트

- [ ] **1주차 — 운영자 셀프 사용**: 운영자 본인이 학생 화면(/study/plan)에서 계획 1건 작성·제출·(다른 staff) 승인·오늘 기록 3일. *자기가 쓰기 싫은 도구는 학생도 쓰지 않는다.*
- [ ] **2주차 — 동반 작성 2~3명**: 상담 중 학생과 함께 작성. **손이 멈추는 지점을 그 자리에서 §6 양식에 기록** — 이 게이트에서 가장 값진 산출물.
- [ ] **3주차 — 전체 9명 확대**
- [ ] **4주차 — 측정 실행 + §5 판단**

## 4. 관찰 항목

**4-1. 붕괴 시점 ★** — 스크립트 §⑤ 표(학생별 첫/마지막 기록일·경과일)가 그대로 답한다.

| 이탈 시점 | 원인 | 처방 방향 |
|---|---|---|
| 첫 주에 시작 안 함 | 가치 전달 실패 | "왜 하는가"를 화면이 설명 |
| 1주 하고 끊김 | 입력 마찰 | 탭 수·진입 경로 재설계 |
| 2~3주 하고 끊김 | 보상 부재 | 기록의 결과가 학생에게 돌아오게 |

**4-2. 계획 작성 관찰(2주차)**: 첫 작성 소요시간 / 노드 부착 멈춤·되돌아감 / 신규 학생 폴백(수준 기반 추천)의 실용성 / "이걸 왜 해요" 질문 여부. 참고: 노드 부착은 추천 칩 경로 2탭·전체 탐색 4탭(코드 기준) — 실측과 대조.

**4-3. 상담자**: 자동 신호 2종을 실제로 보는가 / 계획을 읽지 않고 승인하게 되는가 / 종이 대비 시간.
