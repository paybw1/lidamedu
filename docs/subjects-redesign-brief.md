## 0. 산출물 한 줄

> 변리사 수험생이 실제로 **콘텐츠를 학습하는 화면군**. 과목 진입(hub)부터 조문·판례·문제 본문 학습, 퀴즈까지. 핵심 가치는 **"조문 ↔ 판례 ↔ 문제가 끊김 없이 이어지는 통합 학습 흐름"** — 어느 화면에서든 우측 패널이 관련 자료를 들고 있다.

## 2. 핵심 목적 — 학습과목 영역이 지켜야 하는 3원칙

1. **통합 흐름** — 조문을 보다 관련 판례로, 판례에서 유사 문제로 끊김 없이 이동. 모든 본문 화면 우측에 같은 패널(관련 자료·메모·하이라이트)이 따라온다.
2. **본문 가독성 최우선** — 학습의 90%는 조문·판례·문제 텍스트를 읽는 것. 본문 영역은 넓고, 차분하고, 한국어 가독성이 좋아야 한다. chrome(트리·패널·툴바)은 본문을 방해하지 않는 보조.
3. **위치 인지** — 과목 안에서 "지금 어디를 학습 중인지"(어느 조문/장/단원)가 항상 또렷. 좌측 트리 + breadcrumb.

## 4. 디자인 방향

### 4.1 톤

> "조용한 독서실 책상" — 본문은 종이처럼 차분하고 읽기 편하게, chrome 은 절제된 도구. 학구적·신뢰감. 데이터·기능이 많지만 본문이 늘 주인공.

### 4.2 색 · 타이포 · 형태 (디자인 시스템 SSOT)

- **색**: `colors_and_type.css` Wantedly 토큰. 전경 black-with-alpha, 브랜드 딥블루 `#2D5BA8`. 본문 배경은 흰색, chrome 은 `#FAFAFA`/`#EEEEEE` 중성.
- **타이포**: Pretendard 단일. **본문(조문·판례·문제 텍스트)은 가독성 우선** — 16px 내외, line-height 1.7+, 적절한 measure(한 줄 길이). 숫자(연도·정답률·통계)는 tabular-nums.
- **형태**: 8pt 그리드. 카드 `R4`, 큰 패널 `R12`, pill chip `R100`. 2-layer 중성 그림자.
- **모션**: in-view reveal, 패널 전환 120~240ms. `prefers-reduced-motion` 존중.

### 4.3 본문 의미색

- 하이라이트: 사용자가 고르는 4~5색(노랑·분홍·초록 등) 유지 — 학습 도구라 다색 허용.
- 중요도 별: 앰버 `#F7B500`.
- 콘텐츠 타입 구분(조문/판례/문제): 절제된 색 dot 또는 라벨. 본문 안에서는 과하지 않게.
- 관련조문 inline 링크: 본문 안에서는 dotted underline, 헤더 영역에서는 chip (기존 규칙 유지).

## 5. 공통 패턴 — 모든 본문 화면이 공유 (조문·판례·문제 뷰어)

학습 뷰어 3종(조문·판례·문제)은 **같은 3분할 셸**을 쓴다. 한 번 디자인해 재사용.

### 5.1 3분할 레이아웃

```
┌──────────┬───────────────────────────┬──────────────┐
│ 좌측 트리 │       중앙 본문            │  우측 패널    │
│  260px   │     minmax(0, 1fr)        │   320px      │
│  sticky  │   (학습 콘텐츠 — 주인공)   │   sticky     │
└──────────┴───────────────────────────┴──────────────┘
```

- **데스크톱(lg+)**: 3분할. 좌·우는 `sticky top-20`, 본문만 스크롤.
- **태블릿**: 본문 + 우측 패널 2분할, 좌측 트리는 드로어.
- **모바일**: 본문 1단. 좌측 트리·우측 패널은 상단 버튼 → `Sheet` 드로어(320px).

### 5.2 좌측 트리 패널 (260px)

- 상단: 정렬축 토글 — **"체계도" ↔ "조문"** (SortAxisToggle).
- 본문: 계층 트리 — 가이드 라인 방식(depth 별 세로 라인), active 노드는 blue 좌측 막대 + 연한 배경, leaf 앞 작은 dot. 중요도/메모/하이라이트/즐겨찾기 인디케이터.
- 상단에 중요도·즐겨찾기 필터 chip, 조문 검색 인풋.
- *이 패턴은 이미 코드에 1차 적용됨 — 디자인 시스템 블루 톤으로 마감만.*

### 5.3 우측 패널 (320px) — ArticleRightPanel

- **좌측 44px 아이콘 레일 + 우측 콘텐츠 영역** 구조. 활성 탭은 blue 배경.
- 탭(콘텐츠에 따라 노출): 즐겨찾기 · 메모 · 하이라이트 · 판례 · 유사 문제 · Q&A · 개정이력(강사) · 정오문제 · 코멘트.
- 카운트 있는 탭은 아이콘에 작은 dot.
- *이미 코드에 1차 적용됨 — 디자인 시스템 톤으로 마감.*

### 5.4 본문 위 툴바

- 텍스트 선택 시 하이라이트 색 선택 팝오버(HighlightToolbar).
- 조문 뷰어 한정 기능 버튼: 빈칸 모드 · 암기 모드 · 소제목만 보기 · 해설 보기 · 흐름 학습 · (강사) 편집.

## 6. 화면별 명세

### 6.1 과목 hub (`/subjects/{과목}`)

**헤더**
- eyebrow "과목별 학습 · {카테고리}", 큰 과목명 + 한 줄 설명.
- KPI 3개: 조문 수 · 판례 수 · 문제 수 (+ 내 풀이·정답률).
- 진도 막대(과목 전체 진척).
- 우측: 정렬축 토글.

**3탭 — 조문 / 판례 / 문제**

- **조문 탭**: 좌측 트리(280px) + 우측에 `[최근 학습]`·`[미열람 권장]` 2카드 + "조문을 선택하세요" 안내. 트리 노드 클릭 → 조문 뷰어.
- **판례 탭**: 좌측 트리(260px, 판례 필터용) + KPI 3카드(전체 판례·중요 판례·기출 보유) + 검색 인풋 + 필터 3종(법원·기출·정렬) + **7열 테이블**(★·법원·선고일·사건번호·사건유형·사건명+기출칩·전합) + 페이지네이션(50/페이지).
- **문제 탭**: KPI 3카드(출제 문항·내 풀이·정답률) + 오답노트 배너(앰버) + **학습 모드 3카드**(체계별 풀이·맞춤 퀴즈·정오문제 무작위) + 필터 폼(출처·연도·시험·유형·극성·범위·난이도·정렬 + 본문 검색) + **객관식 테이블** / **주관식 카드 그리드**.

> hub 의 핵심 과제: 정보가 많은 테이블·필터를 **답답하지 않게** 정리. 필터 폼은 한 줄로 접고, 테이블은 행 hover 강조 + 충분한 행 높이.

### 6.2 조문 뷰어 (`/subjects/{과목}/articles/{n}`)

§5 3분할 셸. 중앙 본문:
- **헤더**: 조문 제목(예 "특허법 제29조 (특허요건)") + 이전/다음 버튼 + 1차/2차 badge + 중요도 별. 서브: 법령명·조문번호·시행일. 시점 조회(`?at=`)·비교 모드 배너.
- **툴바**: 빈칸 모드(내용/주체/기간) · 암기 모드 · 소제목만 보기 · 해설 보기 · 흐름 학습 · (강사) 편집.
- **본문**: 조·항·호·목 계층 텍스트. 하이라이트 오버레이, 메모 표식, 관련조문 inline 링크. 빈칸/암기 모드 시 본문이 빈칸 폼/암기 폼으로 전환.

### 6.3 장 뷰어 / 체계도 노드 뷰어

좌측 트리 + 중앙에 **여러 조문 카드를 세로로 나열**. 각 조문 카드 = 헤더(제목·중요도·시행일) + 본문 + 그 조문 전용 우측 패널(카드 내부 2분할 `1fr / 320px`). 맨 위에 장/노드 제목 헤더 카드.

### 6.4 판례 뷰어 (`/subjects/{과목}/cases/{id}`)

§5 3분할 셸 (좌측 트리는 참고용 조문 트리). 중앙 본문:
- 뒤로가기 링크 + 관련 조문 chip.
- **판례 헤더 카드**: 법원·사건번호(mono)·사건유형·전합 badge·중요도 별·선고일·기출 연도칩.
- 섹션: 판결요지([1][2] 복수) · 판시이유(마크다운) · 판결전문 PDF(iframe) · 비고(출처 박스).
- 모든 본문에 하이라이트 오버레이.

### 6.5 문제 풀이 (`/subjects/{과목}/problems/{id}`)

§5 3분할 셸. 중앙:
- 헤더: 연도·문항번호·중요도·이전/다음.
- 본문: 지문(마크다운) + 선택지(객관식 radio / OX / 빈칸 입력 / 주관식 textarea). 정답 제출 후 — 정답 표시 + 선지별 해설 + 관련 조문·판례 링크 reveal.
- 모드: 학습 모드(즉시 해설) vs 시험 모드(타이머, 일괄 제출). 세션 기반(`?session=`).
- 주관식: 모범답안·채점기준 reveal + 자기채점 + 첨삭 요청.

### 6.6 체계별 문제 색인 (`/subjects/{과목}/problems/system`)

뒤로가기 + 헤더("{과목} 체계별 풀이 · 총 N건"). 체계도 노드별 **카드 그리드**(sm 2열 / lg 3열). 각 카드: 경로 breadcrumb + 노드명 + 문제 수 + `[학습 모드]`·`[시험 모드]` 버튼. 문제 0건 노드는 dim.

### 6.7 퀴즈 — 설정 / 결과 / OX

단일 컬럼(`max-w-screen-md`).
- **설정**: 필터 카드(출처·연도·유형·극성·범위) + 세션 카드(문항수 10/20/30/50/100 · 학습/시험 모드 · 셔플).
- **결과**: KPI 4카드(정답률·총 문항·오답·소요시간) + "오답 N건 → 오답노트" 유도 + 문항별 결과 목록(O/X·연도·시간).
- **OX**: 헤더 + OX 지문 무작위 풀이 — O/X 선택 즉시 피드백.

### 6.8 자연과학 (`/subjects/science/*`)

법률보다 **단순형** — 문제 중심. ScienceHub(과목별 진척 + 문제 링크) + 단순 problem-viewer(4지선다, 우측 패널 없음). 법률 화면과 같은 디자인 언어를 쓰되 chrome 을 덜어낸 경량 버전.

## 7. 디자인 가이드 (핵심 과제)

1. **본문 영역을 넓고 차분하게** — 조문/판례/문제 텍스트가 주인공. 폰트 크기·행간·여백을 독서에 맞춰. chrome 색은 죽이고 본문은 또렷하게.
2. **3분할 셸 1벌을 완성도 높게** — 조문·판례·문제 뷰어가 공유하므로 트리·본문·패널·툴바·모바일 드로어 전환을 pixel-perfect 로.
3. **테이블·필터 정리** — hub 의 판례/문제 테이블과 다축 필터가 현재 빽빽함. 필터는 한 줄로 접고, 테이블은 숨 쉴 공간을. 행 hover·정렬·페이지네이션 일관.
4. **상태 렌더 순서** — 모든 화면이 `에러 → 로딩 스켈레톤 → 빈 상태 → 콘텐츠` 순서. **빈 상태 디자인을 함께 제공** (현재 회색 문구 한 줄뿐).
5. **모드 전환** — 조문 빈칸/암기 모드, 문제 학습/시험 모드 등 한 화면이 여러 모드를 가짐. 모드 토글과 각 모드 본문을 명확히.
6. **breadcrumb / 위치** — 과목 > 장 > 조문 경로를 본문 헤더 또는 트리에서 항상 보이게.

## 8. 절대 수정 금지 / Out of scope

- ❌ 라우트 추가·변경, 7개 네비게이션 메뉴 라벨·링크.
- ❌ 화면별 정보·기능의 추가/삭제 — 재배치·시각 개선·정리는 OK, 새 데이터가 필요한 위젯 신설은 범위 밖.
- ❌ DB 스키마·loader 쿼리.
- ❌ 강사/운영자 콘텐츠 편집 화면(`/admin/*`) — 본 작업은 학생이 보는 학습 화면. (단, 학습 화면 안의 강사용 진입 버튼·개정이력 탭은 디자인에 포함.)
- ❌ 기존 shadcn 기본 톤 잔존 — 디자인 시스템 블루로 통일.

## 9. 기술 제약 (코딩 단계 참고)

- 실제 구현: React Router 7 + TypeScript strict + Tailwind v4 + shadcn + Cloudflare Workers.
- 신규 npm 패키지·이미지/폰트 자산 도입 금지.
- 차트·트리·하이라이트 오버레이는 SVG/CSS 로 구현 가능한 수준 (현재도 그렇게 되어 있음).
- 모바일 반응형 필수 — 좌측 트리·우측 패널의 `Sheet` 드로어 전환.
- dark mode 지원 — 디자인 시 light/dark 둘 다 고려.
- `prefers-reduced-motion` 존중.

## 10. 우선순위 — 디자이너가 시간을 어디에 쓸지

1. **3분할 셸 1벌** (§5) — 조문·판례·문제 뷰어가 공유. 트리·본문·우측 패널·툴바·모바일 드로어. 가장 공들일 부분.
2. **조문 뷰어 본문**(6.2) — 학습의 중심. 본문 타이포·하이라이트·모드 전환.
3. **과목 hub**(6.1) — 진입 화면. 헤더·3탭·테이블·필터 정리.
4. **판례 뷰어**(6.4) · **문제 풀이**(6.5) — 셸 재사용 + 본문 차이.
5. **장/체계도 뷰어**(6.3) · **문제 색인**(6.6) — 다중 카드 패턴.
6. **퀴즈 3종**(6.7) · **자연과학**(6.8) — 단일 컬럼, 경량.
7. **빈 상태 / 로딩 스켈레톤** — 각 화면.
