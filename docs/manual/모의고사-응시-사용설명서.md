# 1차 객관식 모의고사 응시 — 수험생 사용설명서

> 이 설명서는 수험생 여러분이 **모의고사를 풀고**, **결과를 보고**, **틀린 문제로 복습**하는 법을 안내합니다.

---

## 한눈에 보는 흐름

```
1) 모의고사 골라 응시 →  2) 결과·점수 확인 →  3) 오답 → 근거 조문/판례 →  4) 오답 다시 풀기
   (/latest/mcq)         (자동)               (결과 화면)              (한 번 클릭)
```

# 1단계 — 모의고사 풀기

화면: **/latest/mcq** → 팩 선택 → "응시 시작"

## 1-1. 응시 모드 두 가지

| 모드 | 특징 | 권장 시점 |
|---|---|---|
| **학습 모드** | 다 풀고 "채점하기" 누르면 정답·해설 보임 | 처음 공부할 때 / 연습 |
| **시험 모드** | 정답·해설 응시 중 안 보임 + 타이머 + 자동 제출 | 실전 감각 / 진단 |

> **시험 모드를 권장**합니다. 실제 시험 환경과 같고, 점수·등수가 산출됩니다.

## 1-2. 응시 화면 둘러보기

화면 상단에 **고정된 회색 띠**(헤더)가 있고, 그 아래에 문제들이 세로로 쭉 늘어서 있습니다.

### 헤더(항상 보임)

| 표시 | 의미 |
|---|---|
| **응답 N / M** (왼쪽) | 지금까지 답 고른 문항 수 |
| 🔖 **다시 볼 문제 N** (있을 때) | 북마크해둔 문제 수 |
| ⏱ **남은 시간** (시험 모드만) | 자동 카운트다운 |
| **네비** 버튼 | 문항 그리드를 펼침/접음 |
| **결과 보기 / 시험 끝내기** | 제출 |

### 문항 카드

각 문제 카드 위쪽에:
- 번호 동그라미 (1, 2, 3…)
- 출처 (기출, 모의고사 등)
- 형식 (단답형, 박스형)
- **북마크 아이콘 🔖 (오른쪽 위)** — 클릭하면 노란색으로 활성 (= "나중에 다시 봐야지" 표시)

문제 본문 아래에는 선지 5개. 박스형은 ㄱㄴㄷㄹㅁ 보기 박스 + 선지.

## 1-3. 네비게이터 — 빠르게 이동하기

헤더의 **"네비"** 버튼을 누르면 그리드가 펼쳐집니다.

- 1, 2, 3 … 숫자 격자로 모든 문항 표시
- **초록색** = 응답 완료
- **회색** = 미응답
- **노란 점** = 북마크(다시 볼 문제)

원하는 번호 클릭하면 그 문항으로 바로 스크롤.

## 1-4. "다시 볼 문제" 북마크 사용법

문제를 풀다가 **"이건 좀 헷갈리네"** 싶으면 카드 우측 상단 🔖 버튼 클릭. 노란색으로 변하면 표시 완료.

- 헤더와 네비 그리드에 표시되어 나중에 다시 찾기 쉬워집니다.
- **새로고침해도 그대로 살아있음** (서버에 저장).
- 다시 클릭하면 해제.

## 1-5. 미응답 안내

"결과 보기" 또는 "시험 끝내기" 버튼을 눌렀을 때, 안 푼 문제가 있으면 **모달 창**이 뜹니다:

- "미응답 N문항이 있습니다"
- 미응답 번호 버튼들 — 클릭하면 그 문제로 이동
- **"계속 풀기"** = 모달 닫고 계속 풀기
- **"그래도 제출"** = 미응답인 채로 제출 (실전이므로 막지 않음)

> ⚠️ 시험 모드에서 미응답 = 0점 처리됩니다.

## 1-6. 도중에 나갔다가 다시 들어오기

브라우저를 끄고 다시 들어와도 OK.

- 응답한 답 그대로 ✓
- 북마크 그대로 ✓
- 타이머는 시간 흐른 만큼 줄어 있음 (실전 시험과 같음)

같은 응시는 **"이어서 응시"** 버튼으로 계속 진행됩니다.

# 2단계 — 결과 보기

응시가 끝나면 자동으로 결과 화면(`/latest/mcq/<팩>/result/<세션>`)으로 이동.

## 2-1. 상단 — 점수와 등수

화면 맨 위 큰 박스에:

| 표시 | 의미 |
|---|---|
| **점수 (숫자)** | 100점 만점 정답률 |
| **합격 / 불합격** 배지 | 합격선 통과 여부 (합격선 있을 때만) |
| **합격까지 N점** (노란 배지) | 점수가 합격선 미만일 때 |
| **합격선 +N점** (초록 배지) | 점수가 합격선 이상일 때 |
| **지난 회차 +N점 / -N점** | 같은 모의고사 이전 응시 대비 변화 |
| **전체 N명 중 ○등** | 등수 + 백분위 + 표준점수 z |

> 💡 **지난 회차 대비 +면 초록**, **-면 빨강**. 변동성도 자연스러우니 한두 번 떨어져도 너무 낙심하지 마세요. 그래도 약점 단원 점검은 필수.

## 2-2. KPI 4개 카드

- **본인 정답률** / **총 문항** / **오답** / **소요 시간**

## 2-3. 풀이 동영상 (있을 때)

강사 풀이 동영상이 등록된 모의고사는 **"동영상 풀이 보기 →"** 버튼이 표시됩니다.

# 3단계 — 단원별 정답률로 약점 진단

점수 박스 아래에 **"단원별 정답률"** 패널.

- 정답률 **낮은 순**으로 상위 5개 단원 표시
- 색상:
  - 🔴 **빨강** (50% 미만) = 약점
  - 🟡 **노랑** (50~74%) = 보강 필요
  - 🟢 **초록** (75% 이상) = 양호
- 단원 라벨 클릭 → 그 단원의 **체계도 페이지**로 이동
- 가장 약한 단원이 60% 미만이면 **"💡 가장 약한 단원: ○○○"** 추천 메시지 표시

> 💡 **활용 팁**: 빨강·노랑 단원에서 약점이 드러나면 그 단원을 클릭해 조문·판례·기출문제를 다시 학습하세요.

# 4단계 — 유형·지문별 정답률

본인 정답률과 **전체 평균**을 나란히 비교:

| 유형별 | 단답형 / 박스형 / 사례형 — 본인 vs 전체 |
|---|---|
| 지문별 | 조문 / 판례 / 이론(실무) — 본인이 선택한 지문 기준 |

> 💡 "박스형이 약하다" / "판례 지문에서 자주 틀린다" 같은 약점 파악에 유용.

# 5단계 — 오답 활용 (★ 핵심)

## 5-1. 오답 묶어 다시 풀기

화면 중간 **"오답 N문항 묶어 다시 풀기"** 패널 → **"오답 재도전"** 버튼.

- 이번 회차 오답만 모아 **새 회차**로 풉니다.
- 학습 모드라 즉시 채점·해설 가능.
- 같은 순서로 다시 풉니다.

> 💡 시험 직후 1-2시간 안에 오답 재도전 하시면 기억 정착에 매우 효과적.

## 5-2. 오답별 근거 바로가기

**"문제별 결과"** 표 아래에 **"오답별 근거 바로가기"** 섹션 등장.

각 오답 카드에:

### 조문 chip (파란색)
- 클릭하면 해당 **조문 페이지**로 이동
- chip 안에 작은 설명: "내가 고른 보기 근거" / "주요 조문" / "ㄱ 보기 근거" 등

### 판례 chip (보라색)
- 판례 사건번호 클릭 → 그 **판례 상세 페이지**로 이동

### AI 근거 청크 (회색 박스)
- AI가 만든 문제일 경우, 출제 근거가 된 조문/판례 원문 일부 미리보기

### 해설 보기 (접힘)
- "해설 보기" 클릭 → 펼쳐서 종합 해설 표시

> 💡 **활용**: 오답 카드의 조문 chip을 새 탭으로 열어 (Ctrl+클릭) 본문을 정독, 같은 카드의 해설과 비교해보세요.

## 5-3. 박스형 오답 — 어떤 보기 틀렸는지 추적

박스형(ㄱㄴㄷㄹ 골라 옳은 것 묶기)에서 틀렸다면:
- 카드 chip 안에 **"ㄱ 보기 근거"**, **"ㄴ 보기 근거"** 식으로 표시
- 각 보기마다 어느 조문이 근거였는지 즉시 확인 가능

> 💡 박스형은 "보기 4개 중 1개만 잘못 판단해도 오답" 입니다. 어느 보기에서 틀렸는지 알면 약점을 정확히 짚을 수 있습니다.

# 6단계 — 통합 1차 모의고사 (3교시 시험)

화면: **/latest/mcq/exams** → 시험 진입

## 6-1. 통합 시험은 뭐가 다른가요?

실제 변리사 1차 시험처럼 **3교시(산업재산권법 + 민법 + 자연과학)** 를 한 시험으로 봅니다.

- **각 교시는 독립 타이머** — 1교시 시간 다 써도 2교시는 새로 시작
- **순서대로 풀어야 함** — 1교시를 완료해야 2교시가 열림
- **합격 = 평균 60점 이상 + 모든 교시 40점 이상** (과락 없음)

## 6-2. 응시 중 화면 안내

화면 상단 안내 박스(노란색):
- **"지금 다음으로 풀 교시는 N교시"** — 어디서 시작하면 되는지 명시
- **"교시는 순서대로 잠금 해제 + 독립 타이머"** — 동작 원리 안내
- 잠긴 교시(다음 교시들)에는 **"이전 교시 완료 후 열림"** 표시

각 교시 카드의 **"교시 응시"** / **"이어서 응시"** 버튼으로 진행.

## 6-3. 결과 화면

전 교시 완료 후 자동으로 결과 화면(`/latest/mcq/exam/<시험>/result/<응시>`):

- **평균 점수 + 합격/불합격 + 과락 사유** 표시
- 등수 / 백분위 / z
- **교시별 점수 표** — 각 교시 행 클릭하면 그 교시 팩 결과 화면으로 drill-in(파고들기)
- 거기서 단원별 약점, 오답 근거, 오답 재도전 등 위 3-5단계가 그대로 적용됨

# 자주 묻는 질문

### Q. 시험 모드 중 답을 바꿀 수 있나요?
A. 네. 제출 전까지는 언제든 답 변경 가능. 마지막 선택이 저장됩니다.

### Q. 응시 중 인터넷이 끊기면 어떻게 되나요?
A. 답안은 선택할 때마다 서버에 즉시 저장됩니다. 잠시 끊겨도 다시 들어오면 그대로 살아 있어요.

### Q. 시험을 중간에 그만두고 싶어요.
A. **"시험 끝내기"** 클릭 → 미응답 모달 → "그래도 제출" → 결과 화면. 강제 종료 시에도 응답한 부분까지는 채점됩니다.

### Q. 다시 풀고 싶어요.
A. 같은 모의고사 팩으로 새 응시 시작 가능. 다만 **등수는 최신 응시 기준**으로 갱신됩니다.

### Q. "오답 재도전" 회차도 시험으로 기록되나요?
A. 학습 모드라 등수 산정에는 안 들어갑니다. 순수 복습용.

### Q. "단원별 정답률"이 안 보여요.
A. 모의고사 과목 범위가 **산업재산권법 통합(industrial)** 또는 **자연과학(science)** 인 경우 단원 매핑이 없어 표시되지 않을 수 있습니다. 일반 단일 과목(특허/상표/디자인/민법)이면 표시됩니다.

### Q. 통합 시험에서 1교시가 너무 어려워 포기하고 싶어요.
A. **그대로 제출하셔도** 실전 감각 측정에 의미가 있습니다. 과락이어도 다른 교시까지 풀고 전체 흐름을 파악하는 게 좋습니다.

### Q. AI가 만든 문제와 기출문제를 구분할 수 있나요?
A. 문제 카드의 출처 라벨이 **"AI 초안"** 으로 표시됩니다. 단 강사가 검토·승인한 후에만 노출되므로 품질은 일반 문제와 동등.

# 학습 동선 추천 — 한 회차 풀고 나면

1. **결과 점수 확인** → 합격선까지·지난 회차 대비 변화 보기
2. **단원별 정답률**에서 약점 단원 1~2개 추리기
3. **약점 단원 클릭** → 체계도에서 조문·판례 다시 학습
4. **오답 재도전** 클릭 → 학습 모드로 다시 풀며 해설 정독
5. **각 오답의 조문 chip** 클릭 → 조문 본문 직접 읽기
6. **다시 볼 문제** 북마크는 별도 노트에 기록 또는 다음 학습 세션에 활용

- **AI 문제는 강사 검증을 거친 것만** 학생 노출
