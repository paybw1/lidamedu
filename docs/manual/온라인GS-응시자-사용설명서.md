# 온라인 GS — 수험생 사용설명서

> 이 설명서는 수험생이 **온라인 GS**(주관식 모의·정기 모의)에 응시하고, 결과를 확인하고, 동료의 답안을 채점하고, 우수 답안을 열람하고, 포인트를 모으기까지의 흐름을 안내합니다.

---

## 무엇을 할 수 있나요? (3줄 요약)

- **응시**: 종이에 손글씨로 답안 → 페이지 사진 업로드 → 제출 → 채점 → 점수·피드백
- **논점 추출 훈련**: 답안 전체 작성 부담 없이, **사례 보고 핵심 쟁점만 빠르게 뽑는 연습** (`/gs/issues`)
- **부가 학습**: 동료 답안 채점, 우수 답안 열람, 포인트 적립

## 한눈에 보는 흐름

```
A) 응시 회차 풀이                B) 논점 추출 훈련 (가볍게 반복용)
─────────────────────            ───────────────────────────
/gs 대시보드                      /gs/issues
       ↓                                ↓
회차 선택 → 답안지 PDF 받기       문항 선택 → 사례 읽고 핵심 논점 백지 작성
       ↓                                ↓
종이에 손글씨 풀이                제출 → 모범 논점과 자기채점
       ↓                                ↓
페이지 사진/PDF 업로드            (옵션) AI 의견 받아 보강
+ 문항 매핑                            ↓
       ↓                          빠뜨린 논점 → 📄 판례 전문 PDF 열람
응시 제출
       ↓
채점 대기 → 채점 완료
       ↓
점수·피드백·모범답안 PDF·우수답안 → 동료채점 → 포인트
```

핵심 포인트:
- **종이 답안지에 손글씨로 작성** — 시험지 PDF를 다운로드해 출력하고, 풀이는 종이에 합니다. (변리사 2차 실전과 동일 환경)
- **페이지별 사진/PDF 업로드** — 각 페이지를 사진(JPG/PNG/WebP)이나 PDF로 올린 다음, "이 페이지가 어느 문항이다" 를 칩으로 매핑합니다.
- **제출 조건이 가벼워졌습니다** — 1페이지 이상 올리고, 올린 페이지가 답안지 최대 페이지 수 이내이고, 본인이 "판독 가능" 체크하면 제출 가능. **미매핑 문항이 있어도 제출 가능** (해당 문항은 채점에서 0점).
- **논점 추출 훈련** 은 별도 진입(`/gs/issues`). 답안 전체 작성 안 해도 됨.

---

## 어디서 들어가나요?

- 상단 네비게이션 → **온라인 GS** 메뉴 → `/gs`
- 응시 가능 / 예정 / 종료 회차가 한 화면에 정리되어 있습니다.

---

# 1단계 — 응시할 회차 고르기

화면: **/gs**

## 1-1. 화면 구성

상단에 내 **포인트 잔액** 표시 (있으면). 본문은 4개 섹션으로:

| 섹션 | 내용 |
|---|---|
| **응시 가능** | 지금 들어가서 풀 수 있는 회차 (emerald) |
| **예정** | 곧 시작될 회차 (시작 시각 표시) |
| **내가 채점할 답안** | 동료 채점이 배정된 답안 카드 |
| **종료** | 이미 끝난 회차 — 결과 보기 / 우수 답안 열람 |

응시 가능 카드 클릭 → 응시 시작.

> 💡 회차마다 **시작·종료 시각** 과 **제한 시간(분)** 이 다릅니다. 시작 시각 전에는 진입 불가, 종료 후에는 새로 응시 불가.

# 2단계 — 응시 화면

화면: **/gs/{회차ID}/take**

## 2-1. 화면 구성

```
┌─ 헤더 (회차 제목 + 과목 chip + ⏱ 남은 시간) ──────┐
│  [📄 답안지 다운로드]                              │ ← 답안지 PDF 받기
│                                                    │
│  [안내: 종이에 작성 → 페이지 사진 업로드]          │
│                                                    │
│  ┌─ 문항 목록 (왼쪽, 읽기 전용) ─────────┐         │
│  │ Q1. ...                                │         │
│  │ Q2. ...                                │         │
│  └────────────────────────────────────────┘         │
│                                                    │
│  ┌─ 페이지 슬롯 그리드 (오른쪽) ─────────┐         │
│  │ [P1 빈] [P2 빈] [P3 빈] ...           │         │
│  │  ↑ 클릭하면 사진/PDF 업로드           │         │
│  └────────────────────────────────────────┘         │
│                                                    │
│  [제출하기] ← 모든 페이지 매핑·판독 OK일 때 활성   │
└────────────────────────────────────────────────────┘
```

## 2-2. 사용 순서

### 1) 답안지 PDF 다운로드

상단 **"답안지 다운로드"** 버튼 → 회차에 등록된 시험지 PDF 받기 → 출력 → 종이에 손글씨로 풀이.

### 2) 페이지별 사진/PDF 업로드

각 페이지 슬롯 클릭 → 사진(JPG/PNG/WebP) 또는 PDF 업로드. 슬롯 번호 = 답안지 페이지 번호와 일치시켜 주세요.

업로드 후 슬롯에 표시:
- 썸네일
- **문항 매핑 칩** (Q1, Q2, ...) — 이 페이지가 어느 문항에 해당하는지 클릭으로 표시 (한 페이지에 여러 문항 가능)
- **판독 확인 체크박스** — "이 사진이 글자를 알아볼 수 있다" 본인 확인

### 3) 페이지 순서가 잘못됐을 때

- **드래그**: 슬롯을 다른 슬롯 위로 드래그 → 위치 교환
- **빈 슬롯 끼워넣기**: 슬롯 하단의 "여기 위에 빈 페이지 추가" 버튼 → 그 위치부터 한 칸씩 밀림
- **삭제**: 슬롯 우측 상단 휴지통 아이콘

> ⚠ **마지막 페이지가 채워진 상태에서 끼워넣기 하면 마지막 페이지가 잘립니다.** 먼저 마지막 페이지를 비우고 끼워넣으세요.

### 4) 제출 가능 조건 (가벼워졌어요)

다음 3가지만 충족되면 **"응시 제출"** 버튼이 활성화됩니다:
1. **1페이지 이상 업로드** — 빈 채로는 제출 불가
2. **페이지 수가 답안지 최대 페이지 이내** — 회차마다 다름(보통 20페이지)
3. **업로드한 모든 페이지가 "판독 가능 확인" ✓** — 본인이 직접 흐림·잘림 점검

> 💡 **미매핑 문항이 있어도 제출 가능합니다.** 단, 매핑 안 된 문항은 자동 채점에서 **0점** 으로 처리됩니다. 제출 확인 다이얼로그에 "미매핑 N건은 0점 처리" 가 명시됩니다.
>
> 즉 시간이 모자라 일부 문항을 못 풀었더라도, 푼 문항에 대해서만이라도 제출하고 점수받을 수 있습니다.

## 2-3. 타이머·재진입

- 헤더 우측의 **카운트다운**: `min(종료 시각 - 지금, 시작 + 제한시간 - 지금)` 중 빠른 쪽
- **응시 중 페이지를 나가도 OK** — 다시 들어오면 이전 상태(업로드한 페이지·매핑 등) 그대로 복구
- 카운트다운 0이 되면 추가 업로드 불가

# 3단계 — 결과 보기

화면: **/gs/{회차ID}/result**

제출 → 자동으로 결과 화면 이동.

## 3-1. 상태 3가지

| 상태 | 화면 |
|---|---|
| **응시 중** | "아직 응시 중입니다 → 응시 화면으로" |
| **제출 완료 (채점 전)** | "채점을 기다리는 중입니다" + 답안지 페이지 갤러리 |
| **채점 완료** | 점수·피드백·모범답안 모두 공개 |

## 3-2. 채점 완료 화면 구성

| 영역 | 내용 |
|---|---|
| 상단 | 회차 제목 · 과목 · 내 총점 / 만점 · 모범답안 PDF 다운로드 |
| 답안지 갤러리 | 내가 올린 페이지를 순서대로 (썸네일 + 페이지 번호) |
| 문항별 카드 | 문항 본문 · **내 점수 / 만점** · 강사 피드백 · 매핑된 페이지 번호 link |

### 모범답안 다운로드

상단 **"모범답안 PDF"** 버튼 (회차에 등록된 경우만). 채점 완료 후 노출.

### 루브릭 점수

문항마다 채점 루브릭이 있다면 항목별 점수도 표시 (예: 결론 20/20, 조문 인용 25/30 ...).

# 3.5단계 — 판례 전문 PDF (어디서나)

판례 학습 화면(`/subjects/{과목}/cases/{판례ID}`) 헤더에 **📄 전문 PDF** 버튼이 보이면, 그 판례의 **대법원 판결 원문 전체**를 PDF로 열어볼 수 있습니다.

| 어디서 | 어떻게 |
|---|---|
| 판례 학습 화면 헤더 | 사이트복사·AI 질문 버튼 옆 **📄 전문 PDF** |
| 논점 추출 훈련 결과 | 빠뜨린 논점 카드 안 `📄 전문 PDF` 링크 (채점 완료 후만) |

- 새 탭에서 열림. 다운로드도 가능
- 사건번호·법원·선고일이 표지로, 본문은 원고/피고/원심/주문/이유 순
- 링크는 1시간 유효. 만료되면 화면 새로고침으로 재발급

> 💡 **모든 판례에 PDF가 있는 것은 아닙니다.** 학원에서 순차 적재 중이며, 적재된 판례만 버튼이 노출됩니다.

# 4단계 — 동료 답안 채점 (배정될 때)

회차 마감 후 운영자가 동료 채점을 켜둔 경우, `/gs` 대시보드에 **"내가 채점할 답안"** 카드가 나타납니다.

## 4-1. 진입

카드 클릭 → **/gs/peer-review/{assignmentId}**

## 4-2. 화면 구성

```
┌─ 헤더 (회차 제목 · "동료 채점") ──────────────┐
│                                                │
│  [익명 답안 안내]                              │
│                                                │
│  문항 1.                                       │
│  ┌─ 답안 페이지들 ────────────────────────┐   │
│  │ (페이지 사진 1, 2, ... 익명)            │   │
│  │ (OCR 텍스트 미리보기, 있다면)            │   │
│  └─────────────────────────────────────────┘   │
│  [점수 입력 0~만점]                            │
│  [피드백 작성란 (Markdown)]                    │
│                                                │
│  문항 2. ...                                   │
│                                                │
│  [채점 제출하기] ← 모든 문항 점수 입력 시 활성 │
└────────────────────────────────────────────────┘
```

## 4-3. 규칙

- **익명**: 답안 작성자 이름은 절대 표시되지 않습니다 (개인정보 보호)
- **점수 + 피드백 둘 다** 작성 권장. 피드백은 학습에 큰 도움
- 모든 문항 점수 입력 시 **"채점 제출"** 가능. 제출 후 수정 불가
- 운영자가 분쟁 신호 감지 시 무효화 가능 (악의적 채점·과도한 편차)

## 4-4. 학습 효과

다른 학생 답안을 평가하면서 **본인 답안의 강·약점**을 객관화할 수 있습니다. 좋은 답안을 보면 다음 회차에 반영 가능.

# 5단계 — 우수 답안 열람

화면: **/gs/{회차ID}/distinguished**

회차 종료 후 운영자가 마킹한 우수 답안을 봅니다 (공개 옵션 설정된 답안만).

## 5-1. 화면 구성

- **회차 종합 우수 답안**: 전체 문제에 걸쳐 우수한 학생 (실명 또는 익명)
- **문항별 우수 답안**: Q1 우수, Q2 우수, ...

각 답안 카드:
- 작성자 이름 (실명 마킹) 또는 "익명"
- 답안 페이지 갤러리
- OCR 텍스트 미리보기 (있는 경우)
- 운영자가 선정한 사유 (선택)

## 5-2. 학습 활용

- 본인 답안과 직접 비교 — 무엇이 부족했는지 즉시 파악
- 답안 구성 패턴(결론 위치, 조문 인용 방식, 도식화 등) 학습
- 다음 회차에 적용

---

# 5.5단계 — 2차 논점 추출 훈련 (가볍게 반복용)

화면: **/gs/issues** → 문항 선택 → **/gs/issues/{문항ID}**

답안 전체 작성 부담 없이, **사례를 보고 핵심 쟁점만 빠르게 뽑는 연습** 모드입니다. 출제된 GS 문항 중 강사가 모범 논점을 등록·승인한 것만 노출됩니다.

## 5.5-1. 단계 4개

```
① 빈 화면      → 사례 본문 보고 핵심 논점을 한 줄씩 자유 서술 (autosave)
       ↓
② 제출         → "제출 → 모범 논점 보기" 클릭
       ↓
③ 자기채점     → 모범 논점이 reveal. "짚음 / 빠뜨림" 본인이 토글
       ↓
④ 결과         → 짚은 / 빠뜨린 / 핵심 누락 카운터 + 빠뜨린 논점에 학습 링크
                    └ 빠뜨린 논점 카드 안: 조문 link + 📄 판례 전문 PDF
```

## 5.5-2. 가운데 단계의 옵션 — AI 의견

자기채점 단계 상단 amber 패널에 **"AI 의견 요청"** 버튼.
- AI 가 학생이 쓴 글을 모범 논점과 의미적으로 비교 → "짚었을 가능성 / 빠뜨렸을 가능성 / 학생 자작 논점" 보조 의견 표시
- **단정 X — 보조 의견** 톤. 최종 결정은 본인 판단으로 짚음/빠뜨림 토글
- 일일 사용량 한도 도달 시 "오늘 한도 도달 — 자기채점으로 진행" 안내. 자기채점 흐름은 그대로 진행 가능

## 5.5-3. 결과 단계 활용

- **빠뜨린 논점** 카드에 학습 링크가 같이 노출:
  - 조문 link (예: 특허법 제29조) → 조문 학습 화면
  - 판례 link → 판례 학습 화면
  - **📄 판례 전문 PDF** — 대법원 판결 원문 직접 열기 (채점 완료 단계에서만 노출)
- 하단 액션:
  - **답안 작성 단계로 →** : 같은 회차의 답안 작성으로 (논점 → 답안)
  - **다시 풀기** : 본인 작성 비우고 처음부터
  - **목록으로** : `/gs/issues` 색인

## 5.5-4. 어떻게 활용하면 좋나요?

- 매일 5~10분 짧게 — 답안 풀이 부담 없이 핵심만 반복
- 빠뜨린 논점은 그 자리에서 조문·판례 link 클릭해 즉시 복습
- 같은 문항을 며칠 후 "다시 풀기" 로 재시도해 정착도 측정

# 6단계 — 포인트 모으기

화면: **/gs/points** (대시보드 우측 상단의 "포인트 잔액" 클릭)

## 6-1. 포인트는 언제 받나요?

- **우수 답안 마킹 시**: 운영자가 마킹한 답안에 포인트 자동 지급
- **회차별 보너스**: 회차 100점 달성 등 운영자 정책에 따라
- **운영자 수동 지급**: 특별 기여(좋은 동료 채점 등) 시

## 6-2. 잔액 / 거래 내역

- 상단에 현재 잔액 표시
- 본문에 거래 로그 (시각 · 사유 · ±포인트)

## 6-3. 사용처

> 현재 포인트는 **명예 점수** 입니다. 환금/할인 등 적용은 학원 정책에 따라 추후 확장될 수 있습니다.

# 자주 묻는 질문

### Q. 종이가 아니라 PC에서 직접 타이핑할 순 없나요?
A. 현재는 **종이 → 사진 업로드** 모델입니다. 변리사 2차 실전이 종이 답안지라서 똑같은 환경에서 연습하도록 설계되었습니다.

### Q. 페이지를 잘못 올렸어요. 운영자에게 문의해야 하나요?
A. 본인이 응시 화면에서 직접 정정 가능합니다 (드래그, 끼워넣기, 삭제). 제출 전이라면 자유롭게 수정하세요. 제출 후엔 운영자에게 문의.

### Q. 사진이 흐릿하게 찍혔어요. 채점받을 수 있나요?
A. **판독 가능 확인 ✓** 체크박스를 본인이 켜야 제출됩니다. 본인이 보기에 글자를 못 알아볼 정도면 다시 찍어 올리세요 — 그렇지 않으면 채점에서 0점 받을 위험.

### Q. 모범답안 PDF는 언제 받을 수 있나요?
A. **채점 완료 후** 결과 화면 상단에 다운로드 버튼이 나타납니다. 채점 전에는 비공개.

### Q. 동료 채점이 제 점수에 영향을 미치나요?
A. **아닙니다.** 운영자가 직접 채점한 점수가 최종 점수입니다. 동료 채점은 본인 학습용 + 운영자 참고용.

### Q. 다른 학생 답안을 보면 누구 답안인지 알 수 있나요?
A. **아니요.** 익명 처리되어 작성자 식별이 불가능합니다.

### Q. 응시 중 인터넷이 끊겼어요. 다시 들어가도 되나요?
A. 네. 업로드된 페이지·매핑·판독 확인 상태는 모두 서버에 저장되어 있어, 다시 들어오시면 그대로 복구됩니다. 타이머는 종료 시각 또는 시작 + 제한 시간 중 빠른 쪽으로 계산됩니다.

### Q. 한 페이지에 두 문항을 답했는데요?
A. 페이지의 매핑 칩에서 **여러 문항** 을 모두 선택 가능합니다 (예: Q1, Q2 동시 매핑).

### Q. 우수 답안 마킹 기준은요?
A. 운영자가 점수·풀이 구성·예시 가치를 종합 판단해 선정합니다. 100점이라고 자동 선정은 아닙니다.

# 학습 동선 추천 — 한 회차 다 끝났을 때

```
1. 결과 보기                  → 내 점수 + 강사 피드백 + 모범답안 확인
       ↓
2. 우수 답안 열람             → 내 답안과 비교 (구성·조문 인용 방식)
       ↓
3. 동료 채점 참여 (배정 시)   → 다른 답안을 평가하며 객관화
       ↓
4. 약점 문항 단원 학습        → 결과 화면 문항별 점수 보고 약한 단원 → /subjects/{과목}/systematic
       ↓
5. 같은 단원 객관식 문제 풀기  → /subjects/{과목}/quiz/setup 에서 단원 필터
       ↓
6. 다음 회차 응시              → 같은 시리즈의 다음 회차 또는 새 회차
```

> 💡 한 회차 풀고 그냥 점수만 보지 말고, **모범답안·우수답안 → 동료 채점 → 약점 단원 보강** 의 동선을 끝까지 가는 것이 가장 학습 효과가 큽니다.
