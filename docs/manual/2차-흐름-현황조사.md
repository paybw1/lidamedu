## 전체 흐름 연결 동선 (★ 설명서 핵심)

학생이 한 판례 항목으로 `②-A → ③④ → ⑤` 를 이어서 풀 수 있는가:

```
[학생 nav] 모의고사 → 판례 쟁점훈련
       ↓
[/case-training 목록]
   카드: "② 쟁점추출 →"        — 항상 노출
   카드: "③④ 결론·강약 →"      — conclusionReadyCount ≥ 2 일 때만
       ↓                             ↓
[② /case-training/:itemId]    [③④ /case-training/:itemId/conclusion]
   write → submit                write → submit
   → self-check (+ AI)           → self-check (+ AI 코칭)
   → done                        → done
       ↓                             ↓
   "③ 결론·강약 훈련으로 →"      "답안 작성으로 →"
   (conclusionReady=true 일 때)  (linked_gs_round_id 있을 때)
       ↓                             ↓
[③④ /case-training/:itemId/conclusion]   [⑤ /gs/:roundId/take]
                                              (학생 답안 작성 + 채점/peer)
```

**연결 동선 — 실제 라벨 정리:**

- `② done` → `③④`: 버튼 라벨 "③ 결론·강약 훈련으로 →" (`case-training-take.tsx` `primaryAction`). 조건 = `conclusionReady` (= `isConclusionTrainingReady`, 결론 정보 있는 쟁점 ≥ 2)
- `③④ done` → `⑤`: 버튼 라벨 "답안 작성으로 →" (`conclusion-done-stage.tsx` `primaryAction`, anchor `href="/gs/{linkedGsRoundId}/take"`). 조건 = `linked_gs_round_id` 가 NULL 아님
- `② done` → `② 다시 풀기`: 버튼 라벨 "다시 풀기" (soft delete 후 새 attempt)
- `③④ done` → `③④ 다시 풀기`: 동일
- 목록 → 양쪽 직접: `/case-training` 카드에 양쪽 진입 버튼 분리

## 설명서 집필 시 권고

1. **① 기본목차 암기는 "현재 미구현"** 로 명시. 우회로 `/srs`(카드 암기) 활용 안내.
2. **② → ③④ → ⑤ 흐름**: 학생 진입은 항상 사이드바 "모의고사 → 판례 쟁점훈련"(/case-training) 시작 권장. ③④ 진입은 (i) 목록의 "③④ 결론·강약 →" 또는 (ii) ② 채점 완료 후 "③ 결론·강약 훈련으로 →"의 두 경로를 모두 안내.
3. **GS 기반 논점추출**(②-B `/gs/issues`)은 사이드바 미노출 — `/gs` 메인의 "논점 추출 훈련 진입 카드"로 들어가도록 명시.
4. ⑤ GS의 상세는 기존 `온라인GS-응시자/출제자-사용설명서.md` 인용. ③④ → ⑤ 연결은 "강사가 회차 연결을 미리 설정한 경우에만 [답안 작성으로 →] 버튼 노출"을 강조.
5. 강사용 ②③④는 같은 편집 화면 안에서 처리 — "한 화면에서 사실관계·쟁점·결론·강약·GS 연결을 모두" 식으로 설명.
