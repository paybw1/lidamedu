# 2차 주관식 학습 — 수험생 사용설명서

> 이 설명서는 1차를 합격한 수험생이 **2차(주관식·논술) 답안 능력**을 이 학습 시스템으로 어떻게 길러가는지 안내합니다.
> 2차는 지식이 아니라 **"사례에서 논점을 잡고 → 결론을 내고 → 강약을 조절한 답안을 써내는"** 능력의 훈련입니다.

---

## 2차 공부의 큰 그림

2차 답안은 머릿속에서 이런 순서로 만들어집니다:

```
기본목차(암기) → ① 논점 추출 → ② 결론 도출 → ③ 응용목차(강약조절) → ④ 답안 작성 → 채점·피드백
   INPUT              -------- PROCESSING --------                        OUTPUT        (FEED)BACK
```

핵심은 **"한 번에 답안을 잘 쓰려" 하지 말고, 단계를 나눠 훈련**하는 것입니다. 논점을 못 잡으면 결론이 틀리고, 결론이 서야 목차의 강약이 잡히고, 그래야 답안이 나옵니다. 이 시스템은 그 단계를 각각 연습하도록 만들어져 있습니다.

이 설명서는 한 문제(판례)를 **논점추출 → 결론·강약 → 답안작성** 순서로 이어서 훈련하는 동선을 따라갑니다.

---

## 단계별 훈련 — 어디서 무엇을 하나

| 단계 | 무엇을 훈련 | 어디서 |
|---|---|---|
| 논점 추출 (판례 기반) | 판례 사실관계에서 쟁점 백지 추출 | **모의고사 → 판례 쟁점훈련** (`/case-training`) |
| 논점 추출 (GS 문제 기반) | GS 모범답안 기반 쟁점 추출 | **모의고사 → GS 논점추출** (`/gs/issues`) |
| 결론 + 응용목차 | 쟁점별 결론 + 답안 목차의 강약 조절 | 위 판례 훈련을 마치면 이어서 (`.../conclusion`) |
| 답안 작성 | 실제 답안을 종이에 써서 제출·채점 | 온라인 GS (`/gs`) |

> **기본목차 암기**는 현재 별도 트랙이 준비돼 있지 않습니다. 카드 암기(`/srs`)는 1차 객관식 기반 자동 복습 큐이고, 목차 카드를 학생이 직접 등록하는 기능은 없습니다. 2차 전용 목차 암기 트랙은 추후 추가될 예정이며, 그동안은 종이 노트 등 시스템 외부 도구를 활용해 주세요.

---

# 1단계 — 논점(쟁점) 추출 훈련

화면: 사이드바 **모의고사 → 판례 쟁점훈련** → **/case-training**

## 1-1. 왜 하나

2차 문제는 대개 주요 판례의 사실관계를 사례로 주고 "쟁점을 잡아 논하라"고 묻습니다. 그래서 **사례를 읽고 쟁점을 스스로 떠올리는 것**이 답안의 출발점입니다. 보기에서 고르는 1차식이 아니라, **백지에서 직접 적어내는** 훈련입니다.

## 1-2. 푸는 순서

1. **/case-training** 목록에서 항목을 고릅니다. 카드의 **"② 쟁점추출 →"** 버튼으로 들어갑니다.
2. **사실관계**만 주어집니다. (쟁점·판단·결론은 가려져 있습니다 — 그게 답이니까요.)
3. 작성란에 **한 줄에 한 쟁점**씩 직접 적습니다.
4. **"제출 → 모범 쟁점 보기"** 를 누르면 모범 쟁점이 공개됩니다.
5. 내가 적은 것과 모범을 비교하며 **짚음 / 빠뜨림**을 토글로 자가 체크합니다.
6. (선택) **"AI 의견 받기"** — AI가 "짚었을 가능성 / 빠뜨렸을 가능성"을 근거와 함께 보조로 알려줍니다. (참고용이며, 최종 판단은 본인이 합니다.)
7. **"자기채점 저장"** 으로 마칩니다.

## 1-3. 채점 후

- 결과에 **짚은 쟁점 / 빠뜨린 쟁점 / 핵심 누락** 3가지가 정리됩니다.
- 채점이 끝나야 **판례 전문 PDF**(📄)가 공개됩니다. 실제 판례에서 출제자가 어떻게 봤는지 확인하며, 내 예측이 어디서 빗나갔는지 교정하세요. **이 "채점 후 전문 확인"이 가장 중요한 학습 단계입니다.**
- 채점 후 화면 상단에 **"다음 단계"** 안내 박스가 뜹니다. 이 박스는 항목 상태에 따라 다음 중 하나를 권장합니다:
  - **③ 결론·강약 훈련으로 →** (권장 — 결론·강약 채점기준이 준비된 항목)
  - **⑤ 답안 작성으로 →** (강사가 GS 회차를 연결한 항목; ③④ 준비된 경우엔 "건너뛰기" 보조 옵션)
  - **GS 메인으로 →** (위 둘 다 없는 경우 — 회차 직접 고르기 안내)
- 같은 안내는 결과 화면 본문 아래의 버튼 영역에도 정리돼 표시됩니다.

> **GS 문제로도 논점추출 연습**이 가능합니다. 사이드바 **모의고사 → GS 논점추출** 으로 바로 들어가거나(`/gs/issues`), **/gs** 메인 화면의 "논점 추출 훈련 진입 카드"로도 동일하게 진입합니다.

# 2단계 — 결론 도출 + 응용목차(강약조절)

화면: 1단계를 마친 항목에서 **"③ 결론·강약 훈련으로 →"**, 또는 **/case-training** 목록의 **"③④ 결론·강약 →"** 버튼 → **/case-training/:itemId/conclusion**

> "③④ 결론·강약 →" 버튼은 강사가 결론 정보를 준비해 둔 항목에만 보입니다.

## 2-1. 무엇을 하나

쟁점을 잡았으면, 이제 **각 쟁점의 결론을 정하고, 답안 목차의 강약을 설계**합니다. 출제자가 깊게 묻는 쟁점은 강하게, 가볍게 묻는 쟁점은 약하게 — 이 **강약조절**이 2단계의 핵심입니다.

## 2-2. 푸는 순서

1. **사실관계**(1단계와 공유)를 다시 보며, 각 쟁점 카드에서:
   - **결론**(예: 인정 / 부정 / 성립 / 불성립)을 적고
   - 짧은 **근거**를 적고
   - **강 / 중 / 약** 중 이 쟁점에 줄 비중을 고릅니다.
2. **답안 목차**(순서·분량 비중)를 자유롭게 작성합니다 — 어떤 쟁점을 앞에, 깊게 둘지 설계합니다.
3. **"제출 → 모범 결론·강약 보기"** 를 누릅니다.
4. 자동 채점이 보여줍니다:
   - **결론**: 일치 / 부분 / 어긋남
   - **강약**: OK / 약함(핵심인데 약하게) / 과함(부차인데 강하게)
5. (선택) **"AI 강약 코칭"** — AI가 "핵심 쟁점에 비중이 부족해 보인다" 같은 코칭을 줍니다. 강약은 정답이 하나가 아니므로 **단정이 아니라 참고**입니다.
6. **"자기채점 저장"**.

## 2-3. 채점 후

- **결론 일치 / 핵심 강조 부족 / 부차 과강조** 3가지가 정리됩니다.
- 핵심 쟁점인데 약하게 간 것이 강조 표시됩니다 — 거기가 보강할 지점입니다.
- AI 코칭을 받았다면, 종합 코칭 박스(상단)와 함께 **쟁점별 AI 메모**가 각 쟁점 카드 안에 인라인으로 표시됩니다 ("AI 강약 코칭: …" / "AI 결론 코칭: …").
- 강사가 GS 회차를 연결해 둔 경우 **"답안 작성으로 →"** 버튼이 보입니다. 방금 짠 목차를 들고 실제 답안 작성으로 넘어가세요.
- 연결돼 있지 않으면 결과 화면 아래에 **"연결된 답안 작성 회차가 없습니다"** 안내 카드가 자동으로 떠서 **"GS 메인으로 →"** 버튼으로 안내합니다. 막다른 길에 빠지지 않으니, /gs 에서 응시 가능한 회차를 직접 골라 답안을 쓰면 됩니다.

# 3단계 — 답안 작성 + 채점 (온라인 GS)

화면: **온라인 GS** → **/gs**, 또는 2단계 끝의 **"답안 작성으로 →"**

여기서 실제 답안을 **종이에 손글씨로 써서 페이지 사진으로 업로드**하고, 강사·동료·AI 채점을 받습니다. 2차 실전과 같은 환경입니다.

> 답안 작성·제출·채점·우수답안·포인트의 자세한 사용법은 **온라인 GS 응시자 사용설명서**(`온라인GS-응시자-사용설명서.md`)를 참고하세요. 이 설명서는 거기까지 가는 **앞단 훈련**(논점추출·결론·강약)을 다룹니다.

---

## 한 문제를 끝까지 — 권장 학습 동선

```
모의고사 → 판례 쟁점훈련 (/case-training)
   └ ② 쟁점추출 →  : 사례 읽고 쟁점 백지 추출 → 채점 → 판례 전문 확인
        ↓ "③ 결론·강약 훈련으로 →"
   └ ③④ 결론·강약  : 쟁점별 결론 + 목차 강약 설계 → 채점 → AI 코칭
        ↓ "답안 작성으로 →" (강사가 회차 연결한 경우)
   └ ⑤ 답안 작성 (GS) : 종이 답안 작성·제출 → 강사/동료/AI 채점 → 우수답안 비교
```

> 한 판례를 **쟁점추출 → 결론·강약 → 답안작성**으로 끝까지 이어서 푸는 것이 가장 효과가 큽니다. 단계마다 "내 예측이 어디서 빗나갔는지"를 모범과 대조하며 교정하는 것이 2차 실력의 핵심입니다.

## 자주 묻는 질문

### Q. 쟁점을 적을 때 보기가 없나요?
A. 없습니다. 2차는 백지에서 떠올리는 시험이라, 보기 없이 직접 적는 것이 실전 훈련입니다.

### Q. AI 채점이 제 점수인가요?
A. 아닙니다. 논점추출·결론·강약 훈련의 채점은 **자기채점이 기본**이고, AI는 "빠뜨린 것 같다 / 비중이 부족해 보인다"를 알려주는 **참고 의견**입니다. 최종 판단은 본인이 합니다.

### Q. 판례 전문은 언제 보나요?
A. **채점을 마친 후**에 공개됩니다. 미리 보면 쟁점을 알아버려 훈련이 안 되기 때문입니다. 채점 후 전문을 보며 예측을 교정하는 것이 핵심입니다.

### Q. "③④ 결론·강약" 버튼이 안 보여요.
A. 강사가 그 항목에 결론 정보를 준비해 둔 경우에만 보입니다. 준비 중인 항목은 쟁점추출(②)만 가능합니다.

### Q. "답안 작성으로 →" 버튼이 없어요.
A. 강사가 그 훈련 항목에 GS 회차를 연결해 둔 경우에만 보입니다. 연결돼 있지 않으면 결과 화면 아래에 **"GS 메인으로 →"** 안내 카드가 자동으로 뜨니, 그걸 따라가 **/gs** 에서 응시 가능한 회차를 직접 고르세요.

### Q. 기본목차 암기는 어디서 하나요?
A. 현재 2차 전용 목차 암기 트랙은 미구현입니다. `/srs` 의 카드 암기는 1차 객관식 기반 자동 복습 큐이며, 학생이 임의로 카드를 등록하는 기능은 제공되지 않습니다. 종이 노트 등 시스템 외부 도구로 보완해 주세요. 전용 트랙은 추후 추가될 예정입니다.

### Q. GS 논점추출은 어디서 들어가나요?
A. 두 경로 모두 가능합니다: (i) 사이드바 **모의고사 → GS 논점추출**, (ii) **/gs** 메인 화면의 "논점 추출 훈련 진입 카드". 같은 화면(`/gs/issues`)으로 연결됩니다.
