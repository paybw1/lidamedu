# 강의 플랫폼 운영관리 — 사용설명서 (관리자 테스트 가이드)

> 이 문서는 **원장·매니저·강사(staff)** 가 강의 플랫폼(영상 강의·도서몰·주문·결제·정산·랜딩 콘텐츠)의 운영 기능을
> **직접 눌러 보며 테스트하고 익히도록** 안내합니다. 학습 플랫폼(조문·판례·문제·학습관리) 운영은 별도 문서를 참고하세요.
>
> - 진입: 로그인 후 상단 **운영관리**(또는 강의 플랫폼 상단바 우측 "운영관리") → `/admin`
> - 화면 찾기: 운영관리 사이드바 상단 **화면 찾기…(⌘K / Ctrl+K)** 로 91개 화면을 이름으로 점프
> - **테스트 시 주의**: 실제 운영 DB에 즉시 반영됩니다. 결제·환불·정산·발송은 **테스트 계정/소액**으로 확인하고, 확정(지급완료 등) 액션은 리허설 후 신중히 누르세요.

---

## 0. 전체 그림 — 어디에 무엇이 있나

운영관리 사이드바는 5개 섹션으로 묶여 있고, **강의 플랫폼 운영은 아래 4개 클러스터**에 모여 있습니다.

| 섹션 | 클러스터(사이드바 라벨) | 다루는 일 |
|---|---|---|
| **커머스·판매** | **강의·도서몰** | 강의 시리즈·회차·영상(콜러스), 콘텐츠 라이브러리, 수강권, 기기, 도서, 세트·번들, 배송 |
| **커머스·판매** | **상품 관리** | 상품·요금, 할인, 수강권(학생별 인스턴스) |
| **커머스·판매** | **매출·정산 관리** | 주문·결제, 매출/구독 통계, 주문 항목·환불, 강사/도서 정산, Q&A 적립, 쿠폰 |
| **운영·시스템** | **강의 플랫폼 콘텐츠** | 히어로 배너, 공부방법·맛보기 영상, 현장강의 일정, 리담소식, 시험정보, 시험 공고 |

보조로 **강사 관리 → 강사소개 관리**(공개 강사 프로필), **공지·커뮤니티 → 고객센터 문의·FAQ 관리** 를 씁니다.

### 역할별 접근

- **강사(instructor/staff)**: 콘텐츠 등록·관리 화면 대부분.
- **매니저(manager)+**: 매출·정산·결제·환불·상품·요금·할인·수강권·기기·수강권 지급 등 **돈이 걸린 화면**은 매니저 이상만 보입니다(loader 이중 방어).
- **원장(admin)**: 전부.

> 사이드바에 어떤 화면이 안 보이면 **역할 권한 문제**입니다(minRole 미달). 원장 계정으로 확인하세요.

### 처음 테스트한다면 — 권장 순서

**신규 강의 1개를 오픈하는 흐름**을 그대로 따라가면 대부분의 기능을 한 번씩 만집니다:

```
① 콘텐츠 라이브러리에서 콜러스 영상 동기화
   → ② 강의 시리즈·에디션 만들기 → 회차에 영상 붙이기 → 발행
   → ③ 상품·요금에서 수강권 상품 만들기 → 에디션에 연결(T-PASS)
   → ④ (선택) 할인·쿠폰 설정
   → ⑤ 테스트 계정으로 실제 결제 → ⑥ 주문·결제/수강권에서 확인
   → ⑦ 강의 플랫폼 콘텐츠에서 배너·맛보기 영상 노출
   → ⑧ 월말 강사 정산 리허설
```

아래 각 장(章)이 이 순서를 따릅니다.

## 1. 강의 영상 (LMS)

### 1-1. 콘텐츠 라이브러리 — 콜러스 영상 가져오기

- **화면**: 운영관리 → 강의·도서몰 → **콘텐츠 라이브러리** (`/admin/lms/contents`)
- **무엇을**: 콜러스에 업로드된 영상(콘텐츠)을 학원 시스템으로 동기화해 목록으로 관리합니다. 회차에 붙일 "재료"를 여기서 확보합니다.

**테스트 순서**
1. 콜러스 관리자에서 영상을 채널(**리담변리사학원**)에 업로드해 둡니다.
2. 이 화면에서 **콜러스 동기화**(`sync_kollus`) 를 누릅니다 → 새 콘텐츠가 목록에 나타납니다.
3. 상태 필터(미지정/사용가능/인코딩중/오류/비활성/중지)로 상태를 확인합니다.
4. **강의그룹**을 만들어(`save_group`) 콘텐츠를 분류(`assign_group`)합니다.
5. **미리보기**(`preview`) 로 재생을 확인합니다 — 이 재생은 **수강권·재생횟수 차감 없이** 됩니다(운영 확인용).

**확인 포인트**
- 재생키는 **media_content_key** 기준으로 저장됩니다(콜러스 채널 기준). 동기화 후 목록에 콘텐츠가 중복 없이 뜨는지 확인하세요.
- 자동 동기화 크론(`/api/cron/kollus-content-sync`)이 별도로 돌지만, 방금 올린 영상을 바로 쓰려면 **수동 동기화**가 빠릅니다.

### 1-2. 강의 시리즈·에디션

- **화면**: 운영관리 → 강의·도서몰 → **강의 시리즈·에디션** (`/admin/lms/courses`)
- **무엇을**: 강의를 **시리즈**(예: "특허법 기본강의")와 **에디션**(연도판, 예: 2026년판)으로 관리합니다.

**테스트 순서**
1. **시리즈 만들기**(`create_series`) — 과목·강사·카테고리 지정.
2. 시리즈 안에 **에디션 만들기**(`create_edition`). 이전 판이 있으면 **에디션 복제**(`clone_edition`)로 구조를 그대로 가져올 수 있습니다.
3. 에디션 카드에서 상세로 진입해 회차·영상을 채웁니다(1-3).
4. 준비가 끝나면 **발행**(`publish`) — 이때 판매 중인 **수강권 상품(T-PASS) 연결**(`link_tpass`)을 제안받습니다.
5. **노출 토글**(`toggle_visible`)로 학생 노출을 켜고 끕니다.
6. 카테고리는 이 화면에서 함께 관리(`save_category`/`delete_category`).

**주의**
- **에디션 삭제**(`delete_edition`)·**시리즈 삭제**(`delete_series`)는 **수강 이력이 있으면 차단**됩니다(soft-delete + 가드). 실수 삭제 방지 장치입니다.

### 1-3. 에디션 상세 — 회차·영상·교재

- **화면**: 강의 시리즈·에디션 → 에디션 카드 클릭 (`/admin/lms/courses/:courseId`)
- **무엇을**: 회차(lesson) 등록·순서·공개, 영상 등록/교체, 교재 첨부, 강사 배정, 회차별 단원(체계도) 연결.

**테스트 순서**
1. **회차 추가**(`add_lesson`) → 제목·회차번호 입력. 순서는 **위/아래 이동**(`move_lesson`).
2. 각 회차에 **영상 등록/교체**(`set_video`) — 1-1에서 동기화한 콜러스 콘텐츠를 선택.
3. **재생 횟수 제한**(`set_lesson_max_plays`)으로 회차별 시청 한도 설정(선택).
4. **교재 첨부**(`add_material`) — 파일 업로드(최대 50MB), 공개 토글(`toggle_material`).
5. **강사 배정**(`add_instructor`) — 복수 강사 가능.
6. **단원 연결**(`set_lesson_nodes`) — 회차를 체계도 노드에 연결(학습 연계).
7. **회차 공개**(`toggle_lesson`)로 학생 노출 제어.
8. **운영 메모**(`save_memo`)에 내부 기록.

**주의**
- 영상을 **교체**해 길이(duration)가 달라지면 시청 배수 모수가 어긋날 수 있습니다 → **길이 변동 조정**(`apply_duration_adjust`)으로 반영. 그렇지 않으면 경고만 뜹니다.
- **회차 삭제**(`delete_lesson`)·**에디션 삭제**는 soft-delete + 수강 이력 가드.
- 모든 변경은 **변경 이력(audit)**에 남습니다.

### 1-4. 영상 수강권 관리 (수동 지급)

- **화면**: 운영관리 → 강의·도서몰 → **영상 수강권** (`/admin/lms/enrollments`) · **매니저+**
- **무엇을**: 결제 외 경로(이관·이벤트·직원용)로 수강권을 수동 지급/조정합니다. 모든 쓰기는 **감사 로그(`enrollment_admin_logs`)**에 남습니다.

**테스트 순서 / 액션**
- **지급**(`grant`) — 회원 검색 후 특정 에디션 수강권 부여.
- **연장**(`extend`) / **기간 직접 지정**(`set_dates`).
- **차단**(`set_blocked`) / **일시정지·재개**(`pause`/`resume`).
- **시청 배수·포인트 조정**(`credit`) / **사용량 리셋**(`reset_usage`).
- **회수**(`revoke`).

**확인 포인트**: 수동 지급은 **정산(매출)에 포함되지 않습니다**(무상 부여). 이벤트/보상 성격.

### 1-5. 기기 관리 (CS 최다 문의)

- **화면**: 운영관리 → 강의·도서몰 → **기기 관리** (`/admin/lms/devices`) · **매니저+**
- **무엇을**: 회원 검색 → 등록 기기 목록 확인 → **강제 초기화**(월 교체 제한 무시). 학생이 "기기 변경이 안 돼요" 문의 시 여기서 풀어 줍니다.

**테스트**: 테스트 계정으로 여러 기기 로그인 → 이 화면에서 강제 초기화 → 재등록 되는지 확인.

### 1-6. 수강평·교재평 관리

- **화면**: 운영관리 → 강의·도서몰 → **수강평·교재평** (`/admin/lms/reviews`)
- **상태**: 현재 **숨김**(`REVIEWS_ENABLED=false`). 재오픈 시 사이드바에 자동 복원됩니다.
- **액션(참고)**: 작성 적립 포인트 설정(`set_reward_points`), 블라인드(`toggle_blind`), 베스트(`toggle_best`), 운영자 답변(`reply`), 삭제(`delete`).

## 2. 도서몰

### 2-1. 도서 관리

- **화면**: 운영관리 → 강의·도서몰 → **도서 관리** (`/admin/books`, 신규 `/admin/books/new`)
- **무엇을**: 교재 등록·판매상태·재고·강의 상품 연결.

**테스트 순서**
1. **도서 등록**(`/admin/books/new`) — 제목·가격·표지 등. **미리보기 이미지 추가**(`add_preview`).
2. **카테고리 추가**(`cat_add`) 및 도서 **이동·정렬**(`move_book`).
3. **판매상태 변경**(`set_status`) — 판매중/품절/숨김.
4. **재고 입고**(`inbound`) — 입고 수량을 원장에 기록. (재고 추적 도서는 재고 0이면 결제 단계에서 자동 차단)
5. **강의 상품 연결**(`link_plan`) — 특정 강의 상품에 부속 교재로 묶기.

### 2-2. 세트·번들

- **화면**: 운영관리 → 강의·도서몰 → **세트·번들** (`/admin/book-bundles`)
- **무엇을**: 여러 도서를 묶은 세트 상품. 결제 시 **정가 비율로 배분**(정산 정확도).
- **액션**: 생성(`create`), 판매상태(`set_status`), 구성 도서 추가/제거(`add_item`/`remove_item`).

### 2-3. 배송 관리

- **화면**: 운영관리 → 강의·도서몰 → **배송 관리** (`/admin/shipments`)
- **무엇을**: 도서 주문의 배송 상태·택배사·송장을 갱신하면 **즉시 학생 마이페이지에 반영**됩니다. **무료배송 임계금액**(`set_free_shipping`)도 여기서 설정.

**테스트 순서**
1. 상태 필터로 **배송 대기** 주문을 봅니다(허브 워크큐에서도 진입 가능).
2. 택배사·송장번호 입력 후 상태를 **배송중 → 배송완료**로 갱신.
3. 학생 화면(`/lecture/orders`)에서 반영 확인.

## 3. 주문·결제·환불

### 3-1. 주문 관리 (항목·환불)

- **화면**: 운영관리 → 매출·정산 관리 → **주문 관리 (항목·환불)** (`/admin/orders`) · **매니저+**
- **무엇을**: 주문을 **항목 단위**로 보고, **부분 환불**(토스 부분취소 + 지급물 회수)·**무통장 입금 확인**을 처리합니다.

**테스트 순서**
1. 테스트 결제(3-3)를 만든 뒤 이 화면에서 주문을 찾습니다.
2. **무통장 입금 확인**(`confirm_transfer`) — 계좌이체 주문을 입금 확인 처리하면 수강권/도서가 지급됩니다.
3. **환불 처리**(`resolve_refund`) — 학생이 접수(`/api/refund-request`)한 환불을 승인/처리. 부분 환불 시 해당 항목의 수강권·재고가 회수됩니다.

**주의**: 환불은 **실제 결제사(토스) 취소**가 일어납니다. 테스트는 소액/테스트키로.

### 3-2. 주문·결제 관리(집계)

- **화면**: 운영관리 → 매출·정산 관리 → **주문·결제 관리** (`/admin/payments`) · **매니저+**
- **무엇을**: 기간·상품 필터 + 일/주/월 집계 + **결제내역/환불내역 탭**. 읽기 중심(무통장 확정은 주문 관리와 연동).

### 3-3. 테스트 결제 만들기

학생 계정으로 `/lecture/catalog`(수강신청) 또는 `/lecture/books`(도서구입)에서 상품을 장바구니에 담아 결제합니다. 카드 결제는 **토스 테스트키**, 계좌이체는 무통장으로 만든 뒤 3-1에서 입금 확인을 눌러 흐름 전체를 확인하세요.

## 4. 상품·요금·할인·쿠폰

### 4-1. 상품·요금 관리

- **화면**: 운영관리 → 상품 관리 → **상품·요금 관리** (`/admin/pricing`) · **매니저+**
- **무엇을**: 개별 과목·번들·회원제 상품의 **가격·부여 과목·기능·기간·활성**을 편집. 강의 수강권(T-PASS)도 여기서 상품으로 정의해 에디션에 연결합니다.

### 4-2. 할인 관리

- **화면**: 운영관리 → 상품 관리 → **할인 관리** (`/admin/discounts`) · **매니저+**
- **무엇을**: 기간·조건·코드 할인 정의. 자동 프로모션은 요금표에 즉시 반영.

### 4-3. 수강권 관리 (학생별 인스턴스)

- **화면**: 운영관리 → 상품 관리 → **수강권 관리** (`/admin/subscriptions`) · **매니저+**
- **무엇을**: 학생별 수강권 조회 + **재량 조정**(수동 부여/연장/취소). **사유 필수 + 감사 로그**.
- **액션**: 회원 검색(`find_user`) → 부여(`grant`)/연장(`extend`)/취소(`cancel`).
- **주의**: 수동 부여는 정산 매출에 포함되지 않습니다.

### 4-4. 쿠폰 관리

- **화면**: 운영관리 → 매출·정산 관리 → **쿠폰 관리** (`/admin/coupons`, 신규 `/admin/coupons/new`)
- **무엇을**: 할인 쿠폰 정의(범위·할인혜택·유효기간·사용일수·공용여부·상태) + 특정 회원에게 **발급/회수**.
- **액션**: 편집 화면에서 발급(`grant`)/회수(`revoke`), 목록에서 삭제(`delete`). 장바구니 적용 미리보기 `/api/coupons/preview-cart`.
- **1인 1회** 등 사용 제한은 쿠폰 정의에서 지정. 테스트 계정으로 장바구니에 넣어 실제 할인액을 확인하세요.

## 5. 정산

> 정산은 **모두 매니저+**. 흐름은 공통: **월 선택 → 생성(초안) → 대상별 확정 → 지급완료**. 초안은 **재생성 가능**, 확정 후에는 스냅샷으로 고정(이중 계상 방지·환불 차감 반영).

### 5-1. 강사 배분 기준

- **화면**: 매출·정산 관리 → **강사 배분 기준** (`/admin/settlements/rules`)
- **무엇을**: 강사 × 대상(상품 > 과목 > 전체) × **정률/정액** 규칙. 규칙 변경은 "새 규칙 추가 + 기존 비활성" 패턴(세대교체).
- **액션**: 생성(`create`), 활성/비활성(`toggle`).

### 5-2. 강사 정산

- **화면**: 매출·정산 관리 → **강사 정산** (`/admin/settlements`, 상세 `/:settlementId`)
- **테스트 순서(리허설 권장)**
  1. 월 선택 → **정산 생성**(`generate`) — 초안이 만들어집니다(몇 번을 눌러도 재생성).
  2. 상세에서 강사별 금액 확인 → **확정**(`confirm`).
  3. 지급 후 **지급완료**(`mark_paid`).
- **주의**: 환불이 있으면 자동 차감됩니다. 확정 전 금액을 꼭 검토하세요.

### 5-3. 도서 정산

- **배분 기준**: **도서 배분 기준** (`/admin/settlements/books`) — 도서 × 저자/출판사 × 정률/정액. 생성/토글.
- **정산 실행**: **도서 정산** (`/admin/settlements/book-runs`, 상세 `/:settlementId`) — 월 선택 → 생성 → payee별 확정 → 지급완료. 흐름은 강사 정산과 동일.

### 5-4. Q&A 답변 적립

- **화면**: 매출·정산 관리 → **Q&A 답변 적립** (`/admin/settlements/qna-rewards`)
- **무엇을**: 강사 Q&A 답변에 대한 적립 기준 설정(`settings`)·지급(`payout`).

## 6. 매출·통계 (읽기 전용)

- **매출 통계** (`/admin/sales/stats`, 매니저+) — 상품유형별(**정기구독·강의·도서**) 매출·환불·순매출, 강의유형/과목/도서카테고리 **필터**, 상품 **랭킹**, **CSV 내보내기**, 기간 커스텀.
- **구독 통계** (`/admin/subscriptions/stats`, 매니저+) — 활성·자동갱신 유지율·해지 예정·해지율·순증.
- **허브 KPI 밴드** (`/admin`, 매니저+) — 순매출·환불율·활성구독·해지율·만료임박·구독순증을 한눈에. 각 지표에서 상세 화면으로 링크.

> 테스트 결제/환불을 몇 건 만든 뒤 이 화면들에서 숫자가 맞게 집계되는지 대조하면 좋습니다.

## 7. 강의 플랫폼 콘텐츠 (랜딩/마케팅)

> 강의 홈(`/lecture/home`)과 리담안내에 노출되는 콘텐츠. 대부분 staff. 목록에서 **추가/수정/삭제/순서 변경**.

| 화면 | 경로 | 무엇을 |
|---|---|---|
| **히어로 배너** | `/admin/landing-banners` | 강의 홈 상단 캐러셀 배너 추가·순서·삭제 |
| **공부방법·맛보기 영상** | `/admin/lecture-videos` | 강의 홈 짧은 영상. **유튜브 URL** 또는 **콜러스 클립**(provider 토글) — LMS 회차 영상과 별개인 홍보용 |
| **현장강의 일정** | `/admin/lecture-schedules` | 오프라인 강의 일정표 CRUD |
| **리담소식** | `/admin/lecture-news` | 공지/소식 게시글(상단 고정 핀) |
| **시험정보** | `/admin/exam-info` | 변리사 시험 일정·과목·기준(구조화 폼 → JSONB 저장) |
| **시험 공고** | `/admin/exam-notices` | 공고 + 첨부파일 업로드 |

**맛보기 영상 테스트**
1. `/admin/lecture-videos/new` → provider를 **유튜브**로 두고 URL 붙여넣기 → 저장 → 강의 홈에서 라이트박스 재생 확인.
2. provider를 **콜러스**로 바꿔 콘텐츠 라이브러리의 짧은 클립을 선택 → 저장 → 재생 확인.
   - ⚠ 맛보기는 **짧은 홍보 클립만** 올리세요(전체 유료 강의를 공개 클립으로 노출 금지).

## 10. 테스트 체크리스트 (요약)

강의 플랫폼 오픈 전 아래를 한 번씩 확인하세요.

- [ ] **콘텐츠 라이브러리** 콜러스 동기화 → 영상이 중복 없이 뜨고 미리보기 재생됨
- [ ] **에디션** 생성 → 회차에 영상 붙임 → **발행** → 학생 노출 토글 ON
- [ ] **상품·요금**에서 수강권 상품 생성 → 에디션에 **T-PASS 연결**
- [ ] (선택) **할인/쿠폰** 설정 → 장바구니에서 실제 할인액 확인
- [ ] **테스트 결제**(카드=테스트키 / 무통장) → 수강권/도서 지급됨
- [ ] **주문 관리**에서 무통장 입금 확인·부분 환불 동작
- [ ] **영상 수강권**·**기기 관리**로 수동 지급·기기 초기화 동작
- [ ] **도서 등록**·재고 입고 → 결제 → **배송 관리**에서 송장 갱신 → 학생 화면 반영
- [ ] **매출/구독 통계**에 방금 만든 결제·환불이 집계됨
- [ ] **강의 홈 콘텐츠**(배너·맛보기 영상·일정·소식) 노출 확인
- [ ] **정산**(강사/도서) 리허설: 생성 → 확정 → (실지급 전) 금액 검토
- [ ] 각 삭제 액션이 **수강 이력 있으면 차단**되는지(안전장치) 확인
