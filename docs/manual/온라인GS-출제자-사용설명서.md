# 온라인 GS — 강사·운영자 사용설명서

> 이 설명서는 강사·운영자(staff) 분들이 **온라인 GS 회차**(주관식 모의·정기 모의)를 만들고, 답안을 채점하고, 우수 답안을 공개하기까지의 전체 흐름을 안내합니다.

---

## 한눈에 보는 전체 흐름

```
[주 흐름] 출제 → 응시 → 채점 → 공개

1) 시리즈 만들기      → 2) 회차 만들기        → 3) 학생 응시·제출
   (선택, 정기 묶음)     (문제 + 답안지 PDF)      (페이지 사진 업로드)
                                                    ↓
4) 채점                ← 5) 동료 채점 (선택)  ← 학생 제출 마감
   (운영자 직접 +         (학생 익명 상호 채점,
    동료 채점 종합)        분쟁 큐로 점검)
                                                    ↓
6) 우수 답안 선정 → 공개 + 포인트 지급 → 학생 열람


[부가 흐름] 같은 문항을 가벼운 반복 학습 자료로

7) 모범답안에서 핵심 논점 추출 → 8) 학생에게 노출
   (AI 보조 + 운영자 승인)         (/gs/issues 빠르게 반복 모드)


[모니터링]

9) AI·OCR 사용량 한도 / 일별 합계      — /admin/gs/usage
```

핵심 원칙:
- **회차 단위 운영** — 시리즈는 회차들을 묶는 컨테이너(예: "주간 GS 1기"). 회차 없이도 운영 가능.
- **종이에 손글씨 → 페이지 사진 업로드** — 학생이 답안지 PDF를 받아 종이에 작성, 페이지별로 촬영해서 올리는 모델. 디지털 에디터가 아닙니다.
- **채점 흐름 다양화** — 운영자 직접 채점 + 동료 채점(선택) + 분쟁 검토 큐.
- **우수 답안 공개** — 회차 종합 + 문항별로 마킹, 익명 또는 실명으로 공개, 포인트 지급.
- **2차 논점 추출 훈련** — 같은 회차 문항을 "답안 전체 작성 없이 핵심 쟁점만 빠르게 뽑는" 가벼운 학습 모드로 재활용. 강사가 모범 논점을 등록·승인하면 학생에게 노출됩니다.
- **AI·OCR 비용 가드** — AI 채점 초안, 손글씨 OCR, 논점 추출/분석에 일일 한도가 걸려 있어 폭주 방지. `/admin/gs/usage` 에서 잔여 한도·일별 비용 확인.

---

## 어디서 들어가나요? (운영관리 메뉴 위치)

상단 네비게이션의 **운영관리** 클릭 → 좌측 사이드바 **"주관식 문제"** 클러스터:

```
운영관리 (사이드바)
└─ 주관식 문제
   ├─ 주관식 회차          ← 회차 만들기·채점·우수답안 선정
   ├─ 주관식 시리즈        ← 회차 묶기 (선택)
   ├─ 포인트 관리          ← 학생 포인트 수동 지급/차감
   └─ AI·OCR 사용량        ← 일일 한도·일별 비용·캡 도달 알림
```

> 회차마다 별도의 운영 화면이 있습니다(메타/문제 편집 · 채점 · 동료 채점 운영 · 분쟁 큐 · 우수 답안 · **논점 관리**). 이 메뉴들은 회차 목록에서 회차를 클릭하면 진입할 수 있습니다.

---

# 1단계 — 시리즈 만들기 (선택)

화면: **/admin/gs/series**

여러 회차를 **하나의 묶음**(예: "2026 주간 GS", "민법 정기 모의 1기")으로 운영할 때 만듭니다. 단발성 회차만 운영한다면 건너뛰셔도 됩니다.

## 1-1. 시리즈 만들기

사이드바 **"주관식 시리즈"** → **"새 시리즈"** 클릭:
- **제목** (예: "2026 주간 GS — 특허법")
- **과목** 선택
- **설명** (선택)
- 저장 → 시리즈 상세로 이동

## 1-2. 통계 보기

시리즈 상세 우측 상단의 **"시리즈 통계"** 버튼 → 회차별 응시율·평균 점수 추이.

---

# 2단계 — 회차 만들기

화면: **/admin/gs** (회차 목록) → **"새 회차"** 클릭 → **/admin/gs/new**

## 2-1. 회차 메타 입력

| 항목 | 설명 |
|---|---|
| **제목** | 예: "특허법 1차 모의 — 2026.6주차" |
| **과목** | 5개 과목 중 하나 |
| **설명** (선택) | 학생에게 보일 안내문 |
| **시작 시각 / 종료 시각** | 응시 가능 구간 (KST) |
| **응시 제한 시간** | 분 단위 (예: 120) — 시작 ~ 종료 사이 + 본인 시작 후 N분 중 빠른 쪽 마감 |
| **상태** | 초안 (draft) / 공개 (published) / 종료 (closed) |
| **시리즈 / 회차 번호** (선택) | 시리즈 묶을 때 |
| **답안지 페이지 수** | 학생이 업로드해야 하는 총 페이지 수 (예: 8) |

> 💡 **초안 상태일 때만 학생에게 안 보입니다.** 모든 준비가 끝나면 "공개"로 전환하세요.

## 2-2. 답안지 PDF 업로드

회차 편집 화면 상단 **"답안지 PDF"** 영역:
- **시험지 PDF**: 학생이 받아 종이에 출력 → 손글씨 작성용 답안지
- **모범답안 PDF**: 채점 완료 후 학생에게 공개 (선택)

업로드한 PDF는 학생 화면에서 **"답안지 다운로드"** 버튼으로 받습니다.

## 2-3. 문제 만들기

회차 편집 화면 본문의 **"문제 목록"**:
- **"문제 추가"** → 본문(필수), 모범답안(선택), 만점, 채점 루브릭(선택) 입력
- 순서는 드래그로 변경
- **삭제** 버튼으로 제거

### AI 초안 생성 (선택)

각 문제 카드에서 **"AI 초안"** 버튼 → 같은 과목 자료 기반으로 본문/모범답안/루브릭 초안을 자동 생성. 결과는 강사가 검토·수정 후 저장.

### 채점 루브릭

만점 100점이면 예시:
- "결론 명시" 20점
- "조문 인용 정확성" 30점
- "판례 적용" 30점
- "결론 도출 논리" 20점

루브릭이 있으면 채점 화면에서 항목별 점수 입력 + 합산 자동 계산.

## 2-4. 공개

메타 영역의 **"상태"** 를 **공개(published)** 로 변경 → 시작 시각이 도래하면 학생에게 노출.

---

# 3단계 — 채점

## 3-1. 어디서 들어가나

회차 편집 화면 상단의 **"채점 목록"** 버튼 → **/admin/gs/{roundId}/grade**

또는 사이드바 → 주관식 회차 → 회차 클릭 → 우측 상단 액션.

## 3-2. 채점 목록 화면

| 컬럼 | 설명 |
|---|---|
| 학생 | 학생 이름 |
| 제출 시각 | 제출 완료 시각 |
| 페이지 수 | 업로드한 페이지 (예상치와 비교) |
| 동료 채점 평균 | 동료 채점이 켜져 있다면 평균 점수 |
| 채점 상태 | 미채점 / 진행중 / 완료 |
| 액션 | "채점 →" 버튼 |

## 3-3. 한 학생 채점 (운영자 직접)

학생 행의 **"채점 →"** 클릭 → 답안지 갤러리 + 문항별 채점 카드.

화면 구성:
- **좌측**: 답안지 페이지 미리보기 (학생이 업로드한 순서대로)
- **우측**: 문항별 카드
  - 본문 + 모범답안 (펼침)
  - **점수 입력란** (0 ~ 만점)
  - **피드백 작성란** (Markdown)
  - 루브릭이 있으면 항목별 점수 입력
  - **동료 채점 참고 패널** — 다른 학생들이 매긴 점수·코멘트 (켜진 경우)

### 채점 완료(잠금)

모든 문항 입력 후 화면 하단 **"채점 마무리(잠금)"** 버튼 → submission 잠금 + 학생에게 결과 공개.

### 재열기

잠금 후 수정이 필요하면 **"채점 다시 열기"** — 학생 결과 화면은 일시 "재채점 중"으로 변경.

# 4단계 — 동료 채점 운영 (선택)

학생들끼리 익명으로 서로 답안을 채점하는 흐름. 학습 효과↑ + 운영자 부담↓.

## 4-1. 자동 배정 cron

회차 종료 시각이 지나면 cron(`/api/cron/gs-auto-assign`)이 제출한 학생들에게 **다른 학생 답안 1~2건** 을 자동 배정. 배정된 학생은 `/gs` 대시보드에서 "내가 채점해야 할 답안" 패널을 봅니다.

## 4-2. 분쟁 큐 (표준편차 큰 문항)

화면: **/admin/gs/{roundId}/peer-review** 또는 회차 액션 메뉴 **"분쟁 큐"**

채점자 간 점수 표준편차가 큰 (제출, 문항) 쌍을 보여줍니다:
- 기본 threshold = 만점 대비 0.15 (15%) — 임의 조정 가능
- 최소 채점자 수 = 2명
- 분쟁 의심 항목 클릭 → 운영자가 직접 채점하거나 동료 점수 무효화 가능

> ⚠ **동료 점수는 학생 최종 점수에 자동 반영되지 않습니다.** 운영자가 직접 채점한 점수가 최종 — 동료 채점은 학생 학습용 + 운영자 참고용입니다.

---

# 5단계 — 우수 답안 선정·공개·포인트

화면: **/admin/gs/{roundId}/distinctions** (회차 액션 → **"우수 답안"**)

## 5-1. 화면 구성

회차 종합 또는 문항별로 우수 답안 마킹:
- **자동 추천**: 상위 N명 (점수 기준) 자동 노출
- **수동 마킹**: 추가 답안 선택 + **포인트 지급량** 입력
- **공개 옵션**: 공개 / 비공개
- **익명 옵션**: 익명 / 실명

## 5-2. 포인트 지급

마킹 시 입력한 포인트(예: 100p)가 학생 잔액에 자동 가산. 학생은 `/gs/points` 에서 본인 잔액·거래 내역 확인.

## 5-3. 학생 열람

공개 마킹된 답안은 `/gs/{roundId}/distinguished` 에서 학생들이 볼 수 있습니다:
- 회차 우수 답안 (전체 문제 통합)
- 문항별 우수 답안

---

# 6단계 — 회차 운영 정리

## 6-1. 회차 종료

- 종료 시각이 지나면 자동으로 마감 (학생 응시 차단)
- 상태를 **closed** 로 명시 전환 가능

## 6-2. 회차 통계

회차 액션 메뉴 **"회차 통계"** → **/admin/gs/{roundId}/stats**:
- 응시율, 평균 점수, 문항별 점수 분포
- 미응시 학생 목록 (재공지 발송 시 활용)

## 6-3. 시리즈 통계

시리즈 단위로 묶은 경우 **/admin/gs/series/{seriesId}/stats** 에서 회차 추이를 한 화면에서.

## 6-4. 포인트 수동 조정

화면: **/admin/gs/points** (사이드바: **포인트 관리**)

- 학생 잔액 상위 200명 표시
- 행별 **+/-** 입력 → 사유 적으면 거래 로그에 기록

# 자주 묻는 질문

### Q. 시리즈 없이 회차만 운영해도 되나요?
A. 네. 시리즈는 묶음 컨테이너일 뿐, 회차 단독 운영도 가능합니다.

### Q. 학생이 페이지 순서를 잘못 올렸을 때 운영자가 고칠 수 있나요?
A. 학생 본인이 응시 화면에서 페이지 swap·끼워넣기로 정정해야 합니다. 운영자 직접 수정은 무결성 사유로 제공하지 않습니다(분쟁 시 동료 채점/운영자가 페이지 매핑 표시로 추적 가능).

### Q. 동료 채점 점수가 학생 최종 점수에 반영되나요?
A. **반영되지 않습니다.** 학생 최종 점수는 운영자가 입력한 점수입니다. 동료 채점은 학생 학습용 + 운영자 참고용.

### Q. 동료 채점에서 부정 채점(악의적 0점 등)이 있으면?
A. **분쟁 큐**(표준편차 기준)에서 발견 → 운영자가 해당 동료 채점을 무효화하거나, 학생에게 경고.

### Q. AI 초안으로 만든 문제도 강사 검토가 필요한가요?
A. **네, 필수입니다.** AI 초안은 본문·모범답안·루브릭 초안일 뿐이며, 강사가 저장 전에 반드시 검토·수정해야 합니다.

### Q. 한 회차를 끝낸 후 우수 답안 마킹을 미루어 진행해도 되나요?
A. 네. 채점 완료가 우선이며, 우수 답안 마킹·포인트 지급은 며칠 뒤에 해도 됩니다. 다만 학생들이 빨리 볼수록 학습 동기가 ↑.

### Q. 오프라인 답안지가 아니라 디지털 에디터로 받을 순 없나요?
A. 현재 모델은 **종이 손글씨 → 페이지 사진 업로드** 입니다. 변리사 2차 실전 환경(종이 답안지)에 맞추기 위함이며, 디지털 에디터는 별도 검토 후 도입.

# 체크리스트 — 한 회차 운영 순서

> 모든 경로는 **운영관리 → 주관식 문제** 사이드바에서 진입 가능.

## 회차 만들기 직전
- [ ] (선택) **"주관식 시리즈"** — 묶을 시리즈가 없으면 만들기
- [ ] **"주관식 회차"** → "새 회차" — 메타 입력 (제목·과목·시간·답안지 페이지 수)
- [ ] **답안지 PDF 업로드** (시험지 + 모범답안)
- [ ] **문제 추가** (필요 시 AI 초안 → 검토·수정)
- [ ] **루브릭** 입력 (선택, 채점 일관성↑)
- [ ] **상태 = 공개(published)** 전환

## 응시 중
- [ ] 회차 통계로 응시율 모니터링
- [ ] 미응시자 재공지 발송 (선택)

## 회차 종료 후
- [ ] **채점 목록** 진입 → 학생별 채점 진행
- [ ] (선택) **동료 채점 분쟁 큐** 검토
- [ ] 모든 학생 채점 마무리(잠금)

# 부가 1단계 — 2차 논점 추출 훈련 (선택)

화면: 회차 편집 헤더의 **"논점 관리"** 버튼 → **/admin/gs/{회차ID}/issues**

이 회차의 GS 문항을, 학생이 **답안 전체 작성 없이 핵심 쟁점만 빠르게 뽑는 가벼운 반복 학습** 으로 재활용할 수 있게 만드는 단계입니다. 모범 논점이 등록되고 강사가 **승인**해야 학생 화면에 노출됩니다.

## 부가 1-1. AI 로 논점 초안 추출

좌측 문항 목록 → 문항 클릭 → 우측 **"AI 로 논점 추출"** 클릭:
- 그 문항의 모범답안에서 3~8 개 핵심 논점이 `review_status='draft'` 로 일괄 생성
- 비용 가드 한도 도달 시 503 ("AI 채점 초안 일일 한도 도달") — 자동 차단

## 부가 1-2. 검수 → 승인

각 draft 카드:
- **수정**: 라벨 · 설명 · importance(핵심/부차) · ref_hint 인라인 편집
- **승인**: 학생 화면에 노출 가능 (`review_status='approved'`)
- **반려**: 사유 입력 후 숨김 (`review_status='rejected'`)
- 상단 툴바: 체크박스 다중 선택 → **일괄 승인**

## 부가 1-3. 학생 노출 게이트

- **승인된 논점만** 학생 화면(`/gs/issues`) 에 노출 — 서버에서 재검증
- 학생이 직접 URL 로 진입해도 미승인 문항은 404
- 미승인 채로 두면 그 문항은 학생 색인에서 미노출

# 부가 2단계 — AI·OCR 사용량 모니터링

화면: **/admin/gs/usage**

AI 채점 초안 / 손글씨 OCR / 논점 추출 / 논점 분석의 **일일 비용 합계와 한도** 를 확인합니다. 회차 실운영 전 비용 폭주 방지가 목적.

## 부가 2-1. 한도

| 종류 | 환경변수 | 동작 |
|---|---|---|
| AI 합산 (채점 초안 + 논점 추출 + 논점 분석) | `GS_AI_DAILY_COST_USD_CAP` | 도달 시 새로운 AI 호출 503 차단 |
| OCR | `GS_OCR_DAILY_PAGE_CAP` | 도달 시 페이지 업로드는 계속, OCR 분석만 skip |

## 부가 2-2. 화면

- **오늘 합계** — AI 비용 + OCR 페이지 수 + 합계 비용
- **일별 / 회차별** — 최근 N일 추이, 회차별 합계
- **알림** — 캡 도달 시 staff 알림 1회 발송 (`gs_cap_reached`)

## 부가 2-3. OCR cap 정책

OCR 한도 도달 시:
- ✓ 학생 페이지 업로드는 **계속 가능** (응시는 막지 않음)
- ✓ AI 채점 초안은 **OCR 텍스트 없이도 진행** (이미지 직접 분석 폴백)
- 다음날 자동 리셋
