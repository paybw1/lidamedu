# 2차 주관식 학습 — 강사·운영자 사용설명서

> 이 설명서는 강사·운영자(staff)가 2차 주관식 **앞단 훈련**(논점추출 · 결론·강약)을 출제·운영하는 방법을 안내합니다.
> 답안작성·채점(온라인 GS)의 운영은 별도 문서(`온라인GS-출제자-사용설명서.md`)를 참고하세요. 이 설명서는 그 **앞 단계**를 다룹니다.

---

## 전체 그림 — 무엇을 출제하나

학생의 2차 훈련은 한 판례(또는 GS 문제)를 다음 순서로 풉니다:

```
② 논점추출 (쟁점 백지 추출)  →  ③④ 결론·강약 (결론 + 목차 강약)  →  ⑤ 답안작성 (온라인 GS)
```

> 번호 체계: ① 기본목차 암기(미구현) / **② 논점추출** / **③ 결론도출 + ④ 응용목차(강약)** / **⑤ 답안작성**. 이 설명서는 강사가 직접 출제하는 ②·③④와 ⑤ 연결을 다룹니다.

강사는 이 중 **②논점추출과 ③④결론·강약을 출제**합니다. 핵심은 — **AI가 초안을 만들고, 강사가 검토·승인**합니다. 승인된 것만 학생에게 노출됩니다.

| 출제 대상 | 화면 |
|---|---|
| 판례 기반 논점추출 + 결론·강약 | **운영관리 → 판례 → 판례 쟁점훈련 출제** (`/admin/case-training`) |
| GS 문제 기반 논점추출 | **운영관리 → 주관식 문제 → 주관식 회차** → 회차 편집 → **"논점 관리"** 버튼 (`/admin/gs/:roundId/issues`) |

> **③④ 결론·강약은 별도 화면이 아니라**, 판례 훈련 편집 화면 **하단 섹션**에서 같이 출제합니다. 한 화면에서 사실관계·쟁점·결론·강약·GS 연결을 모두 처리합니다.

---

# 1. 판례 기반 훈련 출제 (논점추출 + 결론·강약)

화면: **운영관리 → 판례 → 판례 쟁점훈련 출제** → **/admin/case-training**

## 1-1. 신규 출제 — 판례 선택

1. 목록 화면(헤더 "판례 기반 쟁점추출 훈련")에서 **"신규 출제"**.
2. **"판례 선택 — 훈련 항목 신규 출제"** 화면에서 검색해 판례를 고릅니다.
   - 각 판례의 **"선택"** 버튼으로 항목을 만듭니다.
   - **"전문 없음" 칩**이 붙은 판례는 선택할 수 없습니다(전문이 적재돼야 훈련 재료가 됩니다). 전문 적재는 판례 전문 적재 파이프라인을 참고하세요.

## 1-2. 사실관계 요약 작성

편집 화면에서:
- **"사실관계 요약"** 란에 학생에게 사례로 제시할 텍스트를 작성합니다.
- **"AI 초안"** 버튼으로 판례 전문에서 자동 초안을 받을 수 있습니다(검토·수정 후 사용).
- ⚠ **누출 주의**: 사실관계에 **쟁점·판단·결론이 들어가면 안 됩니다**(학생이 답을 미리 보게 됨). 시스템이 쟁점/판시사항/결론 키워드를 감지하면 **누출 lint 경고**를 띄웁니다. 경고가 뜨면 해당 표현을 사실 위주로 고치세요.

## 1-3. 쟁점 목록 작성·승인

- **"쟁점 목록"** 섹션에서 **"AI 초안 추가"** 로 모범 쟁점을 자동 생성하거나 직접 추가합니다.
- 각 쟁점은 **행 단위로** 다룹니다: **핵심 / 부차** 칩 지정, 편집, **승인 / 취소 / 삭제**.
- **승인된 쟁점만** 학생 채점 기준이 됩니다.

## 1-4. 항목 승인 (학생 노출 조건)

- 항목을 승인하려면: **사실관계 50자 이상 + 승인된 쟁점 2건 이상**.
- 승인(상태 chip)해야 학생 목록에 노출됩니다. 미승인 항목은 학생에게 보이지 않습니다(서버에서 차단).

---

# 2. 결론·강약 채점 기준 추가 (③④ — 같은 화면 하단)

같은 편집 화면(`/admin/case-training/:itemId`) **하단 "③ 결론도출 + ④ 응용목차 — 채점 기준 (선택)"** 섹션.

> ③④는 **선택 기능**입니다. 논점추출(②)만 운영해도 되고, 결론·강약까지 가르치려면 이 섹션을 채웁니다.

## 2-1. 쟁점별 결론·강약 입력

- 각 쟁점 행에:
  - **결론 방향**(자유 텍스트 — "인정" / "부정" / "성립" / "불성립" 등)
  - **근거**(짧게)
  - **권장 비중(weight, 0~100)** — **선택**. 비워두면 핵심=강조 / 부차=약하게로 자동 판정됩니다. 정밀하게 가르치고 싶은 문제만 숫자를 넣으세요.
- **"AI 결론·강약 초안"** 버튼으로 한 번에 모든 쟁점의 결론·근거·권장 강약 초안을 받을 수 있습니다(쟁점 2건 이상 필요, 검토·수정 후 사용).

## 2-2. 학생에게 ③④가 열리는 조건

- 결론 정보(결론 방향)가 있는 **승인 쟁점이 2건 이상**이면, 학생 목록에 **"③④ 결론·강약 →"** 버튼이 나타납니다.
- 그 전까지 학생은 논점추출(②)만 가능합니다.

## 2-3. ⑤ 답안작성(GS) 연결

- 하단 **"⑤ GS 답안작성 회차 연결 (선택)"** 드롭다운에서 GS 회차(최근 50건)를 고릅니다.
- 연결하면, 학생이 ③④를 마쳤을 때 **"답안 작성으로 →"** 버튼으로 그 GS 회차의 답안작성으로 바로 이어집니다.
- 연결하지 않아도 학생이 막다른 길에 빠지지 않습니다: 학생 ③④ Done 화면에 **"연결된 답안 작성 회차가 없습니다 — GS 메인으로 →"** 안내 카드가 자동으로 노출돼 학생을 **/gs** 회차 선택 화면으로 인도합니다.
- 마찬가지로 학생 ② Done 화면에도 **"다음 단계"** 박스가 떠서, ③④ 준비 / GS 회차 연결 / 둘 다 미연결 시나리오 각각에 맞는 안내를 노출합니다.

---

# 3. GS 문제 기반 논점추출 출제

화면: **운영관리 → 주관식 문제 → 주관식 회차** → 회차 편집 화면 → **"논점 관리"** 버튼 (`/admin/gs/:roundId/issues`)

판례 대신 **GS 회차의 모범답안**에서 논점을 뽑아 논점추출 훈련을 만드는 트랙입니다.

1. GS 회차 편집(`/admin/gs/:roundId`)에서 우측 액션의 **"논점 관리"** 버튼으로 별도 화면으로 이동합니다 (탭이 아니라 별도 라우트).
2. **"모범답안 미리보기 (논점 추출 source)"** 를 확인하고 **"AI 로 논점 추출"** 로 초안을 만듭니다.
3. 행 단위로 승인합니다.
4. 승인된 모범 논점이 1건 이상인 GS 문항이 학생의 **/gs/issues**(논점 추출 훈련) 목록에 노출됩니다.

> 학생은 이 트랙을 사이드바 **모의고사 → GS 논점추출**(`/gs/issues`) 또는 **/gs** 메인의 "논점 추출 훈련 진입 카드"로 들어갑니다. 두 진입 모두 같은 화면입니다.

---

## AI 사용·비용

- 논점추출·결론·강약의 AI 초안과 학생 AI 의견은 모두 **AI 사용량 가드**에 기록됩니다.
- 운영관리 **주관식 문제 → AI·OCR 사용량**(`/admin/gs/usage`)에서 사용량을 확인할 수 있습니다.
- 상한(cap)에 도달하면 AI 보조만 멈추고(학생 자기채점·강사 직접 출제는 계속), 핵심 기능은 막히지 않습니다.

---

## 출제 체크리스트 — 한 판례 항목

- [ ] **운영관리 → 판례 쟁점훈련 출제 → 신규 출제** — 판례 선택(전문 있는 것만)
- [ ] **사실관계 요약** 작성 (AI 초안 → 검토) — **누출 lint 경고 없도록** 쟁점·결론 제거
- [ ] **쟁점 목록** AI 초안 → 핵심/부차 지정 → 행 단위 승인 (2건 이상)
- [ ] **항목 승인** (사실관계 50자 + 승인 쟁점 2건)
- [ ] (선택) **③④ 섹션** — 쟁점별 결론·근거·(필요시 weight) 입력 또는 AI 초안
- [ ] (선택) **⑤ GS 회차 연결** 드롭다운
- [ ] 학생 화면에서 **② / ③④ 버튼 노출** 확인

## 자주 묻는 질문

### Q. 사실관계에 쟁점이 들어가면 왜 안 되나요?
A. 학생이 사실관계만 보고 쟁점을 **스스로 추출**하는 훈련이라, 사실관계에 쟁점·결론이 새면 답을 미리 보는 셈이 됩니다. 누출 lint 경고가 이를 잡아줍니다.

### Q. 결론·강약(③④)은 꼭 출제해야 하나요?
A. 아닙니다. 선택입니다. 논점추출(②)만으로도 훈련이 됩니다. 결론·강약까지 가르치려면 편집 화면 하단 섹션을 채우세요.

### Q. weight(비중)는 꼭 넣어야 하나요?
A. 아닙니다. 비워두면 핵심=강조/부차=약하게로 자동 판정됩니다. 정밀하게 강약을 가르치고 싶은 문제에만 숫자를 넣으세요.

### Q. AI 초안을 그대로 학생에게 노출해도 되나요?
A. 안 됩니다. AI 초안은 **반드시 강사가 검토·승인**해야 학생에게 노출됩니다. 사실관계 누출, 쟁점 정확성, 결론 방향을 확인하세요.

### Q. ③④와 답안작성(GS)을 어떻게 잇나요?
A. ③④ 편집 하단의 "GS 회차 연결" 드롭다운에서 회차를 고르면, 학생이 ③④를 마쳤을 때 그 회차 답안작성으로 가는 버튼이 생깁니다. 연결을 안 해도 학생 화면이 자동으로 "GS 메인으로 →" 안내 카드를 띄우니, 막다른 길로 빠지지는 않습니다.

### Q. 강사용 ③④ 전용 메뉴가 따로 있나요?
A. 없습니다. 판례 훈련 편집 화면 한 곳에서 사실관계·쟁점(②)·결론·강약(③④)·GS 연결을 모두 처리합니다.

### Q. GS 문제 기반 논점추출 진입이 회차 편집의 "탭"인가요?
A. 아닙니다. 회차 편집 화면(`/admin/gs/:roundId`)의 **"논점 관리"** 버튼을 누르면 별도 화면(`/admin/gs/:roundId/issues`)으로 이동합니다. 회차 메타·문항 편집과는 별개 라우트입니다.
