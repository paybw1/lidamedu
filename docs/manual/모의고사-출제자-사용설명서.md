# 1차 객관식 모의고사 출제 — 강사·운영자 사용설명서

> 이 설명서는 강사·운영자(staff) 분들이 **AI 도움을 받아 객관식 문제 초안을 만들고**, **강사가 검토·승인한 다음**, **모의고사로 출제**하는 전체 흐름을 안내합니다.

---

## 어디서 들어가나요? (운영관리 메뉴 위치)

상단 네비게이션의 **운영관리** 클릭 → 좌측 사이드바 **"객관식 문제 · OX"** 클러스터에 출제 흐름 순서대로 메뉴가 정렬되어 있습니다:

```
운영관리 (사이드바)
└─ 객관식 문제 · OX
   ├─ AI 문제 초안 만들기        ← 1단계 (이 설명서 §1)
   ├─ 검토 대기 문제             ← 2단계 (이 설명서 §2)
   ├─ 문제 직접 만들기           ← 강사가 처음부터 직접 출제할 때
   ├─ 전체 문제 보기
   ├─ OX 검수
   ├─ 정답률·통계
   ├─ 모의고사 팩 관리           ← 3단계 (이 설명서 §3-1 ~ §3-3) — 팩 만들기, 문제 추가 picker
   └─ 통합 모의고사 (3교시)      ← 3-4 (3교시 통합 시험 묶기)
```

> ⚠ **"모의고사 팩 관리" 메뉴는 학생용 화면(`/latest/mcq?kind=mock`)으로 이동합니다** — 클릭하시면 사이드바가 사라지고 상단 네비게이션으로 바뀝니다. 페이지 제목은 **"1차 모의고사 (전체)"** 로 표시되고, **전체 모의(mock_full) + 진도별 모의(mock_progressive) 두 종류가 한 목록에 같이 나옵니다**. 화면 상단 "구분" 필터에서 더 좁히실 수도 있습니다("└ 전체 모의" 또는 "└ 진도별 모의"). 강사 계정으로 들어가 있으면 같은 화면에 **문제 추가 picker** 와 **팩 편집 버튼** 이 자동으로 노출됩니다(학생에게는 안 보임). 다시 운영관리로 돌아오시려면 상단 네비게이션의 **운영관리** 클릭.

운영관리 **허브 화면** 상단 **"오늘 처리할 항목"** 좌측 첫 타일에 **"검토 대기 문제"** 카운터가 항상 떠 있습니다. 숫자가 0이 아니면 강사가 승인해야 할 초안이 쌓여 있다는 뜻 — 클릭하면 바로 검토 큐로 이동합니다.

---

## 한눈에 보는 전체 흐름

```
1) AI 초안 만들기 →  2) 강사 검토·승인 →  3) 모의고사 팩에 넣기 →  4) 학생 응시
   (/admin/problems/    (/admin/problems/    (/latest/mcq/<팩>)
    ai-gen)              review)
```

핵심 원칙: **강사가 승인한 문제만** 학생 화면(모의고사·학습과목·맞춤퀴즈)에 노출됩니다. AI가 만든 초안은 자동으로 "검증 큐"에 들어가고, **승인 도장**을 받기 전까지는 어디에도 안 보입니다.

# 1단계 — AI에게 문제 초안 만들게 하기

화면: **/admin/problems/ai-gen**

## 1-1. 화면 열기

**운영관리 → 객관식 문제 · OX → "AI 문제 초안 만들기"** 를 클릭하시거나, 주소창에 위 URL을 직접 입력하세요.

## 1-2. 입력 항목

| 항목 | 설명 | 권장값 |
|---|---|---|
| **과목** | 특허법 / 상표법 / 디자인보호법 / 민법 중 하나 | 만들고 싶은 과목 |
| **주요 조문 ID** (선택) | 특정 조문만 다루고 싶을 때 | 비워두면 과목 전체에서 자동 분산 |
| **단답형 수** | 일반 5지선다 문제 수 | 3~5 |
| **박스형 수** | 보기 ㄱㄴㄷㄹ에서 옳은 것 고르기 | 1~2 |
| **모델** | AI 모델 선택 | **Claude Sonnet 4.6 (권장)** |

> **합계 최대 30문항** (한 번에). 더 많이 만들고 싶으시면 여러 번 나눠서.

## 1-3. "생성 시작" 클릭

1-3분 정도 기다리시면 결과 리포트가 표시됩니다.

> **AI는 항상 우리 시스템에 등록된 조문·판례 본문을 근거로 출제합니다.** 근거 없이 지어내는 일이 없도록 설계되어 있습니다.

## 1-4. 결과 리포트 보기

화면 아래에 다음 카운트가 표시됩니다:

| 카드 | 의미 |
|---|---|
| **요청** | 강사가 입력한 문항 수 |
| **성공 생성** | 실제로 만들어진 문항 |
| **근거 부족 skip** | 그 조문에 대한 자료가 부족해 AI가 만들지 못한 문항 (자동 건너뜀) |
| **구조 경고** | "정답이 잘못 매겨진 것 같음" 등 자동 검사에서 걸린 문항 (그래도 저장되며 강사가 직접 판단) |
| **중복 의심** | 기존 문제와 매우 비슷한 문항 |
| **비용 (USD)** | 이번 생성에 든 AI 비용 |

**"생성된 문제"** 목록의 ID를 클릭하면 바로 그 문제 검토 화면으로 갑니다.

> 💰 **비용 안내**: Sonnet 4.6 모델 기준 1문항당 약 $0.05 (한화 70원 정도). 30문항 만들어도 $1.5 정도.

> ⚠️ **주의**: AI 초안은 **아직 학생에게 안 보입니다**. 다음 단계에서 강사가 검토·승인해야 출제 가능.

# 2단계 — 강사가 검토·승인하기

화면: **/admin/problems/review**

이 단계가 **가장 중요**합니다. AI가 만든 문제를 강사 눈으로 확인하고 도장을 찍는 곳.

## 2-0. 어디서 들어가나

세 가지 진입 경로 모두 같은 화면으로 갑니다:

1. **운영관리 → 객관식 문제 · OX → "검토 대기 문제"** (사이드바)
2. **운영관리 허브 → "오늘 처리할 항목" → "검토 대기 문제" 타일** (대시보드)
3. **AI 초안 만들기** 결과 화면에서 "생성된 문제" ID 클릭 → 자동 focus

> ⏱ **권장 작업 리듬**: 매일 운영관리 허브를 들어가서 "검토 대기 문제" 카운터를 0에 가깝게 유지하시는 게 좋습니다. 쌓이면 학생 풀에 합격선 못 맞춘 회차가 발생.

## 2-1. 화면 구성

화면이 **왼쪽·오른쪽 두 칸**으로 나뉘어 있습니다.

- **왼쪽**: 검토 대기 중인 문제 목록 (필터 + 카드 리스트)
- **오른쪽**: 선택한 문제의 상세 (본문·선지·해설·근거 자료)

## 2-2. 좌측 — 검토 큐

상단 필터로 좁히실 수 있습니다:
- **과목** / **형식**(단답형/박스형) / **출처**(AI 초안/예상문제 등) / **상태**(검토 전 / 반려)

각 카드에는:
- 출처 라벨 ("AI 초안" / "기출" 등)
- 형식 ("단답형" / "박스형")
- 과목 / 주요 조문
- 본문 앞부분 미리보기
- 모델명 (오른쪽 상단, "claude-sonnet-4-6" 등)
- 주황색 **"근거 부족"** 배지 (있을 경우 — 신중하게 검토)

카드를 클릭하면 오른쪽 패널이 채워집니다.

## 2-3. 우측 — 상세 검토 패널

### 본문 영역
- **형식 / 출처 / 상태 (draft)** 라벨
- **이전 반려 사유** (한 번 반려했던 문제라면 빨간 박스로 표시)
- **문제 본문** — 학생이 볼 그대로
- **보기 (박스)** — ㄱㄴㄷㄹ 박스형이면 각 보기 + 옆에 (true)/(false)
- **선지** — 5개 선지. 정답은 emerald(초록) 강조
- **해설**

### 근거 청크 패널 (★ 매우 중요)

화면 아래쪽 **"근거 청크 (RAG)"** 박스:
- AI가 이 문제를 만들 때 **참고한 조문·판례 원문**이 그대로 표시됩니다
- 각 청크에는 [조문/판례/실무서] 라벨 + 헤딩 + 본문 600자
- **이 청크에 적힌 내용으로 정답·오답이 설명되는지** 강사가 직접 대조하세요

> 💡 **검토 노하우**: AI 문제는 자료에 적힌 사실로만 만들도록 설계되어 있지만, **AI도 가끔 실수합니다**. 근거 청크와 정답을 한 번씩 대조하시는 게 가장 안전합니다.

## 2-4. 액션 — 결정 내리기

문제 카드 우측에 4개 버튼:

| 버튼 | 언제 누름 |
|---|---|
| **빠른 수정** | 본문이나 해설에 사소한 오류 (오탈자, 표현 다듬기) — 본문·해설만 바로 수정 |
| **깊은 편집 화면 →** | 선지·박스 항목까지 고치고 싶을 때 — 별도 편집 페이지로 |
| **승인** (emerald) | 그대로 출제해도 됨 — 학생에게 즉시 노출 가능 |
| **반려** (빨강) | 폐기 + 사유 입력 — 학생에게 안 보임, 검증 큐에서 사라짐 |

## 2-5. 일괄 작업 (시간 절약)

여러 문제를 한꺼번에 처리:
1. 좌측 카드의 **체크박스**를 여러 개 선택
2. 상단에 노란 툴바가 나타나며 **"일괄 승인"** / **"일괄 반려"** 버튼 표시
3. "일괄 반려"는 사유를 한 번만 입력하면 선택 전체에 적용

> ⚠️ **반려 사유**는 필수입니다. 나중에 같은 문제를 다시 만들거나 학생/다른 강사에게 설명할 때 필요.

## 2-6. 빠른 수정 vs 깊은 편집

| | 빠른 수정 (이 화면) | 깊은 편집 (`/admin/problems/<id>`) |
|---|---|---|
| 본문(문제 텍스트) | ✓ | ✓ |
| 해설 | ✓ | ✓ |
| 선지(5개) | ✗ | ✓ |
| 박스 보기(ㄱㄴㄷㄹ) | ✗ | ✓ |
| 정답 바꾸기 | ✗ | ✓ |
| 연결된 조문·판례 지정 | ✗ | ✓ |

선지나 정답까지 손대고 싶으시면 "**깊은 편집 화면 →**" 를 클릭하세요.

# 3단계 — 승인한 문제를 모의고사 팩에 넣기

진입: **운영관리 → 객관식 문제 · OX → "모의고사 팩 관리"** (= `/latest/mcq?kind=mock`)

승인된 문제는 자동으로 **모의고사 출제 도구의 검색 결과**에 등장합니다.

## 3-1. 팩 만들기 (처음이면)

`/latest/mcq` 화면(=사이드바 "모의고사 팩 관리") 진입 → 상단 **"모의고사 팩 만들기"** 또는 인라인 추가 폼:
- **종류**: `mock_full` (1차 종합) / `mock_progressive` (단원별)
- **제목 / 과목 범위 / 제한시간 / 합격선** 입력
- 저장 → 팩 상세(`/latest/mcq/<팩ID>`)로 자동 이동

## 3-2. 문제 추가하기 (picker 위치 + 다축 필터)

팩 상세 페이지(`/latest/mcq/<팩ID>`)의 **"문제 목록"** 카드 안쪽, 헤더 바로 아래에 **회색 배경 박스** 가 자동으로 나타납니다 (강사 계정에서만 보임):

```
┌─ 문제 목록  N ───────────────────────────────────────┐
│ ┌─ "문제 검색해서 추가" ─────── [× 필터 초기화] ─┐ │
│ │ [🔍 문제 본문 검색 (2자 이상) — 비워도 됨    ] │ │
│ │ [출처 ▾] [형식 ▾] [연도 ▾]                     │ │  ← 다축 필터
│ │ 검색 결과 다중 체크 → [+ 선택 N개 추가]        │ │
│ └─────────────────────────────────────────────────┘ │
│ 1. 문제…                                            │
└──────────────────────────────────────────────────────┘
```

**다축 필터**:
- **출처**: AI 초안 / 기출 / 기출 변형 / 예상문제 / 모의고사 / 전체 출처
- **형식**: 단답형 / 박스형 / 사례형 / 전체 형식
- **연도**: 최근 13년 또는 전체 연도

### 활용 시나리오

| 의도 | 필터 조합 |
|---|---|
| **방금 만든 AI 초안 중 골라 넣기** | 출처 = "AI 초안", (선택) 형식 = "단답형" — 키워드 없이도 최근순 노출 |
| **기출 변형으로 한 회차 구성** | 출처 = "기출 변형", (선택) 연도 = 최근 |
| **특정 연도 기출 일괄 추가** | 출처 = "기출", 연도 = "2024년" |
| **예상문제만 보고 선별** | 출처 = "예상문제" |
| **박스형만 출제** | 형식 = "박스형" + 출처 무관 |
| **키워드 정확 검색** | 키워드 입력 + 필터 무관 |

### 사용 순서

1. 필터 한두 개 골라 후보 좁히기 (또는 키워드 2자 이상)
2. 결과 목록에서 추가하고 싶은 문제 체크 (다중 선택 가능)
3. **"선택 N개 추가"** 클릭
4. 추가 후 선택 자동 비움 + 팩 문제 목록 갱신

> 🔒 **미승인 문제는 picker에 안 뜹니다** — review_status='approved' 만 노출. 강사 검증 게이트는 §2 큐 통과 후 자동 해제됩니다.
> 💡 **결과는 항상 "생성 최신순"** 으로 정렬됩니다 (AI 초안·예상문제 등 연도가 없는 항목 포함). 같은 조건이면 가장 최근에 만들어진/등록된 문제가 위에 옵니다.

## 3-3. 합격선 등 설정

- **합격선 (pass_score)**: 100점 만점 기준 (예: 60점). 빈 값이면 합격·불합격 판정 없이 점수만 표시
- **제한 시간** / **공개일** / **풀이 동영상 URL** 등 추가 정보

## 3-4. 통합 모의고사(3교시) 만들기 (선택)

화면: **/admin/mcq-exams** (사이드바: **운영관리 → 객관식 문제 · OX → "통합 모의고사 (3교시)"**)

여러 팩을 묶어 한 시험(예: 산업재산권법 + 민법 + 자연과학 3교시)으로:
1. **"시험 추가"** → 제목·연도·회차·평균 합격선 입력
2. 편집 화면에서 **"교시 매핑"**: 각 팩을 ord 순서로 넣고, 교시별 과락선 지정
3. **"공개"** 토글을 켜야 학생에게 노출됨

# 4단계 — 학생 응시 후 운영

## 4-1. 응시 결과 통계 보기

각 팩 응시 결과는 `/admin/...` 통계 페이지에서 확인 (기존 화면).

## 4-2. 풀이 동영상 등록 (학생 만족도 ↑)

팩 편집에서 **video_url** 입력 → 학생 결과 화면에 "강사 풀이 동영상 보기" 버튼 노출.

## 4-3. 학습과목에 공개 (mock 문제만 해당)

모의고사 응시가 끝난 회차의 mock 문제를 학습과목 일반 풀에 풀어넣고 싶으실 때:
- 팩 상세의 **"학습과목에 공개"** 패널 → 클릭 → 그 팩의 mock 문제들에 `released_at` 자동 설정 → 학생 학습과목 색인에 등장

# 자주 묻는 질문

### Q. 메뉴 어디서 들어가나요?
A. 상단 네비게이션 **운영관리** → 좌측 사이드바 **"객관식 문제 · OX"** 클러스터. 클러스터 안에 출제 순서대로 **AI 문제 초안 만들기 → 검토 대기 문제 → 문제 직접 만들기 → 전체 문제 보기 → OX 검수 → 정답률·통계 → 모의고사 팩 관리 → 통합 모의고사 (3교시)** 가 정렬되어 있습니다. 운영관리 첫 화면(허브) 상단 워크큐에서도 **"검토 대기 문제"** 타일로 바로 진입할 수 있습니다.

### Q. AI가 만든 문제가 이상하면 어떻게 하나요?
A. **반려** 버튼 + 사유. 폐기되고 학생에게 절대 안 보입니다.

### Q. 한 번 반려한 문제를 다시 볼 수 있나요?
A. 검증 큐 상단의 "상태" 필터를 **"반려 (rejected)"** 로 바꾸시면 됩니다. 거기서 다시 승인하거나 깊은 편집도 가능.

### Q. AI가 만든 박스형 문제의 정답이 맞는지 어떻게 확인하나요?
A. 자동 검사가 1차로 걸러줍니다. "정답으로 표시된 보기가 실제로 참 보기 조합과 같은지" 자동으로 검증. 안 맞으면 카드에 **구조 경고** 표시. 사람이 한 번 더 보시고 판단.

### Q. AI 생성 비용에 한도가 있나요?
A. 네. 일일 한도(기본 daily cap)가 설정되어 있어 갑작스러운 폭주를 막습니다. 한도 도달 시 생성 화면에 "cap blocked" 안내.

### Q. 강사 검증 없이 바로 출제는 안 되나요?
A. **불가능합니다 (정책)**. 모든 신규 문제는 강사 승인 도장이 있어야 picker / 학습과목 / 맞춤퀴즈에 노출됩니다. 이는 안전 장치이며 우회 경로는 없습니다.

### Q. 운영 중 사고가 나면?
A. 강사가 잘못 승인한 문제는 `/admin/problems/<id>` 깊은 편집에서 `deleted_at`을 set(소프트 삭제)하거나 직접 수정. 학생 응시 기록은 보존되며 그 문제만 즉시 비공개 처리됩니다.
