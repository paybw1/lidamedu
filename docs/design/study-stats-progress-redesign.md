# 디자인 요청 — 학습현황 "진도" 탭 리디자인 (`/study/stats?tab=progress`)

> Claude Design 핸드오프 브리프. 변리사 수험 학습 플랫폼의 **학습현황 > 진도** 탭을
> "데이터 표 묶음"에서 **"전체를 한눈에 보고, 원하는 과목 학습으로 바로 진입하는 런처"**
> 로 재설계한다.

---

## 0. 한 줄 목표

> **전 과목 학습 현황을 한 화면에서 일목요연하게 파악**하면서, 각 과목에서
> **"이어서 보기 / 이 과목 학습하기"로 즉시 학습에 진입**할 수 있는 과목 런처형 화면.

두 가지가 동시에 충족돼야 한다 — (1) 한눈 파악, (2) 즉시 진입.

---

## 1. 제품 맥락

- **누가**: 대한민국 변리사 시험 수험생(학생/수강생). UI는 **한국어 단일**.
- **시험 구조**: 1차(객관식) · 2차(주관식/논술). 학생은 자신의 **목표 차수**(1차/2차/미정)를 가짐.
- **과목**: 법률 5과목 + 자연과학(1차 한정).
- 이 화면은 **유료 구독(학습관리)** + **"학습 데이터 분석" 동의** 게이트 안에 있다(미동의 시 통계 비표시 — §8).

---

## 2. 대상 화면 & 현재 상태 (Before)

- 위치: `/study/stats` ("학습현황") 페이지의 **"진도"** 탭. 페이지 탭 = `한눈에 / 진도 / 정답률 / 암기 / 약점`.
- 셸: 상단 토픽바 + `PageHeader`(eyebrow "학습 관리" · 제목 **"학습현황"**) + 우측 "대시보드" 버튼. 콘텐츠 폭 `wide`.
- **현재 진도 탭**은 카드(Surface) 안에 **밀집된 표(Table) 5개가 세로로 쌓인** 구조:
  1. `법률 객관식 — 조문 열람 + 문제 풀이` (과목 / 조문 열람 % / 문제 시도 / **가기**)
  2. `자연과학 — 풀이 진척` (과목 / 풀이 n/total / 가기)
  3. `법률 주관식 — 답안 작성` (2차, 과목 / 답안 수 / 가기)
  4. `조문 학습` (과목 / 열람 / 즐겨찾기 / 포스트잇 / 하이라이트 / 가기)
  5. `판례 학습` (과목 / 열람 / 전체 / 가기)
- 각 행의 유일한 액션은 작은 텍스트 링크 **"가기"**(→ 과목 홈).

### 현재의 문제점 (리디자인 동기)

- **표 위주**라 "지금 내가 뭘, 어느 과목을 해야 하는지" 직관이 약함 — 스캔이 아니라 정독을 요구.
- **과목 진입 CTA가 빈약**: 작은 "가기" 텍스트 링크 하나. 학습 시작 동선이 약하고 눈에 안 띔.
- **과목 단위로 흩어진 지표**: 한 과목의 진도는 "진도" 탭, 정답률은 "정답률" 탭, 약점은 "약점" 탭, 마지막 학습 지점/추천은 과목 홈… → 한 과목을 한 곳에서 못 본다.
- 같은 과목이 여러 표(조문/판례/문제/주관식)에 분산돼 **중복·반복**적이다.

---

## 3. 핵심 목표 (2가지, 우선순위 동일)

1. **전체 현황 일목요연** — 5개 법률 과목(+자연과학)을 **카드 한 벌**로 스캔. 과목별 진도·정답률·약점·최근활동을 한 카드에 응집.
2. **과목 바로 진입** — 각 과목 카드에 **명확한 1차 CTA**("이어서 보기" = 마지막 학습 지점에서 계속 / "이 과목 학습"). 클릭 한 번으로 학습 시작.

---

## 4. 표시할 데이터 (실제 제공 가능 — 이 값들로 설계)

> 모두 현재 백엔드에서 제공되거나(또는 과목 홈에 이미 존재해 끌어올 수 있는) **실데이터**다.
> 가짜 수치 만들지 말 것.

### 과목별 (법률 5 + 자연과학 4)
| 지표 | 설명 |
|---|---|
| 진도율 % | 조문 열람 기준 `visited / total` (예: 42%) |
| 조문 열람 | `visited / total` 개수 |
| 문제 시도 수 | 푼 문항 수 |
| 정답률 % | 객관식 정답률(현재 "정답률" 탭에 있음) |
| 주관식(2차) | 답안 수, 평균 자기채점 |
| 즐겨찾기 · 포스트잇 · 하이라이트 | 조문 학습 부가 카운트 |
| 판례 열람 | `visited / total` |
| **마지막 학습 지점** | 마지막 본 조문/판례/문제 + 라벨 → **"이어서 보기"** 동선 (과목 홈엔 이미 있음, 이 화면으로 끌어오는 것을 권장) |
| **약점** | 과목별 약한 단원/노드(있으면 N개 배지) |

### 전체 (요약 띠용)
- 연속 학습일(**streak**), 주별 학습시간 추세, 합격 예측 추세, **D-day**(목표 시험일 기준), 목표 주간 학습시간 대비 달성, **시험 차수(1차/2차)**.

### 차수 필터(중요)
학생의 목표 차수에 따라 노출 과목이 달라진다:
- 공통(1·2차): **특허법 · 상표법 · 디자인보호법**
- 1차 전용: **민법**, **자연과학(물리·화학·생물·지구과학)**
- 2차 전용: **민사소송법**
- 차수 미정(null): 1차·2차 과목 모두 표시.

## 5. 디자인 방향 (제안 — 자유롭게 발전시켜도 좋음)

핵심 전환: **표 스택 → 과목 카드 런처**.

### (A) 상단 "전체 요약" 띠/카드
한 줄 또는 한 벌의 작은 스탯으로 전체를 압축: 전 과목 평균 진도, 연속 학습일, D-day, 이번 주 학습시간/목표. (한눈 파악의 윗부분.)

### (B) 과목 카드 그리드 (화면의 중심)
모바일 1열 → 태블릿 2열 → 데스크톱 2~3열. **각 과목 카드** 권장 요소:
- 헤더: **과목명** + `1차`/`2차` 배지 (+ 산업재산권법/민법 등 분류 칩)
- **큰 진도 링/도넛**(현재 `ProgressDonut` SVG 패턴 재사용 가능) + 진도율 %
- 핵심 지표 칩 2~3개: `정답률 73%` · `약점 4` · `문제 128` 등
- **1차 CTA 버튼** "이어서 보기"(마지막 지점에서 계속) — 가장 눈에 띄게(primary). 보조로 "과목 홈".
- (선택) 미니 "오늘 추천" 한 줄: `안 본 중요 조문` / `꼭 봐야 할 판례` / `복습 필요한 문제` — 과목 홈의 추천 패턴 축약.
- **빈 상태**(진도 0%): 격려 문구 + "시작하기" CTA.

### (C) 보조 동선
- (선택) 상단에 **1차/2차 토글**(차수 미정일 때) + **자연과학 묶음** 섹션.
- 기존의 자세한 표(조문/판례/문제 카운트)는 **카드의 "자세히" 펼침** 또는 별도 보조 뷰로 격하 — 메인은 카드.

> 시각적 톤: 차분하고 신뢰감 있는 학습 도구. 화려한 장식보다 **스캔 가능성·진입 동선**이 최우선.
> 진도/성취는 색으로 직관화하되 과하지 않게(아래 팔레트 규칙).

---

## 6. 진입 경로 (실제 라우트 — CTA 와이어링용)

> 카드의 CTA는 아래 **실제 경로**로 연결한다. `{slug}` ∈ `patent` `trademark` `design` `civil` `civil-procedure`.

| 동선 | 경로 |
|---|---|
| 과목 홈(허브) | `/subjects/{slug}` (탭 `?tab=articles`(기본)·`cases`·`problems`) |
| **이어서 보기**(마지막 지점) | 과목 홈의 "이어서 보기"가 마지막 조문/판례/문제 뷰어로 이동 (`/subjects/{slug}/articles/…` 등) — 동일 로직 재사용 |
| 맞춤 퀴즈 | `/subjects/{slug}/quiz/setup` |
| 정오문제(OX) | `/subjects/{slug}/ox` |
| 자연과학 과목 | `/subjects/science/{physics\|chemistry\|biology\|earth-science}` |
| 오답노트 | `/study/wrong-note?subject={slug}` |
| 오늘 할 일 | `/study/today` |

과목 목록·라벨:

| slug | 과목 | 차수 |
|---|---|---|
| `patent` | 특허법 | 1·2차 |
| `trademark` | 상표법 | 1·2차 |
| `design` | 디자인보호법 | 1·2차 |
| `civil` | 민법 | 1차 |
| `civil-procedure` | 민사소송법 | 2차 |
| (science) | 자연과학(물리·화학·생물·지구과학) | 1차 |

## 7. 디자인 시스템 제약 (반드시 준수)

- **컴포넌트**: shadcn/ui(New York) + Radix + Tailwind v4. 아이콘 **Lucide**. 기존 학생 화면 셸 `StudentShell`(width `wide`) + `PageHeader`(area `manage`) + 카드 primitive `Surface`.
- **색은 토큰만**(하드코딩 hex 금지), **라이트/다크 둘 다** 동작:
  - 표면/카드: `--card`, `--surface-1`, `--surface-2`(서브카드/띠), `--surface-3`(hover/빈상태)
  - 강조: `--primary` / `--primary-foreground`(딥 로열블루, CTA), 링크 `--link`
  - 텍스트: `--foreground`, `--muted-foreground`, `--ink-soft`, `--ink-faint`
  - 경계: `--border`, `--line-strong`
  - 차트/진도: `--chart-1..5`(blue·light-blue·emerald·amber·violet). 성취도 색은 `scoreBgTone` 규칙(emerald→lime→amber→orange→rose), 학습량/활동은 primary blue.
- **반경** `0.65rem`(카드 `rounded-xl`). **폰트** Pretendard(본문). 제목 강조엔 명조(Noto Serif KR) 사용 가능.
- **차트 라이브러리 없음** — 도넛/바/히트맵은 **SVG·CSS 수제**(`ProgressDonut` 등 기존 패턴 재사용). recharts 등 도입 금지.
- **반응형 필수** — 모바일 우선(1열) → 데스크톱 그리드.
- **문체**(한국어): 제목·배지·칩·버튼 = **명사형, 마침표 없음**; 설명·빈상태 본문·안내 = **서술어 `~합니다`, 마침표 있음**. 영어 UI 단어 금지(OX/PDF/AI 등 약어만 예외).

## 8. 상태 / 엣지 케이스 (디자인 시 포함)

- **분석 동의 OFF**: 통계 전부 숨김 + 상단 목표 요약 띠만 노출(현행 동작). 진도 화면도 이 상태에서 깨지지 않게(동의 유도 안내 + 목표 요약).
- **차수 미정(null)**: 1차·2차 과목 카드 모두 표시(또는 토글 제공).
- **빈 과목**(진도 0% / 자연과학 미적재 total 0): 흐림 처리 + "시작하기" CTA + 격려 문구.
- 데이터 로딩(약점 매트릭스는 지연 로드): 스켈레톤 고려.

## 9. 산출물 (요청)

1. **진도 탭 전체 목업** — 데스크톱 + 모바일, **라이트/다크** 각각.
2. **과목 카드** 컴포넌트 상세(진도 링 + 지표 칩 + 1차/2차 배지 + CTA + 미니 추천 + 빈상태).
3. **상단 전체 요약 띠**(평균 진도·streak·D-day·주간 목표).
4. (선택) 1차/2차 토글, 자연과학 섹션, 카드 "자세히" 펼침.
5. 인터랙션 명세: 카드/CTA → §6 경로 매핑(이어서 보기 · 과목 홈 · 퀴즈 · OX · 오답노트).

> 참고: 이미 **과목 홈**(`/subjects/{slug}`)에 "내 학습 현황 도넛 + 이어서 보기 + 오늘의 학습 추천"
> 패턴이 있다. 이 진도 탭은 그 과목별 위젯들의 **전 과목 요약·진입 허브** 역할을 하면 자연스럽다 —
> 일관성을 위해 해당 시각 언어를 이어받는 것을 권장한다.
