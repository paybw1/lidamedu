# lidamedu 이전 — 요구사항 원문 (사용자 제공, 2026-07-08)

> 설계 반영본: `docs/features/lidamedu-이전-M1-설계.md`. ★는 사용자 문서의 우선순위 표기 원문 그대로.

## 0. 현황 점검
프로필/인증·코호트·staff 역할 체계(설계 토대). 스키마에 상품·주문·영상 개념 존재 여부. 시청 진도가 학습현황·종합반 관리자 뷰와 이어질 자리.

## 1. 요구사항 요약 (설계 대상 도메인 — ★는 문서 우선순위)

### 영상 관리 (★★★★★ 중심)
강의 상품 안에 회차(1강, 2강…)별 영상 등록. 외부 DRM 영상 ID(콜러스 콘텐츠 ID·스타플레이어 키 — 불투명 필드) 연결. 제목·회차·강사·과목·재생시간. 노출 순서 변경. 미리보기(맛보기, 결제 전 시청) 지정(★★★★). 공개/비공개. 영상 교체(회차 유지, 영상 ID만 수정본 교체 ★★★★). 영상별 운영 메모(★★).

### 강의/상품 관리 (★★★★★ 중심)
상품 유형: 단과 / 패키지(여러 강의 묶음) / T-PASS(기간제). 회차↔상품 연결.
수강기간(결제일+N일 or 특정일까지). ★일시정지 정책(허용 여부·총 일수·횟수·1회 최소/최대). ★수강 배수(총 강의시간×1.5/2/3배수 = 시청 가능 시간). PC/모바일 허용. 다운로드 허용(★★★★). 수강 연장(★★★★). 판매상태(예정/판매중/일시중지/종료/숨김). 회차별 강의 자료 PDF.

### ★도서몰 (본격 — placeholder 아님) (★★★★★ 다수)
도서 등록(도서명·저자·판매가·재고·판매상태). 강의 상품↔교재 연결(필수/선택, 결제 화면에서 함께 구매 유도). 재고·판매상태 연동. 도서 배송관리(배송상태·택배사·송장번호, 사용자 마이페이지 즉시 반영). 도서 주문 분리 조회. 도서 매출 통계.

### 회원 수강권 관리 (★★★★★)
회원별 수강 조회(강의·기간·배수·상태). 수동 지급(결제 없이 — 이관·이벤트·직원용). 기간 수정·연장(+7/15/30일). 일시정지 관리(적용·남은 일수/횟수·재개 예정일·이력·관리자 예외). 회수(환불·취소 시). 특정 강의 재생 차단(★★★★).

### 재생 권한 제어 (★서버 권위) (★★★★★ 중심)
재생 클릭 시 서버가 판정 후 DRM 플레이어 호출: 로그인(맛보기 예외) → 수강권 보유 → 기간 미만료 → 배수 미초과. 중복 로그인 제한(★★★★). 기기 등록 제한(PC 1+모바일 1, ★★★★). IP 제한(★★★). 캡처/녹화 차단은 DRM 플레이어 설정 확인(★★★).

### 수강 기록 (★★★★★)
회원별 시청 기록(강의·회차·시간·일자). 영상별 누적 재생시간(배수 계산용). 마지막 재생 위치(이어보기). 진도율(회차·강의별). 완강 여부(★★★★). 최초/마지막 재생일(★★★★, 환불 기준). 일시정지 신청(회원, 허용 범위 내).

### ★배수 관리 (설계 난도 최고) (★★★★★ 중심)
강의 총 재생시간 합산 → 배수 곱해 시청 가능 시간 자동 계산. 회원별 사용/잔여 조회. 관리자 초기화·오류 복구(버퍼링·플레이어 오류·영상 교체 시 잘못 차감 복구 ★★★★). 차감 예외(맛보기·무료 ★★★★). 회차별 조정(★★).
★설계 유의: 시청 시간의 서버측 누적·차감 이벤트 모델(클라 신뢰 X, 주기적 하트비트/구간 보고 등), 복구 가능하게 이벤트 로그 보존.

### 기기 관리 (★★★★)
회원별 등록 기기(PC/모바일/태블릿). 초기화(★★★★★ — 기기 교체 CS 최다). 변경 횟수 제한(월 1회 등 ★★★). 관리자 강제 초기화. 비정상 접속(★★).

### 장애 대응 (★★~★★★★)
재생 오류 로그·접속 환경·DRM 오류코드(★★~★★★). 관리자 메모·보상 처리(배수 복구·기간 연장)(★★★★).

### 결제 연동 (★★★★★)
토스: 위젯 결제 → ★서버 승인 확인 → 주문 확정 → 수강권 자동 지급. 취소/전액 환불 시 자동 회수. 부분 환불(패키지 일부, ★★★★). ★무통장 입금 수동 승인(입금 확인→관리자 승인→지급). 주문별 지급/회수 내역.

### 보안 (★★~★★★★★)
관리자 권한 분리(최고/운영/CS/강사)·메뉴 접근 제한(★★★★★ — 기존 staff 역할 체계 확장). 영상 ID 수강생 노출 최소화·재생 임시 토큰·URL 복사 방지(★★). 접속 로그·비정상 차단(★★★★).

### CS 기능 (★★★★★)
회원 검색(이름/아이디/전화/이메일/주문번호). 수강 확인. 기기 초기화. 배수 복구. 기간 연장. 상담 메모(기존 상담 체계와 연계 검토). 처리 이력(★★★★).

### 주문·통계 (★★★★~★★★★★)
주문 목록·환불 관리·전자결제 내역·배송 관리(★★★★★). 매출 통계(일/월/과정/도서, ★★★★~★★★★★ — ★파생 뷰로, 저장 아님). 환불·주문항목 통계(★★★★). 강사 정산(매출·환불 차감·수수료율, ★★★★).

### 쿠폰 (★★★★~★★★★★)
정액/정률/특정 강의/기간 제한 쿠폰 생성·사용 내역. 자동 발급(가입·첫 구매 등 ★★★★).

### 마이페이지 (수강생) (★★★★★ 중심)
수강현황(목록·기간·진도율·배수·완강)·이어보기·일시정지 신청·결제/환불 내역·영수증(★★★)·도서 배송조회(송장·택배사). 쿠폰 조회.

### 2차/축소
2차(★★★, 모델에 자리만): 정기구독(월/연 자동결제·해지·재개), 후기(별점·작성·수정).
축소 검토(★★): 강사용 관리자(본인 강의 한정 뷰), 오류 로그 상세.

## 2. ★플랫폼 고유 추가 (요구사항 문서에 없는 차별점 — 모델에 포함)
- 노드↔강 다대다 매핑: 마스터리·약점의 단원 노드 ↔ 회차. 업로드 시 입력. → "약점 단원 → 그 강의 재수강"(성장 루프). 런칭 필수는 아니나 모델엔 처음부터.
- 시청 진도 → 학습현황 연계: 시청 기록이 학습현황·종합반 관리자 개별 뷰에 흐를 자리(M3+).
- ★에디션(연도판): 연간 법 개정 전면 재촬영(강 구성 변경) 대응 — 시리즈 에디션(2026판/2027판), 신판 기본 노출·구판 수강권/이력 보존. (요구사항의 "영상 교체"는 회차 유지 소규모 수정본용 — 전면 개편은 에디션. 둘 다 필요.)

## 3. 설계 원칙
서버 권위(재생 판정·배수 차감·지급/회수 전부 서버, 클라 신뢰 X) · 벤더 무관(DRM ID 불투명) · 파생 vs 저장(통계=파생 뷰, 저장=이벤트·상태) · DB=dry-run 게이트·RLS 기존 패턴·안전 기본값 · 기존 자산 연계(상담·staff 역할·admin 검색).

## 4. 단계 계획
M2 시청 골격 → M3 기록·배수·기기 → M4 결제·커머스 → M5 이관·전환. ★★★는 자리만, ★★는 축소. 벤더(DRM) 의존=플레이어 호출·토큰·기기/중복로그인 연동만 플래그.
