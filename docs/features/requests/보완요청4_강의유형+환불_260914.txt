및 환불관리 통합 개발요청서

① 강의상품 등록 시 과정 유형 선택 및 유형별 수강정책 자동화, ② 관리자 중심 환불접수·검토·토스 수동취소·후속처리 기능을 하나의 요청서로 통합합니다.





요청 ①

강의상품 등록 · 과정유형 선택

6개 과정 유형 중 하나를 먼저 선택하고, 유형별 필요한 입력항목·기간·배수·정원·패키지 구성이 자동으로 달라지도록 구현합니다.




요청 ②

환불관리 · 관리자 수동 PG 처리

수강생 직접 환불신청은 제외하고, 관리자가 접수·검토 후 토스 상점관리자에서 직접 취소하고 결과를 기록합니다.





통합 요청사항
강의 원본·판매상품·주문·수강권·환불 데이터를 서로 구분하되 연결관계는 유지하고, 기존 주문·결제·수강생·진도·영상 데이터가 훼손되지 않도록 해 주세요.


PART A

강의상품 등록 · 과정 유형 선택 기능



핵심 목적
상품 유형에 따라 필요한 입력항목·수강권 생성방식·기간 계산·정원·연장·배수 정책이 서로 다르므로, 상품 등록 첫 단계에서 유형을 확정하고 이후 입력화면이 해당 유형에 맞게 자동 구성되도록 합니다.

1. 과정 유형 선택

다음 6개 과정 유형 중 하나를 필수 선택한 뒤 다음 단계로 이동하도록 해 주세요. 첫 화면에는 과정명뿐 아니라 짧은 설명을 함께 표시해 관리자가 혼동하지 않도록 합니다.



① 온라인 상시

필수 유형

수강생이 결제 또는 수강신청을 완료한 날부터 관리자가 입력한 학습일수만큼 수강하는 온라인 강의입니다.

운영 예시/특이사항
예: 수강기간 365일 / 9월 10일 시작 시 다음 해 9월 9일까지 수강 / 회원마다 시작·종료일이 다를 수 있음

선택 시 필요한 설정


- 수강일수

- 수강 시작 기준

- 수강배수

- 일시정지 허용 여부 및 횟수

- 최대 일시정지 일수

- 유료 연장 가능 여부

- 영상 다운로드 허용 여부

- 배속 제한

- 기기 등록 제한






② 온라인 정규

필수 유형

모든 수강생이 관리자가 지정한 정해진 학습기간에 맞춰 수강하는 온라인 강의입니다.

운영 예시/특이사항
중간 신청자의 종료일은 「기존 과정 종료일까지 수강」 또는 「신청일부터 별도 설정 일수만큼 수강」 중 선택

선택 시 필요한 설정


- 수강 시작일

- 수강 종료일

- 판매 시작일·종료일

- 중간 신청 허용 여부

- 중간 신청자의 종료일 적용 방식

- 강의 공개 일정

- 수강배수

- 일시정지·연장 허용 여부






③ 현장 강의

필수 유형

학원에서 직접 수강하는 오프라인 강의입니다.

운영 예시/특이사항
온라인 영상 제공을 선택한 경우 영상 연결과 온라인 수강기간을 추가 설정

선택 시 필요한 설정


- 개강일·종강일

- 강의 요일 및 시간

- 강의실

- 모집 정원

- 접수 시작일·마감일

- 대기신청 허용 여부

- 현장 수강생 명단

- 출석 관리 여부

- 교재 포함 여부

- 온라인 영상 제공 여부






④ 온·오프라인 혼합

필수 유형

현장 강의와 온라인 강의를 함께 제공하는 과정입니다.

운영 예시/특이사항
현장 수강권과 온라인 수강권이 중복 생성되거나 수강배수가 이중 차감되지 않도록 하나의 신청 건으로 관리

선택 시 필요한 설정


- 현장 강의 일정

- 강의실 및 모집 정원

- 현장 출석 관리

- 연결할 온라인 강의

- 온라인 영상 공개일

- 온라인 수강 시작일·종료일

- 수강배수 및 재생 제한

- 현장 종료 후 복습기간

- 일시정지·연장 허용 여부






⑤ 정규 패키지

필수 유형

운영 예시/특이사항
중간 구매자의 종료일 적용 방식도 별도로 선택 가능

선택 시 필요한 설정


- 패키지 시작일·종료일

- 판매기간

- 패키지에 포함할 강의 다중선택

- 강의별 수강기간

- 강의별 공개일

- 패키지 전체 가격

- 구성 강의별 정상가격

- 부분 환불 시 강의별 금액 배분 기준

- 패키지 구매자 일괄 수강권 생성






⑥ 상시 패키지

필수 유형

여러 개의 온라인 강의를 하나로 묶어 판매하고, 수강신청일부터 설정한 일수만큼 수강하는 상품입니다.

운영 예시/특이사항
예: T-PASS / 특허법·상표법·디자인보호법 365일 패키지 / 여러 단과강의를 묶은 상시 판매상품

선택 시 필요한 설정


- 패키지 전체 수강일수

- 포함 강의 다중선택

- 강의별 수강일수 별도 적용 여부

- 강의별 수강배수

- 패키지 전체 가격

- 구성 강의별 정상가격

- 일시정지·유료 연장 정책

- 부분 환불 시 강의별 금액 배분 기준

- 패키지 구매자 일괄 수강권 생성




2. 등록 화면 구성





단계 | 화면 | 핵심 내용



1 | 과정 유형 선택 | 6개 과정 유형 중 1개 필수 선택



2 | 기본정보 입력 | 상품명, 카테고리, 강사, 대표이미지, 기본 설명



3 | 강의 또는 패키지 구성 | 단과 강의 연결 또는 패키지 구성 강의 다중선택



4 | 수강정책 설정 | 기간, 배수, 일시정지, 연장, 현장정원 등 유형별 정책



5 | 가격·할인·포인트·쿠폰 설정 | 정상가, 판매가, 할인, 포인트, 쿠폰 사용정책



6 | 판매 및 노출 설정 | 판매기간, 공개상태, 노출기간, 정렬순서



7 | 등록내용 확인 후 저장 | 최종 검토 및 저장







과정 유형은 라디오 버튼 또는 선택형 카드로 표시하고, 반드시 하나를 선택해야 다음 단계로 이동할 수 있게 해 주세요.

3. 선택 유형에 따른 입력항목 자동 변경



유형별 조건부 입력 UI



선택한 과정 유형에 필요한 입력항목만 노출해 주세요. 모든 설정을 한 화면에 전부 노출하지 않습니다.


- 온라인 상시: 강의실·모집정원 입력란 미노출

- 온라인 정규: 시작일·종료일·중간신청 정책 노출

- 현장 강의: 기본적으로 수강배수·영상 재생제한 미노출

- 온·오프라인 혼합: 현장정책 + 온라인정책 동시 노출

- 패키지: 구성 강의 다중선택·강의별 정책·환불 배분 기준 노출


관리자가 어떤 값을 입력해야 하는지 혼란스럽지 않도록 선택한 유형에 필요한 항목만 표시하는 것이 핵심입니다.



4. 강의와 판매상품 구분





구분 | 역할 | 처리 원칙



강의 | 영상·회차·자료의 원본 콘텐츠 | 원본 강의는 판매상품과 별개로 관리



판매상품 | 가격·수강기간·판매조건을 가진 실제 판매 단위 | 하나의 강의를 여러 상품에 연결 가능



단과상품 | 기존 강의 1개 연결 | 같은 강의를 가격·기간이 다른 여러 상품으로 판매 가능



패키지상품 | 기존 강의 여러 개 다중선택 | 구성 강의를 검색 후 일괄 추가








- 상품을 삭제해도 원본 강의와 영상은 삭제되지 않아야 합니다.

- 강의를 수정하면 연결된 판매상품에 미치는 영향을 확인할 수 있어야 합니다.

- 강의와 판매상품의 ID·데이터 구조는 분리하되 연결관계는 명확하게 유지해 주세요.


5. 과정 유형 변경 제한



변경 가능 조건




- 임시저장 상태: 과정 유형 변경 가능

- 주문 또는 수강생 발생 후: 과정 유형 변경 차단

- 변경 필요 시: 기존 상품 판매중지 &rarr; 상품 복사 &rarr; 새 유형으로 신규 등록


신청내역이 있는 상품은 과정 유형을 변경할 수 없습니다.
기존 상품을 판매중지한 후 복사하여 새로운 유형의 상품으로 등록해 주세요.





상품 복사 시 데이터 복사 기준




- 기본정보 복사

- 강의 구성 복사

- 가격·수강정책은 선택적으로 복사 가능

- 주문·수강생·결제내역은 절대 복사하지 않음

개발 핵심: 과정 유형 선택값을 단순 화면 표시용이 아니라 상품의 핵심 속성으로 저장하고, 이후 수강권 생성·기간 계산·정원·패키지 구성·연장·환불 로직이 해당 유형을 기준으로 일관되게 작동하도록 해 주세요.


PART B

환불관리 기능 · 관리자 수동 환불 운영



최종 운영원칙
고객센터 접수 &rarr; 관리자 환불신청 등록 &rarr; 환불금액 검토 &rarr; 토스 상점관리자에서 관리자가 직접 취소 &rarr; 취소정보 입력 &rarr; 강의·교재·포인트·쿠폰·정산 후속처리 &rarr; 환불완료

1. 수강생 직접 환불신청 기능 제외


수강생 환불신청 버튼 미제공

수강생이 마이페이지에서 직접 환불을 신청하는 기능은 개발하지 않습니다. 환불 문의는 전화·카카오톡·게시판·방문 등 고객센터를 통해 접수하고, 상담 내용을 확인한 관리자가 관리자페이지에서 환불신청을 등록합니다.


- 수강생 주문내역에 [환불신청] 버튼 미표시

- 수강생 결제내역에 [환불신청] 버튼 미표시

- 환불 완료 후 수강생 결제내역에는 결과만 표시






항목 | 표시 내용



환불 상태 | 부분환불 / 전체환불



환불금액 | 실제 환불 완료 금액



환불처리일 | 최종 환불완료 처리일



환불된 상품 | 실제 환불 대상 강의·교재

관리자 주문관리에서 결제 완료된 주문마다 [환불신청] 버튼을 제공합니다.


- 주문 전체 환불

- 강의만 환불

- 교재만 환불

교재

- 반품 배송비 공제

- 결제로 적립된 포인트 회수

- 쿠폰 복원 여부는 정책에 따라 처리

10. 중요 안전장치


- 동일 상품 중복 환불신청 차단

- 이미 환불한 금액보다 큰 금액 입력 차단

- 최초 결제금액을 초과하는 누적 환불 차단

- 환불완료 상태 변경 전 확인창 표시

- 토스 취소정보 미입력 시 환불완료 처리 차단

- 누가 언제 어떤 금액을 환불했는지 로그 저장

- 환불완료 후 금액 수정 제한

- 수정 필요 시 원장 권한과 수정사유 필수

- 부분환불 후 남은 환불 가능금액 자동계산

- 환불완료 처리 실패 시 강의·포인트 등의 일부만 변경되지 않도록 일괄처리


일괄처리 원칙: 후속처리 중 하나라도 실패하면 일부 데이터만 변경된 상태가 남지 않도록 트랜잭션 또는 복구 가능한 상태관리 방식으로 처리합니다.

11-1. 계산에 사용하는 기준값





기준값 | 정의 및 저장 기준



결제기준금액(B) | 쿠폰·포인트 차감 전 해당 상품의 실제 판매금액



정상가(N) | 할인 전 정상 판매가격



쿠폰 사용금액(C) | 해당 주문상품에 배분된 쿠폰 할인액



사용 포인트(Q) | 해당 주문상품에 배분된 사용 포인트



실제 PG 결제금액 | 해당 상품에 귀속되는 실제 현금/PG 결제액



정가 수강기간(D) | 결제 당시 상품에 적용된 정상 수강기간



실제 이용일수(d) | 수강 시작일부터 고객센터 환불 접수일까지의 실제 이용일수



전체 예정 회차(T) | 결제 당시 사전 고지된 전체 예정 회차



수강·자료 이용 회차(t) | 유료 영상 또는 유료 자료를 이용한 고유 회차 수



환불 계산유형 | 기간제 / 단과 / 단과 묶음 / 상품별 별도 환불규정 등



상품별 별도 환불규정 | 결제 당시 상품안내 페이지에 별도로 고지된 환불조건의 스냅샷







결제 당시 스냅샷 기준: 환불 계산은 현재 상품정보가 아니라 반드시 결제 당시 저장된 가격·기간·예정 회차·쿠폰/포인트 배분값·환불규정을 기준으로 합니다. 이후 상품정보가 수정되어도 과거 주문의 환불 기준은 변경되면 안 됩니다.

11-2. 환불규정 적용 우선순위


- 결제 당시 상품 안내 페이지에 별도로 고지된 환불규정

- 수강 시작일부터 7일 이내이고 이용이력이 없는 경우 전액환불

- 정가 수강기간의 1/2 이상 경과 여부

- 패키지 부분환불 제한 여부

- 기간제 또는 단과 계산식 적용

- 쿠폰·포인트 및 기존 누적 환불액 반영


관리자 화면에는 판정 결과를 명확히 표시합니다.
예: 전액환불 가능: 수강 시작 후 7일 이내·이용이력 없음 / 환불 불가: 정가 수강기간의 1/2 이상 경과 / 부분환불 불가: 패키지 구성상품 / 단과 계산식 적용 / 상품별 별도 환불규정 적용

11-3. 7일 이내 전액환불


다음 조건을 모두 충족하면 전액환불로 판정


- 수강 시작일부터 7일 이내

- 유료 영상 재생이력 없음

- 유료 강의자료 열람이력 없음

- 유료 강의자료 다운로드이력 없음

- 유료 강의자료 출력이력 없음


환불 대상금액 = 결제기준금액(B) &minus; 쿠폰 사용금액(C)


- 사용 포인트는 포인트로 반환

- 나머지 금액을 토스 취소 예정금액으로 계산

- 토스 취소 예정금액은 실제 PG 결제금액을 초과할 수 없음

- 무료 맛보기 영상과 결제 전 공개된 무료자료 이용이력은 유료 이용이력에서 제외




11-4. 이용이력 판정



- 유료 영상 재생

- 유료 강의자료 열람

- 유료 강의자료 다운로드

- 유료 강의자료 출력


같은 회차에서 영상을 여러 번 재생하거나 자료를 여러 번 이용해도 이용 회차는 1회차로 계산합니다. 영상과 자료를 모두 이용한 경우도 같은 회차라면 중복 계산하지 않습니다.

회차에 연결되지 않은 공통 유료 강의자료를 이용한 경우에는 최소 1회차 이용으로 계산하고, 관리자 화면에서 해당 자료의 이용이력을 확인할 수 있게 해 주세요.



11-5. 실제 이용일수


실제 이용일수(d) = 고객센터 환불 접수일 &minus; 수강 시작일 + 1일


- 수강 시작일 전이면 이용일수는 0일

- 승인된 일시정지 기간은 이용일수에서 제외

- 관리자가 늦게 처리해도 환불 접수일 이후 기간은 추가 계산하지 않음

- 환불접수 등록 시 계산 기준일을 자동 저장

- 계산 기준일 수정 시 변경사유·처리담당자·변경 전후 값을 기록




11-6. 기간제 강좌 계산식


1일 이용대금 = 정상가(N) &divide; 정가 수강기간(D)
이용 공제액 = 1일 이용대금 × 실제 이용일수(d)
환불 대상금액 = 결제기준금액(B) &minus; 이용 공제액 &minus; 쿠폰 사용금액(C)


- 최종 환불금액이 0원 미만이면 0원으로 처리

- 실제 이용일수 × 2 &ge; 정가 수강기간이면 금액 계산 대신 [환불 불가] 표시




11-7. 단과 강좌 계산식


이용일수 기준 공제액 = 정상가(N) &divide; 정가 수강기간(D) × 실제 이용일수(d)
회차 기준 공제액 = 정상가(N) &divide; 전체 예정 회차(T) × 수강·자료 이용 회차(t)
적용 공제액 = MAX(이용일수 기준 공제액, 회차 기준 공제액)
환불 대상금액 = 결제기준금액(B) &minus; 적용 공제액 &minus; 쿠폰 사용금액(C)





표시항목 | 예시



이용일수 기준 공제액 | 50,000원



회차 기준 공제액 | 80,000원



최종 적용 공제액 | 80,000원



적용사유 | 회차 기준 공제액이 더 큼









11-8. 미종강 강의


아직 촬영·업로드가 끝나지 않은 강의는 현재 등록된 회차 수가 아니라 판매 시 상품 안내에 사전 고지한 전체 예정 회차를 기준으로 계산합니다.

예: 현재 업로드 10회 / 사전 공지 전체 예정 30회 &rarr; 환불 계산 전체 회차(T) = 30회


- 강의상품 등록 시 [전체 예정 회차] 필수 입력

- 판매 시작 후 전체 예정 회차 변경 시 변경이력·변경사유·처리관리자 저장

- 기존 주문은 결제 당시 저장된 예정 회차를 계속 사용




11-9. 패키지·PASS·할인상품



- PASS·기간제·패키지·특별기획 등 할인상품의 이용 공제액은 할인가가 아닌 할인 전 정상가(N)를 기준으로 계산

- 패키지 상품은 구성 강좌 일부만 별도 환불할 수 없음


패키지 일부만 선택하면 접수 차단:
“패키지 상품은 구성강좌의 일부만 별도로 환불할 수 없습니다. 패키지 전체를 선택해 주세요.”

패키지·PASS 상품의 환불 계산유형


- 기간제 계산식

- 단과 묶음 계산식

- 상품별 별도 환불규정




11-10. 쿠폰 처리



- 이벤트 쿠폰 사용금액은 환불 대상금액에서 공제

- 특정 상품 전용 쿠폰: 해당 상품에 전액 배분

- 주문 전체 쿠폰: 결제 시 대상 상품 판매금액 비율로 상품별 배분

- 원 단위 배분 차액: 마지막 대상 상품에 반영

- 기본값은 환불 후 쿠폰 자동 재발급 안 함

- 쿠폰 정책에서 [환불 시 복원 가능]으로 설정된 쿠폰만 복원




11-11. 포인트 처리


포인트 반환액 = MIN(사용 포인트(Q), 환불 대상금액)
토스 취소 예정금액 = 환불 대상금액 &minus; 포인트 반환액


- 포인트 반환액 + 토스 취소 예정금액 = 최종 환불금액인지 검증

- 토스 취소 예정금액은 실제 PG 결제금액을 초과할 수 없음

- 기존 누적 환불액을 포함해 최초 결제금액 초과 금지

- 결제로 적립된 포인트는 환불비율에 맞게 회수




11-12. 재수강·수강연장·기간연장


재수강·수강연장·기간연장 결제도 원래 강의와 별개의 환불 대상 상품으로 관리하고 동일한 환불 원칙을 적용합니다.


- 연장/재수강 결제금액

- 정상가

- 적용기간

- 이용 시작일

- 실제 이용일수

- 쿠폰·포인트 사용내역

- 환불 계산유형


원래 강의 결제금액과 연장·재수강 결제금액을 서로 섞어서 계산하지 않습니다.

11-15. 계산 예외 및 반올림



- 계산 결과가 0원 미만이면 0원

- 누적 환불액이 결제금액을 초과하면 처리 차단

- 나눗셈으로 소수점 발생 시 최종 공제액에서 원 단위 미만 절사

- 최종 환불금액은 1원 단위 처리

- 화면 표시값과 DB 저장값이 반드시 일치

- 환불 계산 확정 후 상품가격·예정 회차가 변경되어도 확정된 계산결과는 변경되지 않음




12. 개발 검증 예시


예시 A · 기간제 상품





항목 | 값



결제기준금액 | 300,000원



정상가 | 600,000원



정가 수강기간 | 100일



실제 이용일수 | 20일



쿠폰 | 30,000원







1일 이용대금 = 600,000 &divide; 100 = 6,000원
이용 공제액 = 6,000 × 20 = 120,000원
환불금액 = 300,000 &minus; 120,000 &minus; 30,000 = 150,000원




예시 B · 단과 상품





항목 | 값



결제기준금액 | 200,000원



정상가 | 300,000원



정가 수강기간 | 60일



실제 이용일수 | 10일



전체 예정 회차 | 30회



이용 회차 | 8회



쿠폰 | 20,000원







이용일수 기준 공제액 = 300,000 &divide; 60 × 10 = 50,000원
회차 기준 공제액 = 300,000 &divide; 30 × 8 = 80,000원
적용 공제액 = MAX(50,000, 80,000) = 80,000원
환불금액 = 200,000 &minus; 80,000 &minus; 20,000 = 100,000원



검증 완료 기준
위 계산결과를 관리자가 확인하고 [환불금액 확정] &rarr; [PG 취소대기]로 변경한 뒤, 토스 상점관리자에서 관리자가 직접 전체취소 또는 부분취소하고 리담 환불관리 화면에 실제 취소정보를 입력하는 흐름까지 정상 동작해야 합니다.
