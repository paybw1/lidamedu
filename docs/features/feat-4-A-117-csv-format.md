# 강의노트 매핑 CSV 작성 가이드 (feat-4-A-117)

> 강의노트 PDF 의 어느 페이지가 어떤 조문/판례에 해당하는지 사용자가 직접 매핑하는 CSV.
> 작성 위치: `tmp/lecture-note-mapping.csv` (gitignore — 커밋 안 됨)
> 적용 스크립트: `scripts/import-lecture-note.mjs`

## 1. 컬럼 정의

| 컬럼 | 필수 | 값 | 설명 |
|------|:---:|----|------|
| `시작` | ✅ | 정수 (1~608) | PDF 원본 페이지 번호 (1-based) |
| `끝` | ✅ | 정수 (1~608) | 끝 페이지. 단일 페이지면 시작과 같은 값 |
| `종류` | ✅ | `조문` 또는 `판례` | 매핑 대상 종류 |
| `식별자` | ✅ | 텍스트 | 종류에 따라 형식이 다름 (§ 2) |
| `제목` |  | 텍스트 | 자료 표시 제목. 비우면 자동 생성 (예: "리담특허법 강의노트(제10판) p.67-72") |

## 2. 식별자 형식

### 조문
한국어 표준 표기 그대로:

| 예 | 매칭 결과 |
|----|----------|
| `특허법 제29조` | 제29조 본조 |
| `특허법 제29조 제1항` | 제29조 제1항 |
| `특허법 제29조 제2항 제3호` | 제29조 제2항 제3호 |
| `특허법 제29조의2 제1항` | 가지조 (29의2) |
| `상표법 제33조 제1항 제3호 가목` | 상표법 |
| `디자인보호법 제5조` | 디자인보호법 |
| `민법 제103조` | 민법 |

> 법명은 `특허법 / 상표법 / 디자인보호법 / 민법 / 민사소송법` 중 하나.

### 판례
DB `cases.case_number` 와 **정확 일치**해야 함. 가장 단순한 형태:

| 예 | 비고 |
|----|------|
| `2014후1129` | 일반 사건번호 |
| `2020후10543` | |
| `2014다1234` | 민사 |
| `2014다1234, 2014다1235` | 병합사건은 DB 표기 그대로 |

> 정확 일치하지 않으면 dry-run 에서 빨간색으로 표시. 사건번호는 `대법원 ` 등 법원명 접두사 없이 그대로.

## 3. CSV 예시

```csv
시작,끝,종류,식별자,제목
1,3,조문,특허법 제1조,총칙
67,72,조문,특허법 제29조 제1항,신규성 — 동일성의 유형
73,73,조문,특허법 제29조 제1항,
74,76,판례,2014후1129,진보성 판단 사례
77,79,조문,특허법 제29조 제2항,
80,80,판례,2020후10543,
```

## 4. 페이지 묶음 규칙 (권장)

- 같은 조문/판례가 **연속된 페이지**에 걸쳐 있으면 한 줄로 묶기 (예: 67-72)
- 같은 조문이 비연속 페이지에 등장하면 줄 2개 (예: 67-72 + 100-101)
- 인쇄 페이지 번호가 아니라 **PDF 원본 페이지 번호** 기준 (PDF 뷰어 좌상단 페이지 카운터)

## 5. 적용 흐름

```bash
# 1) tmp/lecture-note-mapping.csv 작성

# 2) dry-run — 검증만, DB 변경 없음
node scripts/import-lecture-note.mjs --dry-run

# 3) 결과 확인 후 적용
node scripts/import-lecture-note.mjs --apply
```

dry-run 출력:
- ✅ 매칭 성공 row → "[apply] p.67-72 → 특허법 제29조 제1항"
- ❌ 매칭 실패 row → 사유 (잘못된 형식 / DB 없음 / 페이지 범위 무효)
- 통계 (total / ok / fail)

`--apply` 는 같은 `source_pdf_id` 의 기존 자료를 soft-delete 한 뒤 재 import (idempotent — CSV 수정 후 재실행 안전).

## 6. 첫 강의노트 (리담특허법 제10판)

- PDF 원본: `source/리담특허법 강의노트(제10판).pdf` (608 페이지)
- `source_pdf_id`: 스크립트가 책 이름 hash 로 결정 (재실행 시 동일)
- `title` 자동 생성 형식: `리담특허법 강의노트(제10판) p.{시작}-{끝}`
