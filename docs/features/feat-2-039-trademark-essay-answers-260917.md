### 상표 고유 사항

- **자기법 접두 삭제**: 괄호 안 `§34①(9)`·`§119①(3)`·`§2①(11)다`. 타법은 표준 약호 `특§`·`디§`·`민§`·`민소§`, 약호 없는 법(부정경쟁방지법·시행령·조약)은 풀네임.
- **2016 전부개정(2016-09-01 시행)**: 구 §7① → §34①, 구 §73① → §119①, 서비스표·지정서비스업 폐지(상표·지정상품에 통합) 등. 발문이 구법 조문·용어를 쓰면 현행 대응관계를 한 줄만 밝히고 부칙·경과는 쓰지 않는다. 대응표 = `scripts/jagwa/derive-article-mapping.mjs` 산출(상표 2016). 2차도서의 조문 번호는 판본 확인 전에는 옮기지 않는다.
- 기관명 「지식재산처」. 판례 인용 「대법원 NNNN후NNNN」, 「허」 사건은 특허법원. `cases.court` 대조.
- 판례 용어(사회통념상 동일성·상표적 사용 등)는 판시 문언대로. 강학 조어 여부는 교재·판례 대조로 판단.
- 채점기준 감점 경고문에 사건번호 금지(별칭으로) — 오배지 방지.
