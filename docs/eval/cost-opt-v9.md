## v9-A 캐싱 실패 (구조적)

production `buildSystemPrompt` 반환 = `가드레일 + 컨텍스트 청크` 단일 문자열. 매 질문마다 청크 다름 → cache prefix invalidate → `cache_read=0`, `cache_create 1.84M` 토큰만 부담(1.25× write premium).

**가드레일 단독 토큰 측정 결과: 1,025 토큰** (Sonnet 4.6 최소 캐시 prefix 2,048 미만).

> 가드레일만 별도 캐싱 블록으로 분리해도 2,048 토큰 미달이라 작동 불가. 가드레일을 억지로 늘리는 건 본말전도(매 요청 토큰 추가 = 절감 상쇄). **캐싱은 이 구조에서는 폐기**.

v9-A `app/features/ai-qna/lib/answer.server.ts` 의 `cache_control: ephemeral` 마킹은 **롤백 완료**. `tokenUsage.cacheRead/cacheCreate` 필드는 향후 측정용으로 보존.
